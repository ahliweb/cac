## Rencana proyek

Komputer cepat menandai data yang mencurigakan menurut aturan, tetapi **manusialah yang memutuskan** apakah data itu dibuang, diperbaiki, atau dibiarkan. Itulah komputasi manusia untuk data berkualitas: programmu menandai, laporanmu mencatat keputusan.

Sebelum menulis program, tulis rencana satu halaman dengan tujuh bagian: tujuan, masukan, aturan pemeriksaan, keluaran, kriteria selesai, daftar uji, dan **prediksi hasil**. Contoh terselesaikan: pemeriksa data suhu ruangan (karangan, dalam derajat Celsius).

| Bagian | Isi contoh |
| --- | --- |
| Tujuan | Menandai bacaan suhu yang tidak dapat dipercaya dan menghitung rata-rata data yang baik. |
| Masukan | Bilangan `n`, lalu `n` bilangan desimal. |
| Aturan | Nilai -999 berarti hilang. Di luar 15 sampai 40 berarti di luar rentang. Beda lebih dari 5 dari data baik sebelumnya berarti lonjakan. Selain itu data baik. |
| Keluaran | Satu baris untuk tiap data yang ditandai, ringkasan jumlah, dan rata-rata data baik. |
| Kriteria selesai | Tiap data masuk tepat satu kategori; jumlah keempat kategori sama dengan `n`; rata-rata hanya dari data baik. |
| Daftar uji | Contoh di bawah; `n = 0`; semua data hilang; nilai tepat 15, 40, dan sedikit di luarnya. |
| Prediksi | Dari 10 data contoh: baik 6, hilang 1, di luar rentang 2, lonjakan 1; rata-rata baik 23,0. |

Pseudocode-nya:

```text
baca n
ULANGI n kali:
  baca x
  BILA x = -999: tandai hilang
  JIKA TIDAK BILA x di luar 15..40: tandai di luar rentang
  JIKA TIDAK BILA ada data baik sebelumnya DAN |x - data baik terakhir| > 5: tandai lonjakan
  JIKA TIDAK: x data baik; tambahkan ke jumlah; perbarui terkecil, terbesar, data baik terakhir
cetak ringkasan
BILA ada data baik: cetak rata-rata, terkecil, terbesar
```

Programnya (konstanta bernama untuk semua batas):

```cpp
#include <cmath>
#include <iomanip>
#include <iostream>
using namespace std;

const double HILANG = -999;
const double MIN_SUHU = 15;
const double MAX_SUHU = 40;
const double BATAS_LONJAKAN = 5;

bool dalamRentang(double x) {
  return x >= MIN_SUHU && x <= MAX_SUHU;
}

int main() {
  int n;
  cin >> n;
  int baik = 0, hilang = 0, luar = 0, lonjakan = 0;
  double jumlah = 0, terkecil = 0, terbesar = 0, terakhirBaik = 0;
  cout << fixed << setprecision(1);
  for (int i = 1; i <= n; i++) {
    double x;
    cin >> x;
    if (x == HILANG) {
      hilang++;
      cout << "data ke-" << i << ": hilang\n";
    } else if (!dalamRentang(x)) {
      luar++;
      cout << "data ke-" << i << ": di luar rentang (" << x << ")\n";
    } else if (baik > 0 && fabs(x - terakhirBaik) > BATAS_LONJAKAN) {
      lonjakan++;
      cout << "data ke-" << i << ": lonjakan (" << x << ", sebelumnya " << terakhirBaik << ")\n";
    } else {
      if (baik == 0 || x < terkecil) {
        terkecil = x;
      }
      if (baik == 0 || x > terbesar) {
        terbesar = x;
      }
      baik++;
      jumlah += x;
      terakhirBaik = x;
    }
  }
  cout << "Ringkasan: baik " << baik << ", hilang " << hilang << ", di luar rentang " << luar << ", lonjakan " << lonjakan << "\n";
  if (baik > 0) {
    cout << "Rata-rata data baik: " << jumlah / baik << " (terkecil " << terkecil << ", terbesar " << terbesar << ")\n";
  } else {
    cout << "Tidak ada data baik.\n";
  }
}
```

Masukan (`masukan.txt`):

```text
10 22.5 23.0 -999 22.8 55.0 23.1 29.9 23.4 23.2 14.0
```

Keluaran:

```text
data ke-3: hilang
data ke-5: di luar rentang (55.0)
data ke-7: lonjakan (29.9, sebelumnya 23.1)
data ke-10: di luar rentang (14.0)
Ringkasan: baik 6, hilang 1, di luar rentang 2, lonjakan 1
Rata-rata data baik: 23.0 (terkecil 22.5, terbesar 23.4)
```

Cocokkan dengan prediksimu. Aturan lonjakan ini sederhana dan punya kelemahan: bila suhu memang naik dan bertahan, semua data sesudahnya ikut ditandai lonjakan. Itu keputusan manusia, dan layak masuk laporanmu.

**Pilihan proyekmu** (pilih satu, atau usulkan ke gurumu): (1) curah hujan harian karangan dalam milimeter, dengan nilai tak mungkin dan lonjakan tak wajar; (2) skor ulangan sintetis 0 sampai 100, dengan skor di luar rentang dan kode -1 untuk "tidak ikut". Tulis rencana tujuh bagianmu sendiri dengan deret datamu sendiri.

## Kunci dan petunjuk

**Ingat kembali.** 1: parameter adalah nama di definisi fungsi; argumen adalah nilai yang diberikan saat memanggil. 2: `=` mengisi variabel; `==` membandingkan. 3: fisik (kabel atau Wi-Fi), alamat IP, DNS, lalu layanan.

**Rencana proyek.** Contoh di atas satu jawaban yang mungkin; rencanamu boleh berbeda selama ketujuh bagian ada dan kriteria selesai dapat diuji. Contoh uji batas dengan program di atas dan masukan `3 40 40.1 39.9`: 40 baik (tepat batas), 40.1 di luar rentang, 39.9 baik. Keluarannya:

```text
data ke-2: di luar rentang (40.1)
Ringkasan: baik 2, hilang 0, di luar rentang 1, lonjakan 0
Rata-rata data baik: 40.0 (terkecil 39.9, terbesar 40.0)
```

Dengan `n = 0` keluarannya `Ringkasan: baik 0, hilang 0, di luar rentang 0, lonjakan 0` lalu `Tidak ada data baik.`. Untuk proyek pilihan: rencana yang baik menyebut aturan yang bisa diperiksa dan prediksi untuk deret data yang kamu tulis sendiri; batas angkanya karanganmu sendiri.

**Daftar periksa.** Tidak ada kunci tunggal; guru memeriksa tiap butir dengan rubrik.

**Umpan balik sejawat.** Umpan balik yang baik menunjuk bagian tertentu, menyebut alasan, dan menawarkan langkah yang bisa dikerjakan. "Bagus" saja bukan umpan balik.

**Latihan bercampur.** 1: perulangan berjalan nol kali, jadi tidak ada data; tanpa pemeriksaan `baik > 0`, rata-rata membagi dengan nol. 2: `x < 15 || x > 40`. 3: contoh kerangka: `if (x == HILANG) return 'H'; if (!dalamRentang(x)) return 'R'; if (adaBaik && fabs(x - terakhirBaik) > BATAS_LONJAKAN) return 'L'; return 'B';`.

**Ulang berjarak.** 1: galat paling sering muncul tepat di batas, misalnya `<` yang seharusnya `<=`. 2: contoh: memeriksa rentang nilai dan menandai nilai penanda hilang (juga boleh: memeriksa lonjakan, memeriksa duplikat). 3: karena -999 bukan hasil ukur; ia menggeser rata-rata jauh dari nilai sebenarnya.
