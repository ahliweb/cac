## Tujuan

Setelah modul ini kamu dapat:

- memakai `for` dan `while` dan menelusuri nilai variabel pada tiap putaran;
- memakai perulangan bersarang untuk pola dan tabel;

## Prediksi dulu

Ini tugas baca-dan-prediksi, `AI: tanpa AI`. **Tebak dulu, tulis jawabanmu, baru jalankan.**

```cpp
#include <iostream>
using namespace std;

int main() {
  int jumlah = 0;
  for (int i = 1; i <= 5; i++) {
    jumlah += i;
    cout << i << ": " << jumlah << "\n";
  }
  int k = 10;
  while (k > 0) {
    k -= 4;
    cout << k << " ";
  }
  cout << "\n";
}
```

1. Apa lima baris pertama yang tercetak?
2. Berapa kali badan `while` berjalan, dan angka apa saja yang tercetak pada baris terakhir?
3. Mengapa `k` tercetak bernilai negatif walaupun syaratnya `k > 0`?

Simpan tebakanmu. Perbandingannya ada di bagian berikutnya.

## Contoh terselesaikan

Keluaran program tadi:

Keluaran:

```text
1: 1
2: 3
3: 6
4: 10
5: 15
6 2 -2 
```

Penelusuran `for`: awalnya `i = 1`; bila `i <= 5` benar, badan dijalankan, lalu `i++` menambah `i`, lalu syarat diperiksa lagi. Pada `while`, `k` turun 4 tiap putaran: 10 jadi 6, 6 jadi 2, 2 jadi -2. Syarat `k > 0` baru diperiksa **sebelum** putaran berikutnya, sehingga -2 tercetak lebih dulu. Tiap angka diikuti spasi, jadi baris terakhir keluaran berakhir dengan spasi.

Jumlah deret 1 sampai n, dengan `long long` agar hasil besar tidak meluap:

```cpp
#include <iostream>
using namespace std;

int main() {
  int n;
  cin >> n;
  long long jumlah = 0;
  for (int i = 1; i <= n; i++) {
    jumlah += i;
  }
  cout << jumlah << "\n";
}
```

Masukan (`masukan.txt`):

```text
100
```

Keluaran:

```text
5050
```

Perulangan bersarang: perulangan luar mengatur baris, perulangan dalam mengatur isi tiap baris. Pola bintang segitiga:

```cpp
#include <iostream>
using namespace std;

int main() {
  int n;
  cin >> n;
  for (int baris = 1; baris <= n; baris++) {
    for (int kolom = 1; kolom <= baris; kolom++) {
      cout << "*";
    }
    cout << "\n";
  }
}
```

Masukan (`masukan.txt`):

```text
4
```

Keluaran:

```text
*
**
***
****
```

Uji prima sederhana: sebuah bilangan `n` yang lebih dari 1 bukan prima bila punya pembagi `i` dengan `2 <= i` dan `i * i <= n`. Cukup memeriksa sampai di situ, karena bila `n = a * b` dengan `a <= b`, maka `a * a <= n`; pembagi yang lebih kecil selalu ketemu lebih dulu. `break` menghentikan perulangan begitu pembagi ditemukan.

```cpp
#include <iostream>
using namespace std;

int main() {
  int n;
  cin >> n;
  bool prima = n >= 2;
  int pembagi = 0;
  for (int i = 2; i * i <= n; i++) {
    if (n % i == 0) {
      prima = false;
      pembagi = i;
      break;
    }
  }
  if (prima) {
    cout << n << " prima\n";
  } else if (pembagi > 0) {
    cout << n << " bukan prima, habis dibagi " << pembagi << "\n";
  } else {
    cout << n << " bukan prima\n";
  }
}
```

Masukan (`masukan.txt`):

```text
91
```

Keluaran:

```text
91 bukan prima, habis dibagi 7
```

Pemeriksaan hanya menunjukkan program bisa dikompilasi; uji dengan beberapa masukan (misalnya 97, 1, dan 49) sebelum memercayainya. `continue` melompati sisa badan dan lanjut ke putaran berikutnya: `if (i % 2 == 0) { continue; }` melewati bilangan genap.

## Soal Parsons

Susun baris-baris berikut (sudah diacak) menjadi badan `main` yang menjumlahkan bilangan **ganjil** dari 1 sampai `n`. `AI: tanpa AI`: tujuannya melatih membaca urutan program.

```text
(a)   int jumlah = 0;
(b)     jumlah += i;
(c)   cout << jumlah << "\n";
(d)   int n;
(e)   for (int i = 1; i <= n; i++) {
(f)     if (i % 2 == 0) {
(g)       continue;
(h)     }
(i)   cin >> n;
(j)   }
```

## Latihan

1. `AI: boleh` **Pseudocode dulu.** Tulis pseudocode lalu program pola segitiga terbalik untuk `n = 4`: empat bintang di baris pertama, tiga di baris kedua, dan seterusnya.
2. `AI: tanpa AI` **Telusuri.** Apa yang tercetak oleh `for (int i = 1; i <= 10; i++) { if (i % 3 == 0) { continue; } if (i > 7) { break; } cout << i << " "; }`?
3. `AI: boleh` **Tabel perkalian.** Cetak tabel perkalian 1 sampai 5 dalam lima baris dan lima kolom, angka dipisah spasi, dengan dua perulangan bersarang.
4. `AI: boleh` **Prima.** Hitung dan cetak banyak bilangan prima dari 2 sampai 50 dengan uji prima di dalam perulangan.
5. *Opsional:* **catatan pemakaian AI.** Bila memakai AI generatif, jawab nomor 1 sendiri dulu, lalu minta penjelasan atau petunjuk bertahap, bukan program jadi. Catat alatnya, tujuanmu, garis besar perintahmu, bagian yang kamu pakai, dan caramu memeriksanya (jalankan atau telusuri). Jangan menaruh data pribadi atau tugas bernilai pada perintah.

## Kesalahan umum

- **Selisih satu (off-by-one).** `i < n` dan `i <= n` beda satu putaran; telusuri putaran pertama dan terakhir.
- **Perulangan tak berhenti.** Lupa mengubah variabel dalam `while` (misalnya `k`) membuat syarat tak pernah salah.
- **Titik koma setelah `for (...)`.** `for (...);` membuat badannya kosong; isi kurung kurawal sesudahnya jalan satu kali.
- **Jumlah meluap.** Jumlah banyak suku bisa melewati batas `int`; pakai `long long`.
- **Memindahkan `continue` atau `break` ke tempat yang salah.** `continue` yang ditaruh sebelum `jumlah += i` ikut melewati penjumlahan itu.

## Kunci dan petunjuk

**Ingat kembali.** 1: `n % 2 == 0 && n > 10`. 2: karena nilai lama a hilang begitu a diisi nilai b; variabel sementara menyimpannya dulu. 3: 45 = 32 + 8 + 4 + 1, jadi 101101.

**Prediksi dulu.** 1: `1: 1`, `2: 3`, `3: 6`, `4: 10`, `5: 15`. 2: tiga kali; tercetak `6 2 -2`. 3: syarat hanya diperiksa sebelum putaran, sehingga putaran ketika `k` bernilai 2 masih mengurangi 4 dan mencetak -2.

**Contoh setengah jadi.** Isi: `1`, `5`, `k * i`. Program lengkapnya:

```cpp
#include <iostream>
using namespace std;

int main() {
  int k;
  cin >> k;
  for (int i = 1; i <= 5; i++) {
    cout << k << " x " << i << " = " << k * i << "\n";
  }
}
```

Masukan (`masukan.txt`):

```text
7
```

Keluaran:

```text
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
```

**Soal Parsons.** Urutan benar: d, i, a, e, f, g, h, b, j, c. Perhatikan: `continue` ada di dalam `if`, `jumlah += i` di luar `if` tetapi di dalam `for`, dan `cout` setelah `for` selesai.

**Latihan.** 1: pseudocode: baca n; untuk baris dari n turun ke 1: cetak bintang sebanyak baris, lalu pindah baris. Program contoh:

```cpp
#include <iostream>
using namespace std;

int main() {
  int n;
  cin >> n;
  for (int baris = n; baris >= 1; baris--) {
    for (int kolom = 1; kolom <= baris; kolom++) {
      cout << "*";
    }
    cout << "\n";
  }
}
```

Masukan (`masukan.txt`):

```text
4
```

Keluaran:

```text
****
***
**
*
```

2: tercetak `1 2 4 5 7`. Nilai 3, 6, 9 dilewati oleh `continue`; pada `i = 8` syarat `i > 7` benar sehingga `break` menghentikan perulangan sebelum mencetak. 3: program contoh:

```cpp
#include <iostream>
using namespace std;

int main() {
  for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= 5; j++) {
      cout << i * j;
      if (j < 5) {
        cout << " ";
      }
    }
    cout << "\n";
  }
}
```

Keluaran:

```text
1 2 3 4 5
2 4 6 8 10
3 6 9 12 15
4 8 12 16 20
5 10 15 20 25
```

4: program contoh:

```cpp
#include <iostream>
using namespace std;

int main() {
  int banyak = 0;
  for (int n = 2; n <= 50; n++) {
    bool prima = true;
    for (int i = 2; i * i <= n; i++) {
      if (n % i == 0) {
        prima = false;
        break;
      }
    }
    if (prima) {
      banyak++;
    }
  }
  cout << banyak << "\n";
}
```

Keluaran:

```text
15
```

**Latihan bercampur.** 1: pseudocode: baca n; banyak <- 0; ulangi n kali: baca skor; BILA skor >= 70: banyak <- banyak + 1; cetak banyak. 2: nilai "terbesar" diperbarui di dalam perulangan yang membaca tiap bilangan; dua pengecekan terpisah diganti satu `if` di dalam perulangan. 3: hasil 256, sama dengan 2^8 nilai berbeda satu byte.

**Ulang berjarak.** 1: 5 kali (i = 0, 1, 2, 3, 4). 2: `break` menghentikan seluruh perulangan; `continue` hanya melewati sisa putaran itu. 3: bila `n = a * b` dengan `a <= b`, maka `a * a <= n`; pembagi terkecil selalu ketemu sebelum `i * i` melewati `n`.
