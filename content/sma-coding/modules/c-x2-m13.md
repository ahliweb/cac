## Untuk siapa modul ini

Modul ini untuk murid kelas X jalur C (IoT dan robotika), minggu `C-X2-M13` silabus v1.3: proyek mini, stasiun pengamat (F). Prasyarat: modul `c-x2-m12` (mencatat data). Proyek ini memadukan seluruh semester: masukan analog (`c-x1-m11`), data berkualitas (`c-x2-m3`), median (`c-x2-m10`), tampilan dan pencatatan (`c-x2-m8` dan `c-x2-m12`), serta `millis()` (`c-x2-m7`).

Modul ini berstatus DRAF: karangan penyusun, belum ditinjau pemilik. Ia mendukung butir `E-BK-c` (menerapkan algoritma dan struktur data standar) dan tidak dihitung memenuhi butir capaian pembelajaran mana pun. Penilaian proyek memakai rubrik dari gurumu; modul ini tidak menilai. Keluaran minggu ini: perangkat, program, dan laporan. Latihan silabusnya: stasiun suhu dan cahaya kelas.

Ada dua cara mengerjakan. **Dengan papan (F):** kelompok tiga murid merakit satu sensor suhu dan satu sensor cahaya sesuai lembar guru. **Tanpa papan:** kamu menulis rancangan dan program, lalu mengujinya dengan "papan tiruan" di komputer memakai pembacaan karangan. Nomor pin, ambang, dan rumus suhu pada contoh hanya contoh `[belum terverifikasi]` untuk papanmu.

## Keselamatan perangkat

- Daya hanya dari kabel USB. Tidak ada listrik jaringan (220 V) dan tidak ada baterai pada modul ini.
- Cabut kabel USB sebelum memasang atau melepas sensor. Hanya komponen yang disiapkan guru; sensor disambung ke pin yang ditunjuk lembar guru.
- Tidak ada solder. Papan percobaan dan kabel jumper sudah cukup.
- Stasiun ini **tidak memakai kamera atau mikrofon** dan tidak mengukur tubuh siapa pun. Data yang dicatat hanya suhu dan cahaya ruangan; berkas tidak memuat nama atau identitas.
- Papan atau komponen yang terasa panas, berbau, atau berasap: cabut kabel dan panggil guru.

## Rencana proyek

Sebelum menyentuh papan, tulis rencanamu: apa arti "selesai", lalu tebakan hasilnya. Satu halaman cukup, dengan enam bagian: tujuan, diagram I-P-O, pseudocode, kriteria selesai, daftar uji, dan prediksi hasil.

Contoh terselesaikan untuk **stasiun suhu dan cahaya kelas**:

| Bagian | Isi contoh |
| --- | --- |
| Tujuan | Mencatat suhu dan kategori cahaya kelas sebagai baris CSV, tanpa terganggu satu pembacaan palsu. |
| Masukan | Sensor suhu dan sensor cahaya (nilai 0 sampai 4095 pada contoh; periksa papanmu). |
| Proses | Kumpulkan 5 pembacaan tiap sensor, ambil median, ubah ke suhu dan kategori. |
| Keluaran | Satu baris `waktu_detik,suhu_c,cahaya,kategori` ke `Serial` (kepala berkas sekali di awal). |
| Kriteria selesai | Lonjakan tunggal tidak mengubah baris; kategori benar di nilai batas; tiga uji lolos. |
| Prediksi | Cahaya 400, 380, 420, 10, 390 menghasilkan median 390 dan kategori GELAP. |

Pseudocode-nya:

```text
ULANG TERUS:
  BILA sudah 200 ms sejak pembacaan terakhir:
    simpan pembacaan suhu dan cahaya
    BILA sudah 5 pembacaan:
      cetak waktu, suhu dari median, cahaya median, kategori
      mulai lagi dari 0 pembacaan
```

Programnya:

```arduino
// Arduino-C++ untuk ESP32. Diperiksa check:module-code terhadap header tiruan (sintaks dan tipe saja, bukan bukti perilaku papan).
const int PIN_SUHU = 34;                 // contoh; periksa papanmu
const int PIN_CAHAYA = 35;
const int N = 5;
const unsigned long BACA_MS = 200;
const int AMBANG_GELAP = 800;            // ukur sendiri; ini contoh
const int AMBANG_TERANG = 2500;          // ukur sendiri; ini contoh

enum Cahaya { GELAP, REDUP, TERANG };
const char* NAMA[] = {"GELAP", "REDUP", "TERANG"};

int suhuMentah[N];
int cahayaMentah[N];
int terisi = 0;
unsigned long awal = 0;
unsigned long mulai = 0;

int median(const int data[N]) {
  int a[N];
  for (int i = 0; i < N; i++) {
    a[i] = data[i];
  }
  for (int i = 1; i < N; i++) {
    int nilai = a[i];
    int j = i - 1;
    while (j >= 0 && a[j] > nilai) {
      a[j + 1] = a[j];
      j--;
    }
    a[j + 1] = nilai;
  }
  return a[N / 2];
}

float suhuDariMentah(int mentah) {
  return mentah * 50.0f / 4095.0f;       // rumus contoh, bukan rumus sensor nyata
}

Cahaya kategoriCahaya(int mentah) {
  if (mentah < AMBANG_GELAP) {
    return GELAP;
  }
  if (mentah < AMBANG_TERANG) {
    return REDUP;
  }
  return TERANG;
}

void setup() {
  Serial.begin(115200);
  Serial.println("waktu_detik,suhu_c,cahaya,kategori");
  awal = millis();
  mulai = awal;
}

void loop() {
  if (millis() - mulai >= BACA_MS) {
    mulai += BACA_MS;
    suhuMentah[terisi] = analogRead(PIN_SUHU);
    cahayaMentah[terisi] = analogRead(PIN_CAHAYA);
    terisi++;
    if (terisi == N) {
      int cahayaTengah = median(cahayaMentah);
      Serial.print((millis() - awal) / 1000);
      Serial.print(',');
      Serial.print(suhuDariMentah(median(suhuMentah)), 1);
      Serial.print(',');
      Serial.print(cahayaTengah);
      Serial.print(',');
      Serial.println(NAMA[kategoriCahaya(cahayaTengah)]);
      terisi = 0;
    }
  }
}
```

Daftar uji dijalankan lebih dulu di komputer dengan pembacaan karangan. Baris kedua suhu memuat lonjakan palsu 4095; baris ketiga cahaya memuat satu pembacaan palsu 10.

```cpp
// C++17 biasa, jalan di komputer. Diperiksa oleh check:module-code.
#include <iomanip>
#include <iostream>

const int N = 5;                    // pembacaan per baris
const int AMBANG_GELAP = 800;       // ukur sendiri; ini contoh (nilai besar = terang pada contoh)
const int AMBANG_TERANG = 2500;     // ukur sendiri; ini contoh

enum Cahaya { GELAP, REDUP, TERANG };
const char* NAMA[] = {"GELAP", "REDUP", "TERANG"};

// Median lima pembacaan; yang diurutkan salinannya.
int median(const int data[N]) {
  int a[N];
  for (int i = 0; i < N; i++) {
    a[i] = data[i];
  }
  for (int i = 1; i < N; i++) {
    int nilai = a[i];
    int j = i - 1;
    while (j >= 0 && a[j] > nilai) {
      a[j + 1] = a[j];
      j--;
    }
    a[j + 1] = nilai;
  }
  return a[N / 2];
}

float suhuDariMentah(int mentah) {
  return mentah * 50.0f / 4095.0f;  // rumus contoh, bukan rumus sensor nyata
}

Cahaya kategoriCahaya(int mentah) {
  if (mentah < AMBANG_GELAP) {
    return GELAP;
  }
  if (mentah < AMBANG_TERANG) {
    return REDUP;
  }
  return TERANG;
}

void cetakBaris(int detik, const int suhu[N], const int cahaya[N]) {
  int cahayaTengah = median(cahaya);
  std::cout << detik << "," << suhuDariMentah(median(suhu)) << "," << cahayaTengah << ","
            << NAMA[kategoriCahaya(cahayaTengah)] << "\n";
}

int main() {
  std::cout << std::fixed << std::setprecision(1);
  std::cout << "waktu_detik,suhu_c,cahaya,kategori\n";
  const int SUHU[3][N] = {{2290, 2300, 2295, 2310, 2305},
                          {2300, 4095, 2310, 2305, 2300},
                          {2320, 2315, 2330, 2325, 2318}};
  const int CAHAYA[3][N] = {{3000, 3010, 2990, 3005, 3000},
                            {1500, 1490, 1510, 1500, 1495},
                            {400, 380, 420, 10, 390}};
  for (int i = 0; i < 3; i++) {
    cetakBaris(i * 30, SUHU[i], CAHAYA[i]);
  }
}
```

Keluarannya:

```text
waktu_detik,suhu_c,cahaya,kategori
0,28.1,3000,TERANG
30,28.1,1500,REDUP
60,28.3,390,GELAP
```

Cocokkan dengan prediksimu. Baris kedua tetap 28,1 walau satu pembacaan 4095 (kira-kira 50 derajat pada rumus contoh), dan baris ketiga tetap GELAP walau satu pembacaan 10. Uji ini hanya membuktikan logikanya; sensormu diuji dengan papan, dan ambangnya diukur dari rangkaianmu sendiri.

## Kesalahan umum

- **Langsung merakit tanpa rencana.** Tanpa kriteria selesai, kamu tidak tahu kapan berhenti dan tidak bisa membandingkan hasil dengan tebakan.
- **Hanya menguji nilai yang nyaman.** Galat sering muncul pada lonjakan dan tepat di batas ambang.
- **Mengambil keputusan dari satu pembacaan.** Satu pembacaan palsu mengubah kategori; saring dulu.
- **Mengira papan tiruan menggantikan papan.** Papan tiruan hanya memeriksa logika; derau, waktu, dan sambungan nyata tidak diuji.
- **Ambang ditebak dan satuan tidak ditulis.** Nilai sensor berbeda antar ruangan dan rangkaian, dan berkas tanpa satuan tidak bisa dipakai orang lain.

## Kunci dan petunjuk

**Ingat kembali.** 1: contoh: keterangan apa yang diukur, satuan tiap kolom, selang waktu (juga boleh: asal data dan judul kolom). 2: median hanya melihat nilai tengah setelah diurutkan, sedangkan rata-rata menjumlahkan semuanya sehingga satu nilai ekstrem ikut menggeser hasil. 3: nilai nyata potensiometer berbeda antar komponen dan rangkaian; tanpa pengukuran, ujung putaran tidak memberi keluaran penuh.

**Rencana proyek.** Contoh di atas satu jawaban yang mungkin; rencanamu boleh berbeda selama keenam bagian ada dan kriteria selesai dapat diuji. Uji batas yang baik: cahaya 799 (GELAP) dan 800 (REDUP), serta 2499 (REDUP) dan 2500 (TERANG).

**Daftar periksa.** Tidak ada kunci tunggal; guru memeriksa tiap butir dengan rubrik.

**Umpan balik sejawat.** Umpan balik yang baik menunjuk bagian tertentu, menyebut alasan, dan menawarkan langkah yang bisa dikerjakan. "Bagus" saja bukan umpan balik.

**Latihan bercampur.** 1: terurut 10, 380, 390, 400, 420; median 390; rata-rata 1600 / 5 = 320. Median lebih cocok karena satu pembacaan palsu (10) menyeret rata-rata ke bawah dan hampir menggeser kategori. 2: `90,28.1,2900,TERANG`.

**Ulang berjarak.** 1: sensor dibaca berkali-kali, disaring dengan median, lalu dicatat sebagai baris berformat (juga boleh menyebut ambil keputusan kategori sebelum mencetak). 2: contoh: lima nilai 7, 7, 7, 7, 7 menghasilkan median 7. 3: karena keputusan dari satu pembacaan palsu langsung salah; menyaring dulu membuat keputusan didasarkan pada nilai yang lebih dapat dipercaya.
