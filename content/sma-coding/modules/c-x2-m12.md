## Untuk siapa modul ini

Modul ini untuk murid kelas X jalur C (IoT dan robotika), minggu `C-X2-M12` silabus v1.3: mencatat data. Prasyarat: modul `c-x2-m11` (sensor jarak dan keputusan). Kamu juga memakai pembacaan suhu dari `c-x2-m2`, data bersih dari `c-x2-m3`, antrian dari `c-x2-m9`, dan `millis()` dari `c-x2-m7`.

Modul ini berstatus DRAF: karangan penyusun, belum ditinjau pemilik. Ia mendukung butir `E-BK-b` (proses komputasi manusia untuk data berkualitas) dan tidak dihitung memenuhi butir capaian pembelajaran mana pun. Keluaran minggu ini: berkas data sintetis atau lingkungan. Latihan silabusnya: catat suhu kelas 10 menit.

Minggu ini tidak bertanda (F): semua bagian pokok dikerjakan **tanpa papan**, dengan kertas dan "papan tiruan" di komputer yang membaca data karangan. Bila kamu mencatat dengan papan, ikuti aturan keselamatan modul sebelumnya: daya USB saja dan cabut kabel sebelum mengubah rangkaian. Nomor pin dan rumus suhu pada contoh hanya contoh `[belum terverifikasi]` untuk papanmu. Data yang dicatat hanya suhu ruangan: jangan menaruh nama, nama sekolah, atau kolom identitas lain di berkas.

## Contoh terselesaikan

Data yang tidak dicatat hilang, dan data yang dicatat tanpa keterangan sulit dipakai. Cara termudah menyimpan data dari papan ialah **teks berformat**: satu baris per pembacaan, kolom dipisah koma (CSV, *comma-separated values*). Papan mengirimnya lewat `Serial`, dan di komputer isinya disalin ke berkas teks berakhiran `.csv`, atau direkam dengan alat catat serial yang disiapkan gurumu `[belum terverifikasi]`.

Berkas yang dapat dipakai orang lain punya **kepala**: baris catatan yang menyebut apa yang diukur, satuannya, selang waktunya, dan asalnya (misalnya "karangan" untuk data sintetis), lalu satu baris judul kolom. Tanda `#` pada baris catatan bukan bagian standar CSV; program pembacamu harus tahu aturan itu. Alasan lain mencatat satuan: `28.1` tanpa satuan bisa Celsius atau Fahrenheit.

Program pencatat memakai `millis()` seperti di `c-x2-m7`. Ia menambah `mulai` dengan `SELANG_MS` tiap kali mencatat, bukan mengisinya dengan waktu sekarang, supaya selang rata walaupun satu putaran sedikit terlambat.

```arduino
// Arduino-C++ untuk ESP32. Diperiksa check:module-code terhadap header tiruan (sintaks dan tipe saja, bukan bukti perilaku papan).
const int PIN_SENSOR = 34;                // contoh; periksa papanmu
const unsigned long SELANG_MS = 30000;    // satu baris tiap 30 detik

unsigned long mulai = 0;

float suhuDariMentah(int mentah) {
  return mentah * 50.0f / 4095.0f;        // rumus contoh, bukan rumus sensor nyata
}

void cetakKepala() {
  Serial.println("# suhu ruang kelas");
  Serial.println("# satuan: waktu detik, suhu derajat Celsius; selang 30 detik");
  Serial.println("waktu_detik,suhu_c");
}

void cetakBaris(unsigned long detik, float suhu) {
  Serial.print(detik);
  Serial.print(',');
  Serial.println(suhu, 1);
}

void setup() {
  Serial.begin(115200);
  cetakKepala();
  mulai = millis();
}

void loop() {
  if (millis() - mulai >= SELANG_MS) {
    mulai += SELANG_MS;
    cetakBaris(millis() / 1000, suhuDariMentah(analogRead(PIN_SENSOR)));
  }
}
```

Setelah berkas ada, ia diperiksa dengan aturan yang tertulis. Papan tiruan di bawah membaca berkas karangan dan menerapkan tiga aturan: suhu terisi, suhu antara 15 dan 45 (rentang yang kamu tentukan sendiri untuk ruang kelasmu), dan waktu naik. Baris yang gagal tidak dihapus diam-diam; alasannya dicetak bersama nomor barisnya.

```cpp
// C++17 biasa, jalan di komputer. Diperiksa oleh check:module-code.
#include <cstdlib>
#include <iomanip>
#include <iostream>
#include <sstream>
#include <string>

const double SUHU_MIN = 15.0;   // rentang masuk akal untuk ruang kelas; tentukan sendiri
const double SUHU_MAKS = 45.0;

// Data karangan, bukan catatan siapa pun. Baris berawalan # adalah catatan kepala.
const char* BERKAS =
    "# suhu ruang kelas, data karangan\n"
    "# satuan: waktu detik, suhu derajat Celsius; selang 30 detik\n"
    "waktu_detik,suhu_c\n"
    "0,28.1\n"
    "30,28.2\n"
    "60,28.2\n"
    "90,\n"
    "120,28.4\n"
    "150,85.0\n"
    "180,28.5\n"
    "170,28.4\n";

int main() {
  std::istringstream masuk(BERKAS);
  std::string baris;
  int nomor = 0;
  int valid = 0;
  long waktuSebelumnya = -1;
  double jumlah = 0.0;
  double terkecil = 1e9;
  double terbesar = -1e9;

  std::cout << std::fixed << std::setprecision(1);
  while (std::getline(masuk, baris)) {
    nomor++;
    if (baris.empty() || baris[0] == '#' || baris == "waktu_detik,suhu_c") {
      continue;                                   // catatan kepala atau judul kolom
    }
    size_t koma = baris.find(',');
    if (koma == std::string::npos) {
      std::cout << "baris " << nomor << ": ditolak (tidak ada pemisah)\n";
      continue;
    }
    std::string teksWaktu = baris.substr(0, koma);
    std::string teksSuhu = baris.substr(koma + 1);
    long waktu = std::strtol(teksWaktu.c_str(), nullptr, 10);
    bool waktuNaik = waktu > waktuSebelumnya;
    waktuSebelumnya = waktu;
    if (teksSuhu.empty()) {
      std::cout << "baris " << nomor << ": ditolak (suhu kosong)\n";
      continue;
    }
    double suhu = std::strtod(teksSuhu.c_str(), nullptr);
    if (suhu < SUHU_MIN || suhu > SUHU_MAKS) {
      std::cout << "baris " << nomor << ": ditolak (suhu " << suhu << " di luar rentang)\n";
      continue;
    }
    if (!waktuNaik) {
      std::cout << "baris " << nomor << ": ditolak (waktu tidak naik)\n";
      continue;
    }
    valid++;
    jumlah += suhu;
    if (suhu < terkecil) terkecil = suhu;
    if (suhu > terbesar) terbesar = suhu;
  }
  std::cout << "valid: " << valid << "\n";
  std::cout << "terkecil " << terkecil << ", terbesar " << terbesar << ", rata-rata " << jumlah / valid << "\n";
}
```

Keluarannya (nomor baris dihitung dari baris pertama berkas, termasuk kepala):

```text
baris 7: ditolak (suhu kosong)
baris 9: ditolak (suhu 85.0 di luar rentang)
baris 11: ditolak (waktu tidak naik)
valid: 5
terkecil 28.1, terbesar 28.5, rata-rata 28.3
```

Tiga baris ditolak dari delapan baris data, dan tiap penolakan punya alasan yang bisa diperiksa orang lain. Menghapus diam-diam membuat orang lain mengira datamu mulus. Data karangan seperti ini berguna karena jawabannya kamu ketahui lebih dulu: bila program pemeriksa salah pada data yang kamu buat sendiri, ia pasti salah pada data nyata. Lolosnya pemeriksaan hanya berarti berkasnya sesuai aturan, bukan bahwa sensornya benar.

## Kunci dan petunjuk

**Ingat kembali.** 1: karena itu tanda gagal membaca, bukan hasil ukur; mengubahnya menjadi jarak membuat keputusan didasarkan pada angka palsu. 2: menolak data baru (yang tertua tetap aman, yang baru hilang) atau membuang yang tertua (yang terbaru tetap masuk, yang lama hilang); keduanya kehilangan data, dan pilihannya bergantung pada data mana yang lebih berharga. 3: membagi dengan nol tidak bermakna, dan jendela kosong berarti belum ada data; kembalikan tanda "tidak ada" dan jangan mengarang angka.

**Prediksi dulu.** 1: baris `60,` ditolak karena suhu kosong; baris `90,85.0` ditolak karena suhu di luar 15 sampai 45; baris `80,28.3` ditolak karena waktu 80 tidak lebih besar dari 90 (waktu baris sebelumnya). 2: dua baris lolos, yaitu `0,28.1` dan `30,28.2`. 3: supaya orang lain tahu apa yang dibuang dan mengapa, dan supaya kamu dapat memeriksa apakah aturannya terlalu ketat atau sensornya bermasalah.

**Contoh setengah jadi.** Isian berurutan: `detik`, `','` (tanda koma dalam kurung kutip tunggal, karena itu satu karakter), `suhu`. Program lengkapnya dikompilasi penulis dengan `Arduino.h` tiruan tanpa peringatan.

**Soal Parsons.** Urutan benar: c, f, d, a, e, b. `mulai += SELANG_MS` diletakkan sebelum pencetakan pada contoh ini; kedua urutan benar selama tetap di dalam `if`.

**Latihan.** 1: pseudocode: cetak kepala; catat awal; ULANG TERUS: BILA selisih waktu dari awal sudah 30 detik: majukan awal 30 detik; baca sensor; cetak detik dan suhu dipisah koma. 2: 600 / 30 = 20 selang, jadi 21 baris bila baris pertama pada detik 0 (0, 30, ..., 600), dan 20 baris bila pertama pada detik 30. 3: `jumlah / valid` menjadi 0 dibagi 0 sehingga hasilnya bukan angka (NaN); perbaikan: bila `valid` sama dengan 0, cetak "tidak ada data valid" dan lewati perhitungan. 4: tidak ada kunci tunggal; jawaban yang baik menyebut alasan tiap baris yang ditolak.

**Latihan bercampur.** 1: terurut 28,1; 28,2; 28,2; 28,4; 28,5; median 28,2 (nilai ketiga); rata-rata 28,3; keduanya dekat karena tidak ada lonjakan. 2: antrian menampung baris sementara selagi komputer sibuk; risikonya, bila antrian penuh sebelum komputer siap, baris hilang.

**Ulang berjarak.** 1: contoh: keterangan apa yang diukur, satuan tiap kolom, selang waktu (juga boleh: asal data dan judul kolom). 2: supaya pemakai data tahu apa yang dibuang dan dapat menilai apakah penolakannya wajar. 3: karena jawabannya kamu ketahui lebih dulu, sehingga kesalahan program tampak jelas tanpa bergantung pada sensor dan tanpa data pribadi.
