## Untuk siapa modul ini

Modul ini untuk murid kelas X jalur C (IoT dan robotika), minggu `C-X1-M11` silabus v1.3: masukan analog dan tipe data. Prasyarat: modul `c-x1-m10` (perulangan dan keluaran serial) dan gagasan byte dari `fondasi-representasi-data`.

Modul ini berstatus DRAF: karangan penyusun, belum ditinjau pemilik. Ia mendukung butir `E-BK-d` (solusi program sederhana dalam format pseudocode) dan tidak dihitung memenuhi butir capaian pembelajaran mana pun.

Ada dua cara mengerjakan. **Dengan papan (F):** kamu membaca potensiometer dan sensor cahaya bersama kelompokmu. **Tanpa papan:** kamu menelusuri program di kertas dan menjalankan "papan tiruan" di komputer yang memakai deretan nilai buatan. Semua bagian pokok bisa dikerjakan tanpa papan. Nomor pin, rentang nilai, dan arah nilai sensor pada papanmu `[belum terverifikasi]`: ikuti lembar guru dan ukur sendiri.

## Keselamatan perangkat

- Daya hanya dari kabel USB. Tidak ada listrik jaringan (220 V) dan tidak ada baterai pada modul ini.
- Cabut kabel USB sebelum memasang atau melepas kabel jumper, potensiometer, atau sensor cahaya.
- Sambungkan potensiometer dan sensor hanya ke pin daya dan pin masukan yang ditunjuk lembar guru. Jangan menyambung ke pin yang tidak kamu kenal; tegangan yang diterima pin papan terbatas dan batasnya `[belum terverifikasi]` untuk papanmu.
- Tidak ada solder. Papan percobaan dan kabel jumper sudah cukup.
- Papan atau komponen yang terasa panas, berbau, atau berasap: cabut kabel dan panggil guru.

## Tujuan

Setelah modul ini kamu dapat:

- membaca masukan analog dengan `analogRead` dan menjelaskan bahwa hasilnya bilangan bulat dalam rentang tertentu;
- memilih tipe data (`int`, `float`, `bool`, `uint8_t`) sesuai kebutuhan dan menjelaskan pembagian bilangan bulat;

## Contoh terselesaikan

Masukan analog adalah tegangan yang berubah halus, bukan hanya `HIGH` atau `LOW`. Papan mengubah tegangan itu menjadi bilangan bulat dengan pengubah analog ke digital (ADC). Pada dokumentasi Arduino-ESP32 (diakses 2026-11), `analogRead` bawaan memberi 12 bit, yaitu nilai 0 sampai 4095; papan Arduino lain memberi 10 bit, yaitu 0 sampai 1023. Periksa papanmu. Angka 4096 = 2 pangkat 12 adalah gagasan bit yang sama dengan satu byte berisi 256 nilai.

Tipe data menentukan apa yang bisa disimpan. `int` menyimpan bilangan bulat; `float` menyimpan bilangan berkoma; `bool` menyimpan benar atau salah; `uint8_t` menyimpan satu byte tanpa tanda (0 sampai 255). Dua jebakan: pembagian bilangan bulat membuang sisanya (7 / 2 menjadi 3, bukan 3,5), dan tipe yang terlalu kecil "berputar" kembali ke 0 saat melewati nilai terbesarnya.

```cpp
// C++17 biasa, jalan di komputer. Diperiksa oleh check:module-code.
#include <cstdint>
#include <iostream>

int main() {
  int a = 7;
  int b = 2;
  std::cout << "7 / 2 = " << a / b << "\n";
  std::cout << "7.0 / 2 = " << 7.0 / 2 << "\n";
  std::cout << "7 % 2 = " << a % b << "\n";
  std::uint8_t kecil = 250;
  kecil = kecil + 10;
  std::cout << "uint8_t 250 + 10 = " << static_cast<int>(kecil) << "\n";
}
```

Keluarannya:

```text
7 / 2 = 3
7.0 / 2 = 3.5
7 % 2 = 1
uint8_t 250 + 10 = 4
```

Ambang adalah nilai batas untuk memutuskan. Program berikut membaca sensor cahaya tiruan pada empat langkah, mencetak nilainya, mengubahnya ke persen dengan `map`, dan menyalakan lampu saat nilai di bawah ambang. `map(x, dariRendah, dariTinggi, keRendah, keTinggi)` memakai bilangan bulat dan membuang pecahan, serta tidak membatasi nilai yang keluar rentang (dokumentasi `map`). Papan tiruan di bawah menulis rumus yang sama dengan `map` karena `map` Arduino tidak ada di komputer.

```cpp
// C++17 biasa, jalan di komputer. Diperiksa oleh check:module-code.
#include <iostream>

// Papan tiruan: pengganti fungsi Arduino.
const int OUTPUT = 3;
const int HIGH = 1;
const int LOW = 0;

// Pembacaan sensor cahaya tiruan per langkah (nilai kecil = gelap pada contoh ini).
const int BACAAN[] = {4000, 2500, 1200, 300};
int langkah = 0;

struct SerialTiruan {
  void begin(long) {}
  template <typename T> void print(T nilai) { std::cout << nilai; }
  template <typename T> void println(T nilai) { std::cout << nilai << "\n"; }
};
SerialTiruan Serial;

void pinMode(int, int) {}
int analogRead(int) { return BACAAN[langkah]; }
void digitalWrite(int, int nilai) {
  std::cout << (nilai == HIGH ? "  -> lampu nyala" : "  -> lampu padam") << "\n";
}
long map(long x, long dariRendah, long dariTinggi, long keRendah, long keTinggi) {
  return (x - dariRendah) * (keTinggi - keRendah) / (dariTinggi - dariRendah) + keRendah;
}

// Program Arduino dengan logika yang sama.
const int PIN_SENSOR = 34;
const int PIN_LED = 2;
const int AMBANG = 2000;

void setup() {
  Serial.begin(115200);
  pinMode(PIN_LED, OUTPUT);
}

void loop() {
  int nilai = analogRead(PIN_SENSOR);
  long persen = map(nilai, 0, 4095, 0, 100);
  Serial.print("nilai=");
  Serial.print(nilai);
  Serial.print(" persen=");
  Serial.println(persen);
  if (nilai < AMBANG) {
    digitalWrite(PIN_LED, HIGH);
  } else {
    digitalWrite(PIN_LED, LOW);
  }
}

int main() {
  setup();
  for (langkah = 0; langkah < 4; langkah++) loop();
}
```

Keluarannya:

```text
nilai=4000 persen=97
  -> lampu padam
nilai=2500 persen=61
  -> lampu padam
nilai=1200 persen=29
  -> lampu nyala
nilai=300 persen=7
  -> lampu nyala
```

Hitung satu baris untuk memeriksa: 4000 x 100 / 4095 = 97,68; bilangan bulat memotong menjadi 97. Arah nilai (kecil berarti gelap atau sebaliknya) dan angka ambang bergantung pada rangkaian dan sensor yang kamu pakai, jadi ambang harus ditentukan dari pengukuran rangkaianmu sendiri.

## Kesalahan umum

- **Memakai 1023 padahal papanmu 4095.** Rentang `analogRead` berbeda antar papan; periksa papanmu sebelum menulis ambang atau `map`.
- **Pembagian bilangan bulat.** `(a + b) / 2` dengan dua `int` membuang sisanya walau hasilnya disimpan ke `float`.
- **Mengira `map` membatasi hasil.** `map` tidak memotong nilai di luar rentang; hasilnya bisa lebih besar atau lebih kecil dari rentang tujuan.
- **Arah ambang tertukar.** `<` dan `>` terbalik membuat lampu menyala saat terang. Ukur dulu arah nilai sensormu.
- **Mengira nilai sensor tetap.** Nilai bisa berubah sedikit walau cahaya tetap. Cara menanganinya dibahas pada semester berikutnya.

## Kunci dan petunjuk

**Ingat kembali.** 1: lima kali; nilai terakhir 4 (nilai 0, 1, 2, 3, 4). 2: contoh sensor cahaya (masukan) dan LED atau buzzer (keluaran); sensor di sisi Masukan, aktuator di sisi Keluaran, mikrokontroler di Proses. 3: 256 nilai (0 sampai 255). 4: karena syaratnya tidak pernah menjadi salah bila isi perulangan tidak mengubah apa yang diperiksa.

**Prediksi dulu.** 1: menyala (500 < 2000). 2: padam. 3: padam, karena 2000 tidak kurang dari 2000. 4: saat gelap, dengan anggapan nilai kecil berarti gelap.

**Contoh setengah jadi.** Isian berurutan: `4095`, `LOW`, `jeda_ms`. Potensiometer di ujung terendah memberi jeda 100 ms; di ujung tertinggi 1000 ms.

**Soal Parsons.** Urutan benar: b, a, c, e, f, g, h, d. Baris (h) menutup `else`; baris (d) menutup `loop`.

**Latihan.** 1: pseudocode: ULANG TERUS: baca nilai; BILA nilai < 1000 ATAU nilai > 3000, nyalakan LED; JIKA TIDAK padamkan LED. Kondisi: `if (nilai < 1000 || nilai > 3000)`. 2: 1000 x 100 / 4095 = 24,42 menjadi 24; 2048 x 100 / 4095 = 50,01 menjadi 50. 3: (a) `int`; (b) `float`; (c) `bool`; (d) `uint8_t`. Hasil `(7 + 2) / 2` adalah 4 (pembagian bilangan bulat dahulu, baru disimpan ke `float`), bukan 4,5. 4: contoh catatan: terang 3500, tertutup 400; ambang di tengah, yaitu sekitar 1950 (3500 + 400 = 3900, dibagi 2). Angkamu akan berbeda.

**Latihan bercampur.** 1: 4096 nilai (2 pangkat 12); terbesar 4095. Satu byte hanya 256 nilai; 4096 = 16 kali lebih banyak. 2: `if (nilai < AMBANG && digitalRead(PIN_TOMBOL) == LOW)`. 3: satu putaran 4 x 100 = 400 ms; 1000 / 400 = 2,5 putaran per detik.

**Ulang berjarak.** 1: 3 dan 3,5; pembagian dua `int` membuang sisa, sedangkan salah satu operand berkoma membuat hasil berkoma. 2: 3000 x 100 / 4095 = 73,26 menjadi 73. 3: karena arah dan besar nilai bergantung pada sensor dan rangkaianmu; ambang tebakan bisa membuat lampu selalu menyala atau tidak pernah menyala.
