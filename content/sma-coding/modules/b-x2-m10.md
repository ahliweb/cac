Modul ini karangan penyusun dan disetujui pemilik program pada 2026-11-20 (keputusan lewat dialog; catatan tinjauan menjadi tindak lanjut revisi). Butir `E-BK-b` (proses komputasi manusia untuk data berkualitas) dipetakan silabus sebagai dipenuhi jalur ini; pemenuhan butir mengikuti pemetaan silabus, bukan status modul.

Contoh dijalankan penyusun dengan Bun 1.4.4 per 2026-11. Tugas baca-dan-prediksi ditandai `AI: tanpa AI`; selain itu AI generatif boleh dipakai dengan etika dan dicatat, tanpa data pribadi, kata sandi, atau tugas bernilai pada permintaanmu. Semua data di modul ini **karangan**: nama dan nilai tidak merujuk orang nyata, dan kamu tidak boleh menaruh data temanmu di latihan.

## Contoh terselesaikan

Keluaran skrip prediksi:

```text
90 0 0 NaN
true false
true false
3 [ 1, 2, 3 ]
```

`Number("")` dan `Number(null)` sama-sama 0: nilai yang kosong bisa menyamar menjadi nol. `"90" > "100"` benar karena teks dibandingkan huruf demi huruf. Menurut MDN, `Number.isNaN` tidak mengubah argumennya, sehingga `Number.isNaN("9o")` salah; periksa hasil `Number(...)`, bukan teks aslinya. Dan `Set` membuang duplikat.

Data berkualitas berarti **cocok untuk dipakai**. Empat pertanyaan sederhana: apakah lengkap, apakah tipenya benar, apakah masuk akal (rentang), dan apakah ada duplikat. Dua pekerjaan berbeda: **memvalidasi** (menemukan baris yang bermasalah) dan **merapikan** (memperbaiki yang pasti, seperti spasi berlebih dan huruf kapital). Skrip berikut membuat tabel JSON karangan berisi tujuh baris bermasalah, menuliskannya ke `nilai.json`, membacanya kembali dengan `Bun.file`, lalu merapikan dan memvalidasi.

```js
// kualitas.js
const mentah = [
  { id: 1, nama: "Dewi-contoh", kelas: "X-1", nilai: 85 },
  { id: 2, nama: "  budi-contoh", kelas: "x-1", nilai: "90" },
  { id: 3, nama: "Citra-contoh", kelas: "X-2", nilai: 105 },
  { id: 2, nama: "budi-contoh", kelas: "X-1", nilai: 90 },
  { id: 5, nama: "", kelas: "X-2", nilai: 70 },
  { id: 6, nama: "Eka-contoh", kelas: "X-2", nilai: null },
  { id: 7, nama: "Fajar-contoh", kelas: "X-1", nilai: "9o" },
];

await Bun.write("nilai.json", JSON.stringify(mentah, null, 2));
const baris = await Bun.file("nilai.json").json();

function rapikan(b) {
  let nilai = null;
  if (b.nilai !== null && b.nilai !== "") {
    nilai = Number(b.nilai);
  }
  return {
    id: b.id,
    nama: String(b.nama).trim(),
    kelas: String(b.kelas).trim().toUpperCase(),
    nilai: nilai,
  };
}

function masalah(b) {
  const daftar = [];
  if (b.nama === "") {
    daftar.push("nama kosong");
  }
  if (b.nilai === null || Number.isNaN(b.nilai)) {
    daftar.push("nilai bukan angka");
  } else if (b.nilai < 0 || b.nilai > 100) {
    daftar.push("nilai di luar 0 sampai 100");
  }
  return daftar;
}

const bersih = [];
const dilihat = new Map();
for (const mentahan of baris) {
  const b = rapikan(mentahan);
  const lama = dilihat.get(b.id);
  if (lama !== undefined) {
    if (JSON.stringify(lama) === JSON.stringify(b)) {
      console.log("id", b.id, "duplikat persis, dibuang");
    } else {
      console.log("id", b.id, "ganda tetapi isinya beda: periksa manual");
    }
    continue;
  }
  dilihat.set(b.id, b);
  const m = masalah(b);
  if (m.length > 0) {
    console.log("id", b.id, "ditolak:", m.join(", "));
  } else {
    bersih.push(b);
  }
}
console.log("bersih:", bersih.length, "dari", baris.length);
console.log(bersih.map((b) => b.id + " " + b.nama + " " + b.kelas + " " + b.nilai));
```

Keluarannya:

```text
id 3 ditolak: nilai di luar 0 sampai 100
id 2 duplikat persis, dibuang
id 5 ditolak: nama kosong
id 6 ditolak: nilai bukan angka
id 7 ditolak: nilai bukan angka
bersih: 2 dari 7
[ "1 Dewi-contoh X-1 85", "2 budi-contoh X-1 90" ]
```

Perhatikan pembagian kerjanya. Baris id 2 yang pertama dirapikan otomatis (spasi dibuang, `x-1` menjadi `X-1`, `"90"` menjadi 90), sehingga duplikatnya persis sama dan dibuang. Baris id 3 (105) dan id 7 (`"9o"`) dilanggar aturan, tetapi komputer tidak tahu nilai yang benar; yang bisa dilakukan hanya menandainya untuk **manusia** yang mengecek lembar asli. Kaidah praktis: perbaiki otomatis hanya bila jawabannya pasti, selebihnya tandai.

Cara lain melibatkan manusia adalah **memasukkan data dua kali**: dua petugas mengetik lembar yang sama sendiri-sendiri, komputer membandingkannya, dan hanya perbedaan yang dicek manusia.

```js
// masukan-ganda.js
const petugasA = [
  { id: 1, nilai: 85 },
  { id: 2, nilai: 90 },
  { id: 3, nilai: 75 },
];
const petugasB = [
  { id: 1, nilai: 85 },
  { id: 2, nilai: 9 },
  { id: 3, nilai: 75 },
];

for (let i = 0; i < petugasA.length; i++) {
  if (petugasA[i].nilai !== petugasB[i].nilai) {
    console.log("id", petugasA[i].id + ": A mengetik", petugasA[i].nilai + ", B mengetik", petugasB[i].nilai, "- cek lembar asli");
  }
}
```

Keluarannya:

```text
id 2: A mengetik 90, B mengetik 9 - cek lembar asli
```

Salah ketik yang sama oleh dua orang jarang terjadi, jadi perbedaan hampir pasti salah satu mengetik keliru; tetapi bila keduanya salah dengan cara yang sama, cara ini tidak menangkapnya.

## Kesalahan umum

- **Mengira `Number("")` galat.** Hasilnya 0, sama dengan `Number(null)`. Tangani nilai kosong lebih dulu, seperti `rapikan` di atas.
- **Memeriksa `Number.isNaN` pada teks.** `Number.isNaN("9o")` salah karena teks bukan `NaN`. Periksa hasil `Number("9o")`.
- **Memperbaiki nilai yang tidak pasti.** Mengganti 105 dengan 100 menghilangkan bukti kesalahan; tandai, jangan tebak.
- **Duplikat dicari sebelum dirapikan.** `"budi-contoh"` dengan spasi di depan tidak sama dengan `"budi-contoh"`; rapikan dulu, baru bandingkan.
- **Mengira data yang lolos validasi pasti benar.** Nilai 85 yang seharusnya 58 tetap lolos. Validasi menangkap yang mustahil, bukan semua yang salah; itu gunanya masukan ganda dan pengecekan ke sumber.
- **Membaca JSON yang rusak tanpa `try`.** `JSON.parse('[{"id": 1,}]')` melempar `SyntaxError` (koma di akhir tidak sah dalam JSON, menurut MDN); bungkus dengan `try`/`catch`.

// id-ganda.js
function idGanda(daftar) {
  const dilihat = new Set();
  const ganda = new Set();
  for (const b of daftar) {
    if (dilihat.has(b.id)) {
      ganda.add(b.id);
    }
    dilihat.add(b.id);
  }
  return [...ganda];
}

// bersih-urut-cari.js
const bersih = [
  { id: 7, nama: "Gita-contoh", nilai: 72 },
  { id: 2, nama: "Budi-contoh", nilai: 90 },
  { id: 5, nama: "Eka-contoh", nilai: 85 },
  { id: 1, nama: "Dewi-contoh", nilai: 85 },
];

const urutNilai = [...bersih].sort((a, b) => b.nilai - a.nilai);
console.log(urutNilai.map((b) => b.nilai + " " + b.nama));

const urutId = [...bersih].sort((a, b) => a.id - b.id);
function cariId(terurut, id) {
  let kiri = 0;
  let kanan = terurut.length - 1;
  while (kiri <= kanan) {
    const tengah = Math.floor((kiri + kanan) / 2);
    if (terurut[tengah].id === id) {
      return tengah;
    } else if (terurut[tengah].id < id) {
      kiri = tengah + 1;
    } else {
      kanan = tengah - 1;
    }
  }
  return -1;
}
console.log(cariId(urutId, 5), cariId(urutId, 6));
console.log(JSON.stringify(urutId[0]));
