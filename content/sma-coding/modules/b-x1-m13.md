## Untuk siapa modul ini

Modul ini berstatus DRAF: karangan penyusun, belum ditinjau pemilik. Minggu ini tidak dipetakan silabus ke butir capaian pembelajaran mana pun. Penilaian proyek memakai rubrik dari gurumu; modul ini tidak menilai.

## Rencana proyek

Sebelum mengetik kode, tulis rencanamu dalam satu halaman dengan enam bagian: tujuan, diagram I-P-O, pseudocode, kriteria selesai, daftar uji, dan prediksi hasil. Berikut contoh terselesaikan.

| Bagian | Isi contoh |
| --- | --- |
| Tujuan | Komputer memilih angka rahasia 1 sampai 100; pemain menebak maksimal 7 kali dan mendapat petunjuk "terlalu kecil" atau "terlalu besar". |
| Masukan | Tebakan pemain (teks dari `prompt()`); angka rahasia dari `Math.random()`. |
| Proses | Ubah tebakan menjadi angka, periksa sahnya, bandingkan dengan angka rahasia. |
| Keluaran | Petunjuk tiap tebakan dan pesan akhir. |
| Kriteria selesai | Tebakan benar mengakhiri permainan; setelah 7 tebakan sah permainan berakhir; masukan yang bukan bilangan bulat 1 sampai 100 ditolak tanpa mengurangi kesempatan. |
| Prediksi | Angka rahasia 37 dengan tebakan 50, 25, 37: tiga petunjuk lalu "Benar dalam 3 percobaan!". |

Pseudocode:

```text
RAHASIA = angka acak 1 sampai 100
PERCOBAAN = 0
ULANG selama PERCOBAAN < 7 dan belum menang:
  TEBAKAN = tanya pemain
  JIKA masukan habis: berhenti
  JIKA TEBAKAN bukan bilangan bulat 1 sampai 100:
    cetak pesan, ulangi tanpa menambah PERCOBAAN
  PERCOBAAN = PERCOBAAN + 1
  cetak "terlalu kecil", "terlalu besar", atau "tepat"
CETAK hasil akhir
```

Programnya. `acak` dan `nilai` adalah fungsi kecil yang bisa diuji sendiri. Argumen opsional pada baris `rahasia` hanya untuk menguji: bila kamu memberi `37`, angka rahasianya 37; bila kosong, angkanya acak (`Math.floor` membulatkan ke bawah, `Math.random()` memberi pecahan dari 0 sampai kurang dari 1).

```js
// tebak.js
function acak(min, maks) {
  return Math.floor(Math.random() * (maks - min + 1)) + min;
}

function nilai(rahasia, tebakan) {
  if (tebakan < rahasia) {
    return "terlalu kecil";
  }
  if (tebakan > rahasia) {
    return "terlalu besar";
  }
  return "tepat";
}

const MAKS_PERCOBAAN = 7;
// Argumen pertama (opsional) menetapkan angka rahasia untuk menguji; tanpa argumen angkanya acak.
const rahasia = Bun.argv[2] ? Number(Bun.argv[2]) : acak(1, 100);

console.log("Tebak angka 1 sampai 100. Kamu punya", MAKS_PERCOBAAN, "kesempatan.");

let percobaan = 0;
let menang = false;
while (percobaan < MAKS_PERCOBAAN && !menang) {
  const jawaban = prompt("Tebakanmu?");
  if (jawaban === null) {
    break;
  }
  const tebakan = Number(jawaban);
  if (!Number.isInteger(tebakan) || tebakan < 1 || tebakan > 100) {
    console.log("Masukkan bilangan bulat 1 sampai 100.");
    continue;
  }
  percobaan = percobaan + 1;
  const hasil = nilai(rahasia, tebakan);
  console.log(tebakan, hasil);
  if (hasil === "tepat") {
    menang = true;
  }
}

if (menang) {
  console.log("Benar dalam", percobaan, "percobaan!");
} else {
  console.log("Permainan selesai. Angkanya:", rahasia);
}
```

Daftar uji dijalankan lebih dulu pada fungsi `nilai`, termasuk nilai di batas:

```js

console.log(nilai(37, 10));
console.log(nilai(37, 37));
console.log(nilai(37, 90));
console.log(nilai(1, 1));
console.log(nilai(100, 99));
```

```text

tepat
terlalu besar
tepat

```

```sh
printf '50\n25\n37\n' | bun run tebak.js 37
```

```text
Tebakanmu? 50 terlalu besar
Tebakanmu? 25 terlalu kecil
Tebakanmu? 37 tepat
Benar dalam 3 percobaan!
```

## Kesalahan umum

- **Tebakan dibandingkan sebagai teks.** Tanpa `Number(...)`, `"100" < "20"` bernilai `true` karena teks dibandingkan huruf demi huruf, sedangkan `100 < 20` bernilai `false`.
- **Perulangan macet saat masukan habis.** Bila `prompt()` kehabisan masukan, ia mengembalikan `null`; `Number(null)` adalah 0, yang ditolak sebagai tebakan tidak sah, lalu perulangan bertanya lagi dan tidak pernah selesai. Pengecekan `jawaban === null` lalu `break` mencegahnya. Pada uji dengan `printf`, ini muncul bila jawaban yang dikirim terlalu sedikit.
- **Menghitung tebakan tidak sah.** Bila `percobaan = percobaan + 1` ditaruh sebelum pengecekan sah, masukan yang salah mengurangi kesempatan. Taruh setelah pengecekan.
- **Angka rahasia pecahan.** `Math.random() * 100` tanpa `Math.floor` menghasilkan pecahan seperti 37,4 yang tidak pernah sama dengan bilangan bulat tebakan.
- **Rentang bergeser satu.** `Math.floor(Math.random() * 100)` memberi 0 sampai 99, bukan 1 sampai 100.

## Kunci dan petunjuk

**Ingat kembali.** 1: `undefined`. 2: `false`, karena beda tipe (angka dan teks) dan `===` tidak mengubah tipe. 3: karena data pribadi tidak boleh tersebar tanpa perlu; nama karangan tidak mengenali siapa pun.

**Rencana proyek.** Tidak ada satu jawaban benar; rencana yang baik punya kriteria selesai yang bisa diuji (misalnya "setelah 7 tebakan sah permainan berakhir") dan prediksi yang spesifik. Bila hasil uji berbeda dari prediksi, catat mana yang salah: rencanamu, atau kodenya.

**Daftar periksa.** Periksa tiap butir dengan masukan nyata. Contoh uji penolakan, dengan angka rahasia 37:

```sh
printf '50\nabc\n150\n10\n20\n30\n40\n60\n70\n80\n' | bun run tebak.js 37
```

```text
Tebak angka 1 sampai 100. Kamu punya 7 kesempatan.
Tebakanmu? 50 terlalu besar
Tebakanmu? Masukkan bilangan bulat 1 sampai 100.
Tebakanmu? Masukkan bilangan bulat 1 sampai 100.
Tebakanmu? 10 terlalu kecil
Tebakanmu? 20 terlalu kecil
Tebakanmu? 30 terlalu kecil
Tebakanmu? 40 terlalu besar
Tebakanmu? 60 terlalu besar
Tebakanmu? 70 terlalu besar
Permainan selesai. Angkanya: 37
```

Perhatikan: `abc` dan `150` ditolak tanpa mengurangi kesempatan, dan permainan berakhir setelah tujuh tebakan sah (50, 10, 20, 30, 40, 60, 70). Masukan terakhir (80) tidak pernah dibaca.

**Umpan balik sejawat.** Contoh: "Sudah baik: fungsi `nilai` mudah dibaca. Perlu diperbaiki: masukan `3.5` diterima sebagai tebakan di skrip temanku dan menghabiskan kesempatan. Langkah berikutnya: tambahkan `Number.isInteger`."

**Latihan bercampur.** 1: kunci yang dijalankan:

```js
// strategi.js
function banyakTebakan(rahasia) {
  let bawah = 1;
  let atas = 100;
  let tebakan = 0;
  while (true) {
    const tengah = Math.floor((bawah + atas) / 2);
    tebakan = tebakan + 1;
    if (tengah === rahasia) {
      return tebakan;
    }
    if (tengah < rahasia) {
      bawah = tengah + 1;
    } else {
      atas = tengah - 1;
    }
  }
}

let terbanyak = 0;
for (let rahasia = 1; rahasia <= 100; rahasia++) {
  const t = banyakTebakan(rahasia);
  if (t > terbanyak) {
    terbanyak = t;
  }
}
console.log("Tebakan terbanyak untuk 1 sampai 100:", terbanyak);
console.log("Untuk 37:", banyakTebakan(37));
```

Keluarannya:

```text
Tebakan terbanyak untuk 1 sampai 100: 7
Untuk 37: 3
```

Tiap tebakan tengah-tengah membuang separuh kemungkinan. Sebelum tebakan pertama sampai ketujuh, kemungkinan yang tersisa paling banyak 100, 50, 25, 12, 6, 3, dan 1 (dibulatkan ke bawah), jadi tebakan ketujuh pasti cukup. Gagasan ini dipakai lagi di pencarian biner (`b-x2-m8`). 2: contoh `function dalamRentang(x, min, maks) { return Number.isInteger(x) && x >= min && x <= maks; }`. 3: contoh: "Tambah fungsi nilai", "Tambah perulangan dan batas tujuh tebakan", "Tolak masukan tidak sah"; `git log --oneline` menampilkan tiga baris atau lebih.

**Ulang berjarak.** 1: karena kesalahan satu-lebih (`<` tertukar `<=`) hanya tampak di batas. 2: ubah dengan `Number(...)`. 3: 7 tebakan.
