Minggu ini tidak bertanda (F): semua bagian pokok dikerjakan **tanpa papan**, dengan kertas dan "papan tiruan" di komputer. ## Tujuan

Setelah modul ini kamu dapat:

- mencari indeks pertama sebuah nilai yang memenuhi syarat dengan pencarian linear;
- mengurutkan larik kecil dengan pengurutan sisip;
- menghitung median dari pembacaan ganjil tanpa merusak larik asli;
- menjelaskan mengapa median lebih tahan terhadap lonjakan tunggal daripada rata-rata;
- menulis program median (keluaran minggu ini).

## Contoh terselesaikan

Rata-rata bergerak (`c-x2-m4`) meredam derau tetapi tertarik oleh satu lonjakan ekstrem. Median tidak: ia hanya melihat posisi tengah, sehingga satu nilai ganjil, sekecil atau sebesar apa pun, tidak menggeser hasil. Itulah alasan median dipakai pada data sensor yang kadang mengirim pembacaan palsu.

Untuk mendapat median, data perlu diurutkan. **Pengurutan sisip** bekerja seperti menyusun kartu di tangan: ambil elemen berikutnya, geser elemen yang lebih besar satu tempat ke kanan, lalu sisipkan elemen itu di celah. Setelah selesai, untuk jumlah ganjil `n`, median berada di indeks `n / 2` (bilangan bulat). Untuk jumlah genap, median adalah rata-rata dua nilai tengah; modul ini memakai jumlah ganjil supaya sederhana.

Dua kehati-hatian. Pertama, pengurutan dilakukan pada **salinan**, karena urutan asli (menurut waktu) dibutuhkan untuk hal lain, seperti grafik dan rata-rata bergerak. Kedua, **pencarian linear** adalah cara paling sederhana mencari: periksa elemen satu per satu dari indeks 0 sampai ketemu, dan kembalikan -1 bila tidak ada. Pada larik kecil seperti ini cukup.

Program berikut mengumpulkan tujuh pembacaan, satu per 50 ms tanpa `delay()`, lalu mencetak mediannya.

```arduino
// Arduino-C++ untuk ESP32. Diperiksa check:module-code terhadap header tiruan (sintaks dan tipe saja, bukan bukti perilaku papan).
const int PIN_SENSOR = 34;               // contoh; periksa papanmu
const int N = 7;
const unsigned long SELANG_MS = 50;

int jendela[N];
int terisi = 0;
unsigned long mulai = 0;

void urutkan(int a[], int n) {
  for (int i = 1; i < n; i++) {
    int nilai = a[i];
    int j = i - 1;
    while (j >= 0 && a[j] > nilai) {
      a[j + 1] = a[j];
      j--;
    }
    a[j + 1] = nilai;
  }
}

int median(const int data[], int n) {
  int salinan[N];
  for (int i = 0; i < n; i++) {
    salinan[i] = data[i];
  }
  urutkan(salinan, n);
  return salinan[n / 2];
}

void setup() {
  Serial.begin(115200);
  mulai = millis();
}

void loop() {
  if (millis() - mulai >= SELANG_MS) {
    mulai = millis();
    jendela[terisi] = analogRead(PIN_SENSOR);
    terisi++;
    if (terisi == N) {
      Serial.println(median(jendela, N));
      terisi = 0;
    }
  }
}
```

Papan tiruan di bawah memakai fungsi yang sama dengan data karangan, ditambah rata-rata dan pencarian linear untuk perbandingan. Nilai 95 sengaja menjadi lonjakan palsu.

```cpp
// C++17 biasa, jalan di komputer. Diperiksa oleh check:module-code.
#include <iomanip>
#include <iostream>

const int N = 7;

// Urutkan larik dari kecil ke besar: sisipkan tiap elemen ke tempat yang benar.
void urutkan(int a[], int n) {
  for (int i = 1; i < n; i++) {
    int nilai = a[i];
    int j = i - 1;
    while (j >= 0 && a[j] > nilai) {
      a[j + 1] = a[j];
      j--;
    }
    a[j + 1] = nilai;
  }
}

// Median n pembacaan (n ganjil). Larik asli tidak berubah: yang diurutkan salinannya.
int median(const int data[], int n) {
  int salinan[N];
  for (int i = 0; i < n; i++) {
    salinan[i] = data[i];
  }
  urutkan(salinan, n);
  return salinan[n / 2];
}

float rataRata(const int data[], int n) {
  int jumlah = 0;
  for (int i = 0; i < n; i++) {
    jumlah += data[i];
  }
  return static_cast<float>(jumlah) / n;
}

// Pencarian linear: indeks pertama yang nilainya >= ambang, atau -1 bila tidak ada.
int cariPertama(const int data[], int n, int ambang) {
  for (int i = 0; i < n; i++) {
    if (data[i] >= ambang) {
      return i;
    }
  }
  return -1;
}

int main() {
  const int DATA[N] = {21, 22, 95, 21, 23, 22, 20};   // data karangan; 95 lonjakan palsu
  std::cout << std::fixed << std::setprecision(1);
  std::cout << "median " << median(DATA, N) << "\n";
  std::cout << "rata-rata " << rataRata(DATA, N) << "\n";
  std::cout << "indeks pertama >= 90: " << cariPertama(DATA, N, 90) << "\n";
  std::cout << "indeks pertama >= 100: " << cariPertama(DATA, N, 100) << "\n";

  int salinan[N];
  for (int i = 0; i < N; i++) {
    salinan[i] = DATA[i];
  }
  urutkan(salinan, N);
  std::cout << "terurut:";
  for (int x : salinan) {
    std::cout << " " << x;
  }
  std::cout << "\n";
}
```

Keluarannya:

```text
median 22
rata-rata 32.0
indeks pertama >= 90: 2
indeks pertama >= 100: -1
terurut: 20 21 21 22 22 23 95
```

Satu lonjakan menggeser rata-rata dari sekitar 21 ke 32, tetapi median tetap 22. Median bukan obat segalanya: bila setengah lebih pembacaan palsu, median pun ikut palsu, dan ia tidak menggantikan memeriksa sensor sendiri.

## Kesalahan umum

- **Mengurutkan larik asli.** Urutan menurut waktu hilang; grafik dan rata-rata bergerak ikut rusak.
- **Mengambil `data[n / 2]` sebelum diurutkan.** Itu hanya elemen di tengah posisi, bukan nilai tengah.
- **Memakai jumlah genap tanpa menyesuaikan.** Dengan jumlah genap tidak ada satu nilai tengah; median berupa rata-rata dua nilai tengah.
- **Mengira median selalu benar.** Bila lebih dari separuh pembacaan palsu, median ikut palsu.
- **Mengira pencarian linear lambat dan harus dihindari.** Untuk larik kecil ia sederhana dan cukup; yang perlu dihindari adalah memakainya tanpa memikirkan -1 (tidak ketemu).

**Latihan.** 1: pseudocode: salin tujuh pembacaan; urutkan salinan; median adalah elemen indeks 3 dari salinan; untuk tiap pembacaan asli: bila nilai mutlak selisih dari median lebih dari 10, tandai. 2: terurut 11, 12, 12, 13, 14, 15, 40; median 13; rata-rata 117 / 7 = 16,7. 3: urutan menurut waktu hilang, sehingga garis grafik tidak lagi menunjukkan kejadian menurut waktu. 4: tidak ada kunci tunggal; median kelompok yang digoyang seharusnya bergeser lebih sedikit daripada rata-ratanya, kecuali separuh lebih pembacaan memang kacau.
