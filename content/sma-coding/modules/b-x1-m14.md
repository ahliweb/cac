## Kunci dan petunjuk

**Ingat kembali.** 1: masukan (papan ketik), proses (CPU), keluaran (layar). 2: 8 + 4 + 1 = 13 desimal = D heksadesimal. 3: contoh jawaban: panjang, tidak mudah ditebak (misalnya frasa acak), unik untuk tiap akun. 4: `break` menghentikan seluruh perulangan; `continue` hanya melewati sisa putaran itu. 5: kesalahan satu-lebih (`<` tertukar `<=`) paling sering tampak di batas.

**Latihan bercampur.**

1: pseudocode: `JIKA BELANJA >= 100000 MAKA PERSEN = 10; JIKA TIDAK JIKA BELANJA >= 50000 MAKA PERSEN = 5; JIKA TIDAK PERSEN = 0`; `TOTAL = BELANJA - BELANJA * PERSEN / 100`. Contoh skrip yang dijalankan:

```js
// diskon.js
function persenDiskon(belanja) {
  if (belanja >= 100000) {
    return 10;
  } else if (belanja >= 50000) {
    return 5;
  }
  return 0;
}

function totalBayar(belanja) {
  return belanja - belanja * persenDiskon(belanja) / 100;
}

const belanja = Number(Bun.argv[2]);
console.log("Belanja:", belanja);
console.log("Diskon:", persenDiskon(belanja), "persen");
console.log("Total bayar:", totalBayar(belanja));
```

```sh
bun run diskon.js 50000
```

```text
Belanja: 50000
Diskon: 5 persen
Total bayar: 47500
```

Untuk 120000 total bayarnya 108000 (diskon 10 persen), untuk 49999 total bayarnya 49999 (batas bawah tepat di bawah 50000), dan untuk 20000 total bayarnya 20000. Rubrik soal 1, empat hal: ketepatan (hasil untuk empat uji benar, termasuk batas 50000 dan 49999), keterbacaan (nama fungsi dan variabel jelas), pengujian (keempat masukan diuji dan hasilnya dicatat), dan justifikasi (alasan memilih urutan syarat). Skala per hal: sudah, sebagian, belum.

2: untuk `f(7)`, `i` yang bukan kelipatan 3 adalah 1, 2, 4, 5, dan 7, sehingga hasilnya 1 + 2 + 4 + 5 + 7 = 19; untuk `f(2)` hasilnya 1 + 2 = 3. Tercetak `19` lalu `3`. Kondisi `i % 3 === 0` benar dua kali pada `f(7)`, yaitu untuk 3 dan 6.

3: tercetak `82 16 2 32 boolean false`. `"8" + 2` menyambung teks sehingga menjadi `"82"`; `"8" * 2` mengubah teks menjadi angka dulu sehingga menjadi 16.

4: sebelum diperbaiki tercetak `undefined 0`. Galat pertama: `a + b / 2;` tidak ada `return`, jadi fungsi mengembalikan `undefined`. Galat kedua: urutan operasi, `b / 2` dihitung lebih dulu; seharusnya `(a + b) / 2`. Galat ketiga: `let total = 0;` di dalam `for` membuat variabel baru yang menutupi `total` di luar, sehingga `total` di luar tetap 0; hapus `let` di dalam. Setelah diperbaiki, `console.log(rata(4, 8), total)` mencetak `6 6`:

```js
// galat-kunci.js
function rata(a, b) {
  return (a + b) / 2;
}
let total = 0;
for (let i = 1; i <= 3; i++) {
  total = total + i;
}
console.log(rata(4, 8), total);
```

```sh
bun run galat-kunci.js
```

```text
6 6
```

5: contoh perintah: `git init -b main`, `git config user.name "nama-yang-ditentukan-guru"`, `git add diskon.js`, `git commit -m "Skrip diskon: fungsi dan uji"`, ubah satu baris, `git add diskon.js`, `git commit -m "Ubah pesan keluaran"`, lalu `git log --oneline` menampilkan dua baris. Periksa: nama commit menjelaskan isi, tidak ada data pribadi, dan `git add` dilakukan sebelum `git commit`.
