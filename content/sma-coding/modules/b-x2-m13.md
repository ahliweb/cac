## Rencana proyek

Tulis rencanamu dalam satu halaman sebelum mengetik kode: tujuan, I-P-O, pseudocode, kriteria selesai, daftar uji, dan prediksi. Contoh terselesaikan untuk bubble sort:

| Bagian | Isi contoh |
| --- | --- |
| Tujuan | Halaman menampilkan tujuh batang berbagai tinggi dan memperlihatkan bubble sort satu perbandingan demi satu. |
| Masukan | Klik tombol; data awal `[5, 3, 8, 1, 9, 2, 7]` (karangan). |
| Proses | Hitung semua keadaan lebih dulu; tiap klik pindah ke keadaan berikutnya. |
| Keluaran | Batang, kalimat status, dan hitungan perbandingan dan pertukaran. |
| Kriteria selesai | Tiap klik memajukan tepat satu perbandingan; dua batang yang dibandingkan ditandai; setelah langkah terakhir tombol maju mati dan data terurut; ada tombol ulangi. |
| Prediksi | Total 21 perbandingan; hasil akhir `1 2 3 5 7 8 9`. |

Pseudocode:

```text
FUNGSI langkahBubble(awal):
  salin awal ke A; simpan keadaan awal
  untuk tiap putaran, untuk tiap pasangan bertetangga (i, i+1):
    tambah perbandingan
    JIKA A[i] > A[i+1]: tukar, tambah pertukaran
    simpan salinan A, i, apakah ditukar, dan kedua hitungan
HALAMAN:
  gambar(keadaan ke-posisi): batang, kalimat status, hitungan
  tombol maju: posisi + 1; putar otomatis: maju tiap 600 ms; ulangi: posisi = 0
```

Kuncinya pemisahan: `langkah.js` hanya menghitung dan bisa diuji di Bun tanpa peramban; `visual.js` hanya menggambar.

```js
// langkah.js
function langkahBubble(awal) {
  const a = [...awal];
  const hasil = [{ daftar: [...a], i: -1, tukar: false, perbandingan: 0, pertukaran: 0 }];
  let perbandingan = 0;
  let pertukaran = 0;
  for (let putaran = 0; putaran < a.length - 1; putaran++) {
    for (let i = 0; i < a.length - 1 - putaran; i++) {
      perbandingan++;
      const tukar = a[i] > a[i + 1];
      if (tukar) {
        const sementara = a[i];
        a[i] = a[i + 1];
        a[i + 1] = sementara;
        pertukaran++;
      }
      hasil.push({ daftar: [...a], i: i, tukar: tukar, perbandingan: perbandingan, pertukaran: pertukaran });
    }
  }
  return hasil;
}

// Bagian ini hanya berjalan di Bun, karena `document` tidak ada di sana.
if (typeof document === "undefined") {
  const semua = langkahBubble([4, 2, 3, 1]);
  console.log("banyak keadaan:", semua.length);
  for (const l of semua) {
    console.log(l.daftar.join(" "), "| i =", l.i, "| tukar =", l.tukar);
  }
  const akhir = semua[semua.length - 1];
  console.log("perbandingan", akhir.perbandingan, "pertukaran", akhir.pertukaran);
}
```

`bun run langkah.js` menghasilkan, cocok dengan penelusuran tangan:

```text

4 2 3 1 | i = -1 | tukar = false
2 4 3 1 | i = 0 | tukar = true
2 3 4 1 | i = 1 | tukar = true
2 3 1 4 | i = 2 | tukar = true
2 3 1 4 | i = 0 | tukar = false
2 1 3 4 | i = 1 | tukar = true
1 2 3 4 | i = 0 | tukar = true

```

Kode penggambaran memakai DOM. Menurut MDN, `textContent` mengisi elemen dengan teks biasa dan `addEventListener` mendaftarkan fungsi untuk peristiwa seperti `"click"`; `setTimeout` mengembalikan nomor timer untuk `clearTimeout`. Blok ini memakai `document`, jadi tidak dijalankan Bun.

```js
// visual.js
const DATA_AWAL = [5, 3, 8, 1, 9, 2, 7];
const semuaLangkah = langkahBubble(DATA_AWAL);
let posisi = 0;
let timer = null;

const wadah = document.getElementById("batang");
const teksStatus = document.getElementById("status");
const teksHitung = document.getElementById("hitung");
const tombolMaju = document.getElementById("maju");
const tombolPutar = document.getElementById("putar");
const tombolUlang = document.getElementById("ulang");

function gambar() {
  const l = semuaLangkah[posisi];
  wadah.textContent = "";
  l.daftar.forEach((nilai, indeks) => {
    const b = document.createElement("div");
    b.className = "batang";
    if (l.i >= 0 && (indeks === l.i || indeks === l.i + 1)) {
      b.classList.add(l.tukar ? "tukar" : "banding");
    }
    b.style.height = nilai * 24 + "px";
    b.textContent = nilai;
    wadah.appendChild(b);
  });
  if (l.i < 0) {
    teksStatus.textContent = "Awal: " + l.daftar.join(" ");
  } else {
    const hasil = l.tukar ? "ditukar" : "tidak ditukar";
    teksStatus.textContent = "Membandingkan indeks " + l.i + " dan " + (l.i + 1) + ": " + hasil;
  }
  teksHitung.textContent = "Perbandingan: " + l.perbandingan + ", pertukaran: " + l.pertukaran;
  tombolMaju.disabled = posisi === semuaLangkah.length - 1;
}

function maju() {
  if (posisi < semuaLangkah.length - 1) {
    posisi++;
    gambar();
  }
}

function berhenti() {
  clearTimeout(timer);
  timer = null;
  tombolPutar.textContent = "Putar otomatis";
}

function putar() {
  if (timer !== null) {
    berhenti();
    return;
  }
  tombolPutar.textContent = "Jeda";
  const jalan = () => {
    if (posisi < semuaLangkah.length - 1) {
      maju();
      timer = setTimeout(jalan, 600);
    } else {
      berhenti();
    }
  };
  timer = setTimeout(jalan, 600);
}

function ulang() {
  berhenti();
  posisi = 0;
  gambar();
}

tombolMaju.addEventListener("click", maju);
tombolPutar.addEventListener("click", putar);
tombolUlang.addEventListener("click", ulang);
gambar();
```

## Kunci dan petunjuk

**Ingat kembali.** 1: `git switch -c fitur-x`; cabang memisahkan pekerjaan baru dari `main` sampai siap digabung. 2: `Number("")` adalah 0 dan `Number("9o")` adalah `NaN`; periksa dengan `Number.isNaN(hasil)` setelah menangani nilai kosong. 3: `@media (min-width: 600px) { .dua-kolom { flex-direction: row; } }`.

**Rencana proyek.** Tidak ada satu jawaban benar; rencana yang baik punya kriteria selesai yang bisa diuji ("tiap klik memajukan tepat satu perbandingan") dan prediksi yang spesifik. Bila hasil berbeda dari prediksi, catat mana yang salah: rencana atau kodenya.

**Daftar periksa.** Contoh uji data terurut: untuk `[1, 2, 3, 4, 5]` fungsi mengembalikan 10 perbandingan dan 0 pertukaran; bila tidak, periksa kondisi `a[i] > a[i + 1]`. Pada data contoh halaman, hasil akhir 21 perbandingan dan 10 pertukaran.

**Umpan balik sejawat.** Contoh: "Sudah baik: dua batang yang dibandingkan jelas berbingkai. Perlu diperbaiki: di langkah terakhir status tetap berbunyi "tidak ditukar" tanpa menyebut bahwa data sudah terurut. Langkah berikutnya: tampilkan `Selesai: data sudah terurut` pada keadaan terakhir."

**Latihan bercampur.** 1: kunci yang dijalankan:

```js
// langkah-insertion.js
function langkahInsertion(awal) {
  const a = [...awal];
  const hasil = [[...a]];
  for (let i = 1; i < a.length; i++) {
    const x = a[i];
    let j = i - 1;
    while (j >= 0 && a[j] > x) {
      a[j + 1] = a[j];
      j--;
    }
    a[j + 1] = x;
    hasil.push([...a]);
  }
  return hasil;
}

for (const keadaan of langkahInsertion([7, 3, 5, 2])) {
  console.log(keadaan.join(" "));
}
```

```text
7 3 5 2
3 7 5 2
3 5 7 2
2 3 5 7
```

```js
// langkah-biner.js
function langkahBiner(terurut, x) {
  const hasil = [];
  let kiri = 0;
  let kanan = terurut.length - 1;
  while (kiri <= kanan) {
    const tengah = Math.floor((kiri + kanan) / 2);
    hasil.push({ kiri: kiri, kanan: kanan, tengah: tengah, nilai: terurut[tengah] });
    if (terurut[tengah] === x) {
      break;
    } else if (terurut[tengah] < x) {
      kiri = tengah + 1;
    } else {
      kanan = tengah - 1;
    }
  }
  return hasil;
}

for (const l of langkahBiner([2, 5, 8, 12, 16, 23, 38, 56, 72, 91], 23)) {
  console.log("kiri", l.kiri, "kanan", l.kanan, "tengah", l.tengah, "nilai", l.nilai);
}
```

```text
kiri 0 kanan 9 tengah 4 nilai 16
kiri 5 kanan 9 tengah 7 nilai 56
kiri 5 kanan 6 tengah 5 nilai 23
```

Untuk visualisasi pencarian, tandai rentang `kiri` sampai `kanan` dan batang `tengah` pada tiap langkah.

**Ulang berjarak.** 1: supaya penghitungan bisa diuji di Bun tanpa peramban, dipakai ulang untuk tampilan lain, dan mudah mundur. 2: `setTimeout(fungsi, ms)` menjalankan fungsi sekali setelah `ms` milidetik dan mengembalikan nomor timer; `clearTimeout(nomor)` membatalkannya. 3: karena hasilnya bisa dibandingkan dengan jawaban yang sudah pasti; tanpa itu, program yang salah bisa tampak benar.
