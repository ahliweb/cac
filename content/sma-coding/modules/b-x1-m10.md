## Untuk siapa modul ini

Modul ini untuk murid kelas X jalur B (Web dengan JavaScript, TypeScript, dan Bun), minggu `B-X1-M10` silabus v1.4.1: percabangan dan logika Boolean. Prasyarat: modul `b-x1-m9` (variabel, tipe, ekspresi, dan masukan dari `Bun.argv` atau `prompt()`). Modul ini mengajar dari awal dan tidak mengandaikan kamu pernah memprogram; urutannya tebak dulu, lengkapi contoh, susun baris, baru menulis dari halaman kosong.

Modul ini berstatus DRAF: karangan penyusun, belum ditinjau pemilik. Butir `E-BK-d` (solusi program sederhana dalam format pseudocode) dipetakan silabus sebagai dipenuhi jalur ini; modul draf ini belum dihitung sebagai pemenuhan butir itu.

Contoh dijalankan penyusun dengan Bun 1.4.4 per 2026-11. Tugas baca-dan-prediksi ditandai `AI: tanpa AI`; selain itu AI generatif boleh dipakai dengan etika dan dicatat, tanpa data pribadi, kata sandi, atau tugas bernilai pada permintaanmu. Saran: jawab dulu sendiri, baru minta penjelasan atau petunjuk bertahap.

## Tujuan

Setelah modul ini kamu dapat:

- memakai `if`, `else if`, dan `else` untuk membuat keputusan, dan `switch` untuk memilih dari beberapa nilai;
- menggabungkan syarat dengan `&&`, `||`, dan `!` dan membuat tabel kebenarannya;
- membedakan `===` dari `=` dan menjelaskan mengapa `5 === "5"` salah;
- menyebut nilai "truthy" dan "falsy" (keluaran minggu ini: skrip bercabang dan tabel kebenaran).

## Prediksi dulu

Baca skrip ini dan **tebak dulu, tulis jawabanmu per baris, baru jalankan**. `===` membandingkan dua nilai tanpa mengubah tipenya. `true` dan `false` adalah nilai `boolean`.

```js

  console.log("ada isi");

```

## Contoh terselesaikan

Keluaran skrip prediksi di atas:

```text
7 ganjil
false
true
false true false
kosong
```

**Percabangan.** `if (syarat) { ... } else { ... }` menjalankan blok pertama bila syaratnya benar. Bila ada beberapa kemungkinan, rantai dengan `else if`; hanya cabang pertama yang syaratnya benar yang dijalankan. Skrip kategori nilai berikut memakai nilai karangan dari argumen:

```js
// kategori.js
const nilai = Number(Bun.argv[2]);
if (nilai >= 85) {
  console.log(nilai, "sangat baik");
} else if (nilai >= 70) {
  console.log(nilai, "baik");
} else if (nilai >= 55) {
  console.log(nilai, "cukup");
} else {
  console.log(nilai, "perlu latihan");
}
```

Dijalankan dengan nilai 78:

```sh
bun run kategori.js 78
```

```text
78 baik
```

Untuk 90 hasilnya `sangat baik`, untuk 85 juga `sangat baik` (karena `>=`), untuk 60 `cukup`, dan untuk 40 `perlu latihan`. Urutan syarat penting: bila `nilai >= 55` ditulis pertama, angka 90 jatuh ke `cukup`.

**Logika Boolean.** `A && B` (dan) benar bila keduanya benar. `A || B` (atau) benar bila salah satu atau keduanya benar. `!A` (bukan) membalik nilai. Tabel kebenarannya dicetak skrip ini:

```js
// tabel.js
console.log("A     B     A&&B  A||B  !A");
console.log(true, true, true && true, true || true, !true);
console.log(true, false, true && false, true || false, !true);
console.log(false, true, false && true, false || true, !false);
console.log(false, false, false && false, false || false, !false);
```

Keluarannya (kolom mengikuti urutan judul; spasi antarkolom bisa berbeda dari judul):

```text
A     B     A&&B  A||B  !A
true true true true false
true false false true false
false true false true true
false false false false true
```

**Truthy dan falsy.** Saat dipakai sebagai syarat, sebuah nilai yang bukan `boolean` diubah menjadi `true` atau `false`. Nilai yang menjadi `false` disebut falsy; menurut MDN di antaranya `false`, `0`, `""` (teks kosong), `null`, `undefined`, dan `NaN`. Hampir semua nilai lain truthy. Perhatikan: `"0"` dan `"false"` adalah teks yang berisi karakter, jadi truthy.

```js
// falsy.js
console.log(Boolean(0), Boolean(""), Boolean(null), Boolean(undefined), Boolean(NaN));
console.log(Boolean("0"), Boolean("false"), Boolean(1), Boolean("a"));
```

Keluarannya:

```text
false false false false false
true true true true
```

**`switch`.** Untuk memilih dari beberapa nilai tertentu. `break` mengakhiri `case`; tanpa `break` eksekusi jatuh ke `case` berikutnya. Dua `case` yang berurutan tanpa `break` di antaranya sengaja dipakai untuk satu aksi yang sama:

```js
// hari.js
const hari = Number(Bun.argv[2]);
switch (hari) {
  case 6:
  case 7:
    console.log(hari, "akhir pekan");
    break;
  case 1:
    console.log(hari, "awal pekan");
    break;
  default:
    console.log(hari, "hari biasa");
}
```

Dengan masukan 1, 3, 6, dan 7 hasilnya `awal pekan`, `hari biasa`, `akhir pekan`, dan `akhir pekan`.

## Kesalahan umum

- **`=` tertukar dengan `===`.** `if (x = 5)` memberi `x` nilai 5 dan hasilnya selalu truthy. Pada skrip uji, `x` yang semula 0 masuk ke dalam `if` dan `x` menjadi 5. Pakai `===` untuk membandingkan.
- **Mengandalkan `==`.** `5 == "5"` bernilai `true` karena teks diubah menjadi angka dulu, sedangkan `5 === "5"` bernilai `false`. Biasakan `===` agar tipe tidak berubah diam-diam.
- **Lupa `break` di `switch`.** Dengan `hari = 1` dan tanpa `break` setelah `case 1`, tercetak dua baris: `awal pekan` lalu `hari biasa`, karena eksekusi jatuh ke `case` berikutnya.
- **Menulis `nilai > 80 && < 90`.** Bagian kedua kehilangan `nilai`; JavaScript tidak menerima ini. Tulis `nilai > 80 && nilai < 90`.
- **Mengira `"0"` falsy.** Teks `"0"` truthy karena tidak kosong; hanya angka `0` dan teks kosong `""` yang falsy.

## Kunci dan petunjuk

**Ingat kembali.** 1: `7 % 3` adalah 1 dan `7 / 2` adalah 3.5. 2: `TERBESAR = A`; `JIKA B > TERBESAR MAKA TERBESAR = B`; `JIKA C > TERBESAR MAKA TERBESAR = C`; `CETAK TERBESAR`. 3: 0 atau 1.

**Prediksi dulu.** 1: `angka % 2` untuk 7 adalah 1, bukan 0, jadi cabang `else` jalan dan tercetak `7 ganjil`. 2: `===` tidak mengubah tipe; angka lima dan teks "5" berbeda tipe. 3: `""` falsy, jadi cabang `else` jalan dan tercetak `kosong`. Keluaran lengkap ada di bagian contoh.

**Contoh setengah jadi.** Isian berurutan: `&&`, `0`. Kuncinya:

```js
// pg.js
const n = Number(Bun.argv[2]);
if (n > 0 && n % 2 === 0) {
  console.log("positif genap");
} else {
  console.log("bukan");
}
```

```sh
bun run pg.js 8
```

```text
positif genap
```

Untuk `-4` dan `7` hasilnya `bukan`.

**Soal Parsons.** Urutan benar: c, d, f, a, b, e. Baris (a) menutup `if` dan membuka `else`, baris (e) menutup `else`.

**Latihan.** 1: dengan a = 6 dan b = 4: `false`, `true`, `true`. Hasil kedua dan ketiga sama: negasi `!(a > 5 && b < 3)` setara dengan `a <= 5 || b >= 3` (hukum De Morgan: membalik `&&` menjadi `||` dan membalik tiap perbandingan). 2: pseudocode: `JIKA N sisa 2 sama dengan 0 MAKA CETAK genap, JIKA TIDAK CETAK ganjil`; skrip: `if (n % 2 === 0) { console.log("genap"); } else { console.log("ganjil"); }`. Bilangan negatif ganjil menghasilkan sisa `-1`, jadi `n % 2 === 0` tetap benar untuk genap negatif dan salah untuk ganjil negatif. 3: contoh seperti `kategori.js`; di batas, 70 masuk `baik` dan 69 masuk `cukup` karena `>=`. 4: `if (x)` untuk `x === true` (hanya bila x memang `boolean`); `if (a <= 5 || b >= 3)`. Keduanya mengurangi simbol tanpa mengubah hasil.

**Latihan bercampur.** 1: kuncinya dijalankan:

```js
// terbesar.js
const a = Number(Bun.argv[2]);
const b = Number(Bun.argv[3]);
const c = Number(Bun.argv[4]);
let terbesar = a;
if (b > terbesar) {
  terbesar = b;
}
if (c > terbesar) {
  terbesar = c;
}
console.log(terbesar);
```

```sh
bun run terbesar.js 4 9 6
```

```text
9
```

Untuk `2 7 7` hasilnya `7`. 2: `if (n > 0) { ... } else if (n === 0) { ... } else { ... }` dengan `n` dari `Number(Bun.argv[2])`. 3: baris (A, B): (benar, benar) salah; (benar, salah) benar; (salah, benar) benar; (salah, salah) salah. Ini "salah satu saja, bukan keduanya" (atau eksklusif).

**Ulang berjarak.** 1: `n % 2 === 0`. 2: `false`, karena beda tipe (angka dan teks) dan `===` tidak mengubah tipe. 3: contoh: `0`, `""`, `null` (juga `undefined`, `NaN`, `false`).
