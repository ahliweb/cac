## Tujuan

Setelah modul ini kamu dapat:

- menulis fungsi biasa dan fungsi panah dengan parameter dan `return`;
- memanggil fungsi dan memakai nilai yang dikembalikannya;
- menjelaskan variabel lokal dan mengapa ia tidak terlihat di luar fungsi;
- menyusun skrip modular yang terdiri dari beberapa fungsi kecil (keluaran minggu ini), misalnya faktorial dan FPB.

## Prediksi dulu

Fungsi adalah blok langkah bernama yang bisa dipanggil berkali-kali. Parameter adalah nama di dalam kurung saat fungsi ditulis; nilai yang kamu berikan saat memanggil disebut argumen. `return` mengembalikan nilai ke tempat pemanggilan. Baca skrip ini dan **tebak dulu, tulis jawabanmu per baris, baru jalankan**.

```js
// prediksi-fungsi.js
function kuadrat(x) {
  return x * x;
}
function sapa(nama) {
  console.log("Halo,", nama);
}
console.log(kuadrat(5));
sapa("Dewi-contoh");
const hasil = sapa("Budi-contoh");
console.log(hasil);
const tambah = (a, b) => a + b;
console.log(tambah(2, 3));
```

1. Apa yang tercetak pada tiap baris?
2. `sapa` tidak memakai `return`. Apa yang disimpan di `hasil`?
3. Apa beda `kuadrat(5)` dengan `sapa("Dewi-contoh")` dilihat dari "apa yang keluar dari fungsi"?

## Contoh terselesaikan

Keluaran skrip prediksi di atas:

```text
25
Halo, Dewi-contoh
Halo, Budi-contoh
undefined
5
```

**Dua cara menulis fungsi.** Fungsi biasa: `function kuadrat(x) { return x * x; }`. Fungsi panah: `const tambah = (a, b) => a + b;`. Bila badan fungsi panah satu ekspresi tanpa kurung kurawal, nilainya langsung dikembalikan; dengan kurung kurawal kamu wajib menulis `return`. Fungsi tanpa `return` mengembalikan `undefined`: nilai "belum ada isinya".

**Variabel lokal.** Variabel yang dibuat di dalam fungsi hanya hidup di dalam fungsi itu. Parameter juga lokal: mengubah parameter tidak mengubah variabel di luar fungsi yang dipakai sebagai argumen.

**Skrip modular.** Pecah pekerjaan menjadi fungsi kecil yang masing-masing satu tugas. Faktorial `n!` adalah hasil kali 1 sampai `n` (dan `0! = 1`); FPB dihitung dengan algoritma Euclid: ganti pasangan `(a, b)` dengan `(b, sisa a dibagi b)` sampai `b` menjadi 0, lalu `a` adalah FPB-nya.

```js
// modular.js
function faktorial(n) {
  let hasil = 1;
  for (let i = 2; i <= n; i++) {
    hasil = hasil * i;
  }
  return hasil;
}

function fpb(a, b) {
  while (b !== 0) {
    const sisa = a % b;
    a = b;
    b = sisa;
  }
  return a;
}

console.log("0! =", faktorial(0));
console.log("5! =", faktorial(5));
console.log("10! =", faktorial(10));
console.log("FPB(12, 18) =", fpb(12, 18));
console.log("FPB(17, 5) =", fpb(17, 5));
console.log("FPB(100, 75) =", fpb(100, 75));
```

Keluarannya:

```text
0! = 1
5! = 120
10! = 3628800
FPB(12, 18) = 6
FPB(17, 5) = 1
FPB(100, 75) = 25
```

Penelusuran `fpb(12, 18)`:

| Putaran | `a` | `b` | `sisa` |
| --- | --- | --- | --- |
| awal | 12 | 18 | - |
| 1 | 18 | 12 | 12 |
| 2 | 12 | 6 | 6 |
| 3 | 6 | 0 | 0 |

Setelah putaran ketiga `b` sama dengan 0, perulangan berhenti, dan fungsi mengembalikan `a`, yaitu 6. Pada contoh ini hanya tiga putaran yang dibutuhkan.

## Kesalahan umum

- **Lupa `return`.** Fungsi `tanpaReturn(x) { x * x; }` menghitung tetapi tidak mengembalikan apa pun, sehingga `console.log(tanpaReturn(4))` mencetak `undefined`. Hal yang sama terjadi pada fungsi panah berkurung kurawal tanpa `return`.
- **Menulis nama fungsi tanpa tanda kurung.** `console.log(kuadrat)` tidak memanggil fungsi; yang tercetak adalah fungsinya sendiri, `[Function: kuadrat]`. Panggilan ditulis `kuadrat(5)`.
- **Argumen kurang.** `kuadrat()` tanpa argumen membuat `x` bernilai `undefined`, sehingga hasilnya `NaN`.
- **Memakai variabel lokal di luar fungsi.** `rahasia` yang dibuat di dalam fungsi tidak ada di luar; mencetaknya dari luar menghentikan skrip dengan `ReferenceError: rahasia is not defined`.
- **Mencampur mencetak dan mengembalikan.** `console.log` di dalam fungsi hanya menampilkan nilai; ia tidak memberikannya kepada pemanggil. Bila hasilnya mau dipakai lagi, `return`.

## Kunci dan petunjuk

**Ingat kembali.** 1: `for (let i = 1; i <= 5; i++) { console.log(i); }`; tiga bagiannya awal, syarat, dan langkah. 2: `let` boleh diisi ulang, `const` tidak. 3: masukan, proses, keluaran. 4: `false` dan `true`.

**Prediksi dulu.** 1: `25`, `Halo, Dewi-contoh`, `Halo, Budi-contoh`, `undefined`, `5`. 2: `undefined`, karena `sapa` hanya mencetak dan tidak mengembalikan nilai. 3: `kuadrat(5)` memberikan nilai 25 kepada pemanggil; `sapa(...)` hanya menampilkan sesuatu di layar.

**Contoh setengah jadi.** Isian berurutan: `a`, `b`, `c`, `3`; lalu `a`, `b`. Kuncinya:

```js
// fungsi-kunci.js
function rataRata(a, b, c) {
  return (a + b + c) / 3;
}
console.log(rataRata(4, 8, 6));

const terbesar2 = (a, b) => {
  if (a > b) {
    return a;
  }
  return b;
};
console.log(terbesar2(3, 9));
```

Keluarannya:

```text

9
```

**Soal Parsons.** Urutan benar: c, g, a, f, d, b, e. Baris (d) menutup `for` dan (e) menutup fungsi; `return` harus berada setelah perulangan selesai.

**Latihan.** 1: di dalam `ubah(3)`: `y` menjadi 4, `x` menjadi 6, hasil `4 + 6` adalah 10; `a` tetap 3 karena parameter lokal; `dua(dua(3))` adalah 12. Tercetak `10`, `3`, `12`. 2: pseudocode: `HASIL = 1`; `ULANG I dari 2 sampai N: HASIL = HASIL * I`; `KEMBALIKAN HASIL`. Hasil uji: 1, 1, 120, 3628800. 3: `fpb(48, 18)`: (48, 18) lalu (18, 12), (12, 6), (6, 0); hasil 6. 4: kunci yang dijalankan:

```js
// prima-fungsi.js
function apakahPrima(n) {
  if (n < 2) {
    return false;
  }
  for (let pembagi = 2; pembagi < n; pembagi++) {
    if (n % pembagi === 0) {
      return false;
    }
  }
  return true;
}

for (let n = 1; n <= 30; n++) {
  if (apakahPrima(n)) {
    console.log(n);
  }
}
```
