## Untuk siapa modul ini

Modul ini untuk murid kelas X jalur C (IoT dan robotika), minggu `C-X1-M14` silabus v1.3: asesmen dan refleksi semester 1 (termasuk asesmen formatif fondasi). Prasyarat: modul `c-x1-m12` dan seluruh materi `c-x1-m8` sampai `c-x1-m13`; modul ini menilai semuanya.

Modul ini karangan penyusun dan disetujui pemilik program pada 2026-11-20 (keputusan lewat dialog; catatan tinjauan menjadi tindak lanjut revisi), dan tidak dihitung sebagai pemenuhan butir capaian pembelajaran. Asesmen ini **tanpa AI**: jangan memakai AI generatif saat mengerjakannya (silabus 7.4). Bobot nilai dan predikat mengikuti kebijakan sekolah `[belum terverifikasi]`; modul ini hanya memberi soal dan kunci latihan.

Bagian praktik dapat dikerjakan **dengan papan** bila tersedia, atau **tanpa papan** di kertas dan komputer. Bila memakai papan, ikuti aturan keselamatan modul sebelumnya: daya USB saja, cabut kabel sebelum mengubah rangkaian.

## Ingat kembali

Ini inti asesmen: jawab dari ingatan, tanpa melihat catatan, lalu cocokkan dengan kunci. Soal 1 sampai 3 dari modul fondasi (`fondasi-komputer-dan-hardware`, `fondasi-representasi-data`, `fondasi-keamanan-dasar`), soal 4 dari `c-x1-m11`, soal 5 dari `c-x1-m13`.

1. Sebutkan tiga bagian siklus Input-Proses-Output, lalu beri satu contoh sensor dan satu contoh aktuator pada papan.
2. Ubah bilangan biner 1101 menjadi desimal dan heksadesimal.
3. Sebutkan dua ciri kata sandi yang kuat.
4. Hitung `map(3000, 0, 4095, 0, 100)` dengan aturan bilangan bulat.
5. Sebutkan dua hal yang harus ada di rencana proyek sebelum program ditulis.

## Tujuan

Soal di modul ini menilai apakah kamu dapat:

## Latihan bercampur

Kerjakan sendiri, `AI: tanpa AI`, dengan waktu yang ditetapkan gurumu.

1. **Tulis.** Tulis pseudocode lalu programnya: LED menyala selama tombol ditekan, dan sesudah tombol dilepas LED masih menyala 2 detik sebelum padam. Pakai `INPUT_PULLUP` dan konstanta bernama untuk pin dan jeda.
2. **Telusuri.** Program berikut dijalankan:

   ```arduino
   // Arduino-C++ untuk ESP32. Diperiksa check:module-code terhadap header tiruan (sintaks dan tipe saja, bukan bukti perilaku papan).
   const int POLA[] = {3, 1, 4, 1};
   const int PANJANG = 4;

   void setup() {
     Serial.begin(115200);
     int jumlah = 0;
     for (int i = 0; i < PANJANG; i++) {
       if (POLA[i] > 2) {
         jumlah += POLA[i];
       }
     }
     Serial.println(jumlah);
   }

   void loop() {
   }
   ```

   Apa yang tercetak? Berapa kali kondisi `POLA[i] > 2` benar?
3. **Hitung dan jelaskan.** Sensor memberi nilai 1024 dari rentang 0 sampai 4095. Berapa `map(1024, 0, 4095, 0, 100)`? Lalu berapa nilai `x` setelah `float x = 9 / 2;` dan mengapa?
4. **Cari galat.** Potongan berikut sengaja salah. Tulis dua galat, jelaskan akibatnya, dan tulis perbaikannya.

   ```text
   const int POLA[] = {1, 0, 1};
   const int PANJANG = 3;
   for (int i = 0; i <= PANJANG; i++) {
     if (digitalRead(PIN_TOMBOL) = LOW) {
       digitalWrite(PIN_LED, POLA[i]);
     }
   }
   ```
5. **Praktik atau rangkaian.** Dengan papan: rakit tombol dan LED sesuai lembar guru, unggah programmu, dan peragakan. Tanpa papan: tulis daftar sambungan (apa disambung ke apa) dan empat langkah keselamatan yang kamu lakukan sebelum mengubah rangkaian.

## Kunci dan petunjuk

**Ingat kembali.** 1: masukan, proses, keluaran; contoh sensor cahaya dan LED. 2: 1101 biner = 8 + 4 + 1 = 13 desimal = D heksadesimal. 3: contoh jawaban: panjang, tidak mudah ditebak (misalnya frasa acak), tidak dipakai di banyak akun. 4: 3000 x 100 / 4095 = 73,26 menjadi 73. 5: contoh jawaban: tujuan dan kriteria selesai (juga boleh: diagram I-P-O, daftar uji, prediksi hasil).

**Latihan bercampur.** 1: pseudocode: ULANG TERUS: BILA tombol ditekan, nyalakan LED; tunggu sampai tombol dilepas; tunggu 2 detik; padamkan LED. Contoh program: `if (digitalRead(PIN_TOMBOL) == LOW) { digitalWrite(PIN_LED, HIGH); while (digitalRead(PIN_TOMBOL) == LOW) { } delay(JEDA_MS); digitalWrite(PIN_LED, LOW); }` dengan `JEDA_MS` bernilai 2000 dan `pinMode` yang tepat di `setup()`. Boleh juga versi lain yang memenuhi tujuannya. 2: tercetak 7 (3 + 4); kondisi benar dua kali (untuk 3 dan 4). 3: 1024 x 100 / 4095 = 25,006 menjadi 25; `float x = 9 / 2;` menghasilkan 4, karena 9 / 2 dihitung sebagai pembagian bilangan bulat lebih dulu (sisa dibuang), baru disimpan ke `float`. 4: galat pertama `i <= PANJANG` membaca `POLA[3]` yang tidak ada, perbaikan `i < PANJANG`; galat kedua `=` yang memberi nilai, bukan membandingkan, dan program tidak dikompilasi dengan benar atau kondisinya salah arah, perbaikan `==`. 5: contoh sambungan: satu kaki tombol ke pin masukan dan kaki lain ke GND; LED lewat resistor ke pin keluaran dan GND dengan polaritas benar. Langkah keselamatan: cabut kabel USB, periksa polaritas, tanpa listrik 220 V, laporkan papan panas atau berbau.

**Rubrik singkat.** Untuk soal 1 dan 5, periksa empat hal: ketepatan (program atau rangkaian memenuhi tujuan), keterbacaan (nama dan konstanta jelas), pengujian (disebut cara mengujinya), dan justifikasi (alasan pilihan). Skala yang disarankan: sudah, sebagian, belum, per hal. Untuk soal 2 sampai 4, jawaban dinilai benar bila angka dan alasan sama dengan kunci.

**Refleksi.** Tidak ada kunci. Jawaban yang baik menyebut bukti, bagian yang lemah, dan rencana yang jelas waktunya.
