## Untuk siapa modul ini

Modul ini untuk murid kelas X jalur C (IoT dan robotika), minggu `C-X1-M10` silabus v1.3: perulangan dan keluaran serial. Prasyarat: modul `c-x1-m9` (tombol, `if`/`else`, `&&`, `||`, `!`).

Modul ini berstatus DRAF: karangan penyusun, belum ditinjau pemilik. Ia mendukung butir `E-BK-d` (solusi program sederhana dalam format pseudocode) dan tidak dihitung memenuhi butir capaian pembelajaran mana pun.

Ada dua cara mengerjakan. **Dengan papan (F):** kamu merakit tiga LED bersama kelompokmu dan melihat teks dari papan di monitor serial komputer. **Tanpa papan:** kamu menelusuri program di kertas dan menjalankan "papan tiruan" di komputer yang mencetak ke layar. Semua bagian pokok bisa dikerjakan tanpa papan. Nomor pin dan kecepatan serial pada papanmu `[belum terverifikasi]`: ikuti lembar guru.

## Keselamatan perangkat

- Daya hanya dari kabel USB. Tidak ada listrik jaringan (220 V) dan tidak ada baterai pada modul ini.
- Cabut kabel USB sebelum memasang atau melepas kabel jumper atau LED.
- Setiap LED dipasang bersama resistor yang disiapkan guru, dan kaki LED punya polaritas. Periksa polaritas sebelum menyalakan.
- Tidak ada solder. Papan percobaan dan kabel jumper sudah cukup.
- Papan atau komponen yang terasa panas, berbau, atau berasap: cabut kabel dan panggil guru.

## Tujuan

Setelah modul ini kamu dapat:

- memakai `for` dan `while` untuk mengulang sejumlah langkah yang sudah diketahui atau sampai suatu syarat terpenuhi;
- menelusuri nilai variabel pencacah pada tiap putaran;
- mencetak nilai ke monitor serial dengan `Serial.begin`, `Serial.print`, dan `Serial.println`;
- memakai cetakan serial untuk mencari galat, lalu menghasilkan program pola lampu dan catatan galat (keluaran minggu ini).

## Contoh terselesaikan

Perulangan mengulang sebuah blok. `for (awal; syarat; langkah)` cocok bila jumlah putarannya sudah jelas: bagian awal dijalankan sekali, syarat diperiksa sebelum tiap putaran, dan langkah dijalankan di akhir tiap putaran. `while (syarat)` cocok bila kamu menunggu sesuatu terjadi: blok diulang selama syaratnya benar, dan blok harus mengubah sesuatu agar syarat suatu saat salah. Bila tidak, perulangan tidak pernah berhenti.

Dua perulangan berikut menghitung mundur dengan cara berbeda dan menghasilkan hasil sama. Bagian ini dijalankan di komputer, tanpa papan.

```cpp
// C++17 biasa, jalan di komputer. Diperiksa oleh check:module-code.
#include <iostream>

int main() {
  std::cout << "for:";
  for (int i = 3; i >= 1; i--) std::cout << " " << i;
  std::cout << "\nwhile:";
  int j = 3;
  while (j >= 1) {
    std::cout << " " << j;
    j--;
  }
  std::cout << "\n";
}
```

Keluarannya:

```text
for: 3 2 1
while: 3 2 1
```

Bila baris `j--` dihapus, `j` tetap 3 dan perulangan tidak pernah berhenti.

Sekarang pola lampu berjalan dengan tiga LED di pin berurutan. Nilai `i` dipakai dua kali: sebagai pencacah, dan sebagai penambah nomor pin (`PIN_AWAL + i`). Monitor serial adalah jendela di komputer yang menerima teks dari papan lewat kabel USB; `Serial.println` mencetak nilainya lalu pindah baris. Kecepatan (baud) di program dan di monitor harus sama, bila tidak yang tampil huruf acak.

```arduino
// Arduino-C++ untuk ESP32. Tidak dikompilasi oleh check:module-code.
const int PIN_AWAL = 16;   // LED di pin 16, 17, 18; contoh, periksa papanmu
const int JUMLAH_LED = 3;
const int JEDA_MS = 200;

void setup() {
  Serial.begin(115200);
  for (int i = 0; i < JUMLAH_LED; i++) {
    pinMode(PIN_AWAL + i, OUTPUT);
  }
}

void loop() {
  for (int i = 0; i < JUMLAH_LED; i++) {
    Serial.print("i=");
    Serial.println(i);
    digitalWrite(PIN_AWAL + i, HIGH);
    delay(JEDA_MS);
    digitalWrite(PIN_AWAL + i, LOW);
  }
}
```

Papan tiruan berikut menjalankan `setup()` dan `loop()` yang sama, tetapi `Serial` mencetak ke layar komputer dan `digitalWrite` mencatat waktu. `loop()` hanya dipanggil sekali karena papan sungguhan mengulangnya tanpa henti.

```cpp
// C++17 biasa, jalan di komputer. Diperiksa oleh check:module-code.
#include <iostream>

// Papan tiruan: pengganti fungsi Arduino.
const int OUTPUT = 1;
const int HIGH = 1;
const int LOW = 0;
long waktu_ms = 0;

struct SerialTiruan {
  void begin(long) {}
  void print(const char* teks) { std::cout << teks; }
  void println(int nilai) { std::cout << nilai << "\n"; }
};
SerialTiruan Serial;

void pinMode(int, int) {}
void digitalWrite(int pin, int nilai) {
  std::cout << waktu_ms << " ms: pin " << pin << (nilai == HIGH ? " HIGH" : " LOW") << "\n";
}
void delay(long ms) { waktu_ms += ms; }

// Program yang sama dengan di atas.
const int PIN_AWAL = 16;
const int JUMLAH_LED = 3;
const int JEDA_MS = 200;

void setup() {
  Serial.begin(115200);
  for (int i = 0; i < JUMLAH_LED; i++) {
    pinMode(PIN_AWAL + i, OUTPUT);
  }
}

void loop() {
  for (int i = 0; i < JUMLAH_LED; i++) {
    Serial.print("i=");
    Serial.println(i);
    digitalWrite(PIN_AWAL + i, HIGH);
    delay(JEDA_MS);
    digitalWrite(PIN_AWAL + i, LOW);
  }
}

int main() {
  setup();
  loop();
}
```

Keluarannya:

```text
i=0
0 ms: pin 16 HIGH
200 ms: pin 16 LOW
i=1
200 ms: pin 17 HIGH
400 ms: pin 17 LOW
i=2
400 ms: pin 18 HIGH
600 ms: pin 18 LOW
```

Satu putaran `loop()` memakan 3 x 200 = 600 ms. Cetakan `i=...` membuktikan LED mana yang sedang diproses; itulah gunanya keluaran serial saat mencari galat: kamu melihat apa yang sebenarnya dikerjakan program, bukan apa yang kamu kira.

## Soal Parsons

Susun baris-baris di bawah (sudah diacak) menjadi program yang mencetak 0, 1, 2 di monitor serial lalu tidak melakukan apa-apa.

```text
(a) void loop() {}
(b)   Serial.println(i);
(c) void setup() {
(d)   for (int i = 0; i < 3; i++) {
(e)   }
(f)   Serial.begin(115200);
(g) }
```

## Latihan

1. `AI: boleh` **Pseudocode dulu.** Tulis pseudocode, lalu programnya: hitung mundur dari 5 sampai 1 di monitor serial, lalu cetak 0.
2. `AI: tanpa AI` **Telusuri.** Untuk `for (int i = 2; i < 12; i += 3)`, tulis nilai `i` pada tiap putaran dan berapa kali badan dijalankan.
3. `AI: tanpa AI` **Cari galat.** Seorang murid menulis `for (int i = 0; i <= JUMLAH_LED; i++)` dengan `JUMLAH_LED` bernilai 3 untuk menyalakan tiga LED. Pin mana yang ikut dinyalakan, dan baris cetak apa yang akan memperlihatkannya? Tulis catatan galat satu kalimat.
4. `AI: boleh` **Dengan papan (F).** Rakit tiga LED sesuai lembar guru dengan kabel USB dicabut, unggah program contoh terselesaikan, dan buka monitor serial. Lalu tambahkan cetakan nilai tombol dari modul sebelumnya. Bila yang tampil huruf acak, samakan kecepatan monitor dengan `Serial.begin`.
5. *Opsional:* **catatan pemakaian AI.** Bila memakai AI generatif, jawab nomor 1 sendiri dulu, lalu minta penjelasan atau petunjuk bertahap, bukan program jadi. Catat alatnya, tujuanmu, garis besar perintahmu, bagian yang kamu pakai, dan cara memeriksanya (jalankan atau telusuri). Jangan menaruh data pribadi atau tugas bernilai pada perintah.

## Latihan bercampur

1. Tombol A dan B menyalakan LED dengan syarat `(a_ditekan || b_ditekan) && !(a_ditekan && b_ditekan)`. Telusuri syarat itu untuk empat kombinasi (A, B) dengan ditekan = 1, lalu tulis hasilnya sebagai deret empat bit.
2. Satu putaran `loop()` pola lampu menyalakan tiga LED masing-masing 200 ms. Berapa putaran dalam satu menit?
3. Mengapa pencacah `for` pada papan biasanya dimulai dari 0? Kaitkan dengan `PIN_AWAL + i`.

## Kesalahan umum

- **Satu lebih atau satu kurang.** `i <= JUMLAH_LED` menjalankan satu putaran lebih banyak daripada `i < JUMLAH_LED`; pada larik atau pin, itu berarti mengakses benda yang tidak ada.
- **Lupa mengubah syarat `while`.** Syarat tidak pernah salah, jadi program tidak keluar dari perulangan. Pada papan, program tampak "membeku".
- **Titik koma setelah `for (...)`.** `for (...);` membuat badannya kosong, dan blok di bawahnya hanya jalan sekali.
- **`Serial.begin` terlupa atau kecepatannya beda.** Monitor kosong atau menampilkan huruf acak.
- **Mengira cetakan serial mengubah rangkaian.** `Serial.println` hanya mengirim teks ke komputer; ia tidak menyalakan atau mematikan apa pun.

## Kunci dan petunjuk

**Ingat kembali.** 1: baris (A, B) (0,0), (0,1), (1,0), (1,1) menjadi 0, 0, 0, 1. 2: 0,25 detik. 3: 8 + 2 + 1 = 11. 4: `if (a_ditekan || b_ditekan)` dengan `a_ditekan` = `digitalRead(PIN_A) == LOW`; boleh juga ditulis langsung `digitalRead(PIN_A) == LOW || digitalRead(PIN_B) == LOW`.

**Prediksi dulu.** 1: 1, 3, 5, 7 (satu angka per baris). 2: empat kali. 3: tidak ada yang tercetak lagi; `loop()` kosong terus diulang tanpa melakukan apa pun. 4: 1, 3, 5.

**Contoh setengah jadi.** Isian berurutan: `JUMLAH_LED - 2`, `HIGH`. Dengan tiga LED, putaran mundur hanya menyalakan LED nomor 1, sehingga urutannya 0, 1, 2, 1.

**Soal Parsons.** Urutan benar: c, f, d, b, e, g, a. Baris (e) menutup `for`; baris (g) menutup `setup`; baris (a) adalah `loop()` kosong.

**Latihan.** 1: pseudocode: untuk n dari 5 turun sampai 1: cetak n; lalu cetak 0. Program: `for (int n = 5; n >= 1; n--) { Serial.println(n); }` lalu `Serial.println(0);` di dalam `setup()` setelah `Serial.begin`. 2: `i` bernilai 2, 5, 8, 11; badan dijalankan empat kali (14 sudah tidak memenuhi `i < 12`). 3: pin `PIN_AWAL + 3` (pin 19 pada contoh) ikut dinyalakan, tidak ada LED di sana; baris cetak `i=3` memperlihatkannya. Catatan galat contoh: "Pencacah berjalan dari 0 sampai 3 karena `<=`; seharusnya `<`."

**Latihan bercampur.** 1: hasil (0,0) menjadi 0; (0,1) menjadi 1; (1,0) menjadi 1; (1,1) menjadi 0; deret bit 0110. 2: satu putaran 600 ms; 60.000 / 600 = 100 putaran. 3: pencacah dari 0 membuat `PIN_AWAL + 0` menunjuk pin pertama; menambah 1 menunjuk pin berikutnya, jadi nomor pin dan pencacah sama-sama mulai dari awal.

**Ulang berjarak.** 1: lima kali; nilai terakhir 4 (nilai 0, 1, 2, 3, 4). 2: kamu melihat nilai sebenarnya pada tiap langkah, bukan nilai yang kamu kira. 3: `for (int n = 5; n >= 1; n--)`.
