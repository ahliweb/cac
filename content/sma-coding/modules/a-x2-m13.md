## Rencana proyek

Tabel adalah baris-baris data dengan kolom yang sama. Pekerjaan yang umum: urutkan, cari satu baris, dan rekap. Dua hal perlu kamu putuskan sebelum memprogram: cara menyimpan (di sini dua `vector` paralel: `kode[i]` dan `skor[i]` milik baris yang sama) dan urutan kerja (data harus terurut menurut kolom pencarian sebelum pencarian biner).

Tulis rencana satu halaman dengan tujuh bagian: tujuan, masukan, aturan, keluaran, kriteria selesai, daftar uji, dan **prediksi hasil**. Contoh terselesaikan: tabel skor kuis sintetis.

| Bagian | Isi contoh |
| --- | --- |
| Tujuan | Mengurutkan skor kuis menurut kode peserta, mencari skor satu kode, dan merekap. |
| Masukan | `n`, lalu `n` pasang `kode skor`; lalu `q`, lalu `q` kode yang dicari. |
| Aturan | Urutkan menurut kode (abjad) dengan insertion sort, kedua kolom ikut dipindahkan. Cari kode dengan pencarian biner. Rekap: rata-rata, tertinggi, terendah, dan banyak skor di rentang 0 sampai 59, 60 sampai 79, 80 sampai 100. |
| Keluaran | Tabel terurut, hasil tiap pencarian, dan rekap. Tabel kosong dilaporkan, bukan dihitung. |
| Kriteria selesai | Tiap baris tetap berpasangan setelah diurutkan; jumlah ketiga rentang sama dengan `n`; kode yang tidak ada dilaporkan. |
| Daftar uji | Contoh di bawah; `n = 0`; `n = 1`; kode tak ada; kode pertama dan terakhir; dua skor sama. |
| Prediksi | Tabel terurut `K01` sampai `K07`; `K05` skor 66; `K08` tidak ada; rata-rata 72,0; rentang 2, 2, 3. |

Pseudocode-nya:

```text
baca n; BILA n = 0: cetak "Tabel kosong." lalu selesai
baca n pasang (kode, skor) ke dua vector
urut(kode, skor): insertion sort menurut kode, pindahkan keduanya
cetak tabel
baca q; ULANGI q kali: baca kode; cariKode lewat pencarian biner; cetak skor atau "tidak ada"
rekap: jumlah, rata-rata, tertinggi dan terendah beserta kodenya, banyak per rentang
```

Programnya (batas rentang dalam konstanta bernama):

```cpp
#include <iomanip>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

const int BATAS_RENDAH = 60;
const int BATAS_TINGGI = 80;

void urut(vector<string>& kode, vector<int>& skor) {
  int n = kode.size();
  for (int i = 1; i < n; i++) {
    string k = kode[i];
    int s = skor[i];
    int j = i - 1;
    while (j >= 0 && kode[j] > k) {
      kode[j + 1] = kode[j];
      skor[j + 1] = skor[j];
      j--;
    }
    kode[j + 1] = k;
    skor[j + 1] = s;
  }
}

int cariKode(vector<string>& kode, string yang) {
  int kiri = 0;
  int n = kode.size();
  int kanan = n - 1;
  while (kiri <= kanan) {
    int tengah = kiri + (kanan - kiri) / 2;
    if (kode[tengah] == yang) {
      return tengah;
    } else if (kode[tengah] < yang) {
      kiri = tengah + 1;
    } else {
      kanan = tengah - 1;
    }
  }
  return -1;
}

void rekap(vector<string>& kode, vector<int>& skor) {
  int n = skor.size();
  int jumlah = 0;
  int atas = 0;
  int bawah = 0;
  int rendah = 0;
  int sedang = 0;
  int tinggi = 0;
  for (int i = 0; i < n; i++) {
    jumlah += skor[i];
    if (skor[i] > skor[atas]) {
      atas = i;
    }
    if (skor[i] < skor[bawah]) {
      bawah = i;
    }
    if (skor[i] < BATAS_RENDAH) {
      rendah++;
    } else if (skor[i] < BATAS_TINGGI) {
      sedang++;
    } else {
      tinggi++;
    }
  }
  cout << fixed << setprecision(1);
  cout << "rata-rata " << (double)jumlah / n << ", tertinggi " << kode[atas] << " (" << skor[atas] << "), terendah " << kode[bawah] << " (" << skor[bawah] << ")\n";
  cout << "rentang 0-59: " << rendah << ", 60-79: " << sedang << ", 80-100: " << tinggi << "\n";
}

int main() {
  int n;
  cin >> n;
  if (n == 0) {
    cout << "Tabel kosong.\n";
    return 0;
  }
  vector<string> kode(n);
  vector<int> skor(n);
  for (int i = 0; i < n; i++) {
    cin >> kode[i] >> skor[i];
  }
  urut(kode, skor);
  for (int i = 0; i < n; i++) {
    cout << kode[i] << " " << skor[i] << "\n";
  }
  int q;
  cin >> q;
  for (int j = 0; j < q; j++) {
    string yang;
    cin >> yang;
    int hasil = cariKode(kode, yang);
    if (hasil == -1) {
      cout << yang << ": tidak ada\n";
    } else {
      cout << yang << ": skor " << skor[hasil] << "\n";
    }
  }
  rekap(kode, skor);
}
```

## Kesalahan umum

Untuk 3 pertanyaan: sekuensial 3 x 1000 = 3000 langkah, jauh lebih murah daripada mengurutkan 499.500 langkah. 2: program contoh:

```cpp
#include <iostream>
#include <vector>
using namespace std;

int jumlahSkor(vector<int>& v, int i) {
  int n = v.size();
  if (i >= n) {
    return 0;
  }
  return v[i] + jumlahSkor(v, i + 1);
}

int main() {
  vector<int> v = {85, 91, 72};
  cout << jumlahSkor(v, 0) << "\n";
}
```

```text

```
