**Latihan bercampur.**

1: kunci yang dijalankan:

```js
// urut-bubble.js
function urutBubble(awal) {
  const a = [...awal];
  let tukar = 0;
  for (let putaran = 0; putaran < a.length - 1; putaran++) {
    for (let i = 0; i < a.length - 1 - putaran; i++) {
      if (a[i] > a[i + 1]) {
        const sementara = a[i];
        a[i] = a[i + 1];
        a[i + 1] = sementara;
        tukar++;
      }
    }
  }
  return { hasil: a, tukar: tukar };
}

const asli = [4, 1, 3, 2];
const r = urutBubble(asli);
console.log(r.hasil, r.tukar, asli);
```

```text
[ 1, 2, 3, 4 ] 4 [ 4, 1, 3, 2 ]
```

Rubrik soal 1, empat hal: ketepatan (hasil dan 4 pertukaran), keterbacaan, pengujian (data diuji dan hasil dicatat), dan justifikasi (alasan menyalin array dulu). Skala per hal: sudah, sebagian, belum.

2: untuk `58`: `kiri 0, kanan 7, tengah 3` (22, lebih kecil) maka `kiri 4`; `tengah 5` (40, lebih kecil) maka `kiri 6`; `tengah 6` (58) ketemu di indeks 6 pada langkah ketiga. Untuk `20`: `kiri 0, kanan 7, tengah 3` (22, lebih besar) maka `kanan 2`; `tengah 1` (9, lebih kecil) maka `kiri 2`; `tengah 2` (15, lebih kecil) maka `kiri 3`; sekarang `kiri > kanan`, hasil -1 pada langkah ketiga.

3: kunci yang dijalankan:

```js
// bersihkan.js
const mentah = [
  { id: 1, nama: " Ani-contoh ", nilai: "80" },
  { id: 2, nama: "Beni-contoh", nilai: 120 },
  { id: 3, nama: "", nilai: 75 },
  { id: 1, nama: "Ani-contoh", nilai: 80 },
  { id: 5, nama: "Cici-contoh", nilai: "tujuh" },
  { id: 6, nama: "Dedi-contoh", nilai: 65 },
];

function bersihkan(daftar) {
  const bersih = [];
  const ditolak = [];
  const dilihat = new Set();
  for (const b of daftar) {
    const nama = String(b.nama).trim();
    const nilai = b.nilai === "" || b.nilai === null ? NaN : Number(b.nilai);
    if (dilihat.has(b.id)) {
      continue;
    }
    dilihat.add(b.id);
    if (nama === "" || Number.isNaN(nilai) || nilai < 0 || nilai > 100) {
      ditolak.push(b.id);
    } else {
      bersih.push({ id: b.id, nama: nama, nilai: nilai });
    }
  }
  return { bersih: bersih, ditolak: ditolak };
}

const h = bersihkan(mentah);
console.log(h.bersih.map((b) => b.id + " " + b.nama + " " + b.nilai));
console.log("ditolak:", h.ditolak);
```

```text
[ "1 Ani-contoh 80", "6 Dedi-contoh 65" ]
ditolak: [ 2, 3, 5 ]
```

Id 2 ditolak (120 di luar rentang), id 3 (nama kosong), id 5 (`"tujuh"` bukan angka); `id` 1 yang kedua diabaikan sebagai duplikat. Rubrik: ketepatan, penanganan nilai kosong, pengujian, dan justifikasi (mengapa baris tidak pasti ditolak, bukan ditebak).
