## Latihan bercampur

1. **Tulis.** Tulis pseudocode lalu program: baca `n`, lalu baca `n` bilangan bulat; cetak jumlah bilangan genap dan banyaknya bilangan ganjil. Pakai fungsi `bool genap(int x)`.
2. **Telusuri.** Program berikut dijalankan. Apa yang tercetak? Tulis tabel penelusuran `i` dan `s` untuk `f(1, 10)`.

   ```cpp
   #include <iostream>
   using namespace std;

   int f(int a, int b) {
     int s = 0;
     for (int i = a; i <= b; i++) {
       if (i % 3 == 0) {
         continue;
       }
       s += i;
     }
     return s;
   }

   int main() {
     cout << f(1, 10) << "\n";
   }
   ```

3. **Cari galat.** Potongan berikut sengaja salah dan maksudnya menghitung rata-rata 1 sampai `n`. Tulis tiga galat, akibatnya, dan perbaikannya.

   ```text
   int jumlah;
   for (int i = 1; i < n; i++) {
     jumlah += i;
   }
   cout << jumlah / n;
   ```

4. **Praktik.** Kompilasi programmu dari nomor 1 dengan `g++ -std=c++17 -Wall -Wextra` dan jalankan dengan masukan dari berkas. Tulis dua uji yang kamu pilih, satu di antaranya `n = 0`, beserta hasil yang kamu prediksi.
5. **Kuis konsep fondasi (formatif).** (a) Dari CPU, RAM, dan SSD, mana yang isinya hilang bila listrik mati? (b) Berapa bit panjang alamat IPv4 seperti `192.0.2.10`, dan mengapa tiap bagiannya paling besar 255? (c) Sebutkan dua kebiasaan untuk mengamankan akun.

## Kunci dan petunjuk

**Ingat kembali.** 1: galat paling sering muncul tepat di batas, misalnya `<` yang seharusnya `<=`. 2: `break` menghentikan seluruh perulangan; `continue` hanya melewati sisa putaran itu. 3: 11010 biner = 16 + 8 + 2 = 26 desimal = 1A heksadesimal. 4: "gratis" soal harga; "sumber terbuka" soal kode yang boleh dilihat dan diubah menurut lisensinya. 5: data yang sudah dikirim sulit ditarik kembali, dan kunci atau kata sandi bisa disalahgunakan.

**Latihan bercampur.** 1: pseudocode: baca n; jumlahGenap <- 0; banyakGanjil <- 0; ulangi n kali: baca x; BILA genap(x): jumlahGenap <- jumlahGenap + x; JIKA TIDAK: banyakGanjil <- banyakGanjil + 1; cetak keduanya. Program contoh:

```cpp
#include <iostream>
using namespace std;

bool genap(int x) {
  return x % 2 == 0;
}

int main() {
  int n;
  cin >> n;
  long long jumlahGenap = 0;
  int banyakGanjil = 0;
  for (int i = 0; i < n; i++) {
    int x;
    cin >> x;
    if (genap(x)) {
      jumlahGenap += x;
    } else {
      banyakGanjil++;
    }
  }
  cout << "jumlah genap = " << jumlahGenap << ", banyak ganjil = " << banyakGanjil << "\n";
}
```

Masukan (`masukan.txt`):

```text
5 4 7 10 3 8
```

Keluaran:

```text
jumlah genap = 22, banyak ganjil = 2
```

2: `f(1, 10)` menjumlahkan 1 sampai 10 kecuali kelipatan 3. Nilai `i` yang masuk ke `s`: 1, 2, 4, 5, 7, 8, 10, sehingga `s` bertahap 1, 3, 7, 12, 19, 27, 37. Keluarannya:

```text
37
```

3: galat pertama `jumlah` tidak diberi nilai awal sehingga hasilnya tak terduga; perbaikan `int jumlah = 0;`. Galat kedua `i < n` melewatkan `n`; perbaikan `i <= n`. Galat ketiga `jumlah / n` adalah pembagian bulat dan membuang pecahan; perbaikan `(double)jumlah / n` atau menjadikan `jumlah` bertipe `double`. 4: contoh uji: masukan `5 4 7 10 3 8` dengan prediksi `jumlah genap = 22, banyak ganjil = 2`; masukan `0` dengan prediksi `jumlah genap = 0, banyak ganjil = 0`. Bila memakai `g++` dan ada peringatan, baca dan perbaiki. 5: (a) RAM. (b) 32 bit, karena empat bagian masing-masing satu byte (8 bit); satu byte paling besar 255. (c) contoh: kata sandi panjang dan unik dengan manajer kata sandi; autentikasi dua langkah.

**Rubrik singkat.** Untuk soal 1 dan 4, periksa empat hal: ketepatan (program memenuhi tujuan), keterbacaan (nama dan fungsi jelas), pengujian (disebut cara mengujinya, termasuk nilai batas), dan justifikasi (alasan pilihan). Skala yang disarankan: sudah, sebagian, belum, per hal. Untuk soal 2, 3, dan 5, jawaban dinilai benar bila angka dan alasan sama dengan kunci.

**Refleksi.** Tidak ada kunci. Jawaban yang baik menyebut bukti, bagian yang lemah, dan rencana yang jelas waktunya.
