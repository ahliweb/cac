## Kunci dan petunjuk

**Ingat kembali.** 1: bila hanya satu kolom yang dipindahkan, baris tabel tidak lagi cocok: skor akan terlepas dari kodenya. 2: tanpa kasus dasar fungsi memanggil dirinya tanpa henti; tiap panggilan menambah satu bingkai di tumpukan pemanggilan sampai memori tumpukan habis. 3: ukurannya dapat tumbuh dan menyusut, dan punya `size()`, `push_back`, dan `pop_back`; kamu tetap menjaga indeks agar tidak keluar dari 0 sampai `size() - 1`. 4: sangat cepat bila data sudah hampir terurut (sedikit geseran); paling lambat bila data terbalik urutannya. 5: data harus terurut, karena membuang separuh rentang hanya sah bila kamu tahu arah elemen yang dicari.

**Latihan bercampur.**

1: pseudocode: `BUAT TUMPUKAN KOSONG; UNTUK TIAP HURUF c: JIKA c = '#' DAN TUMPUKAN TIDAK KOSONG, BUANG ATAS; JIKA c BUKAN '#', MASUKKAN c; SUSUN ISI TUMPUKAN DARI BAWAH KE ATAS DAN CETAK`. Program contoh:

```cpp
#include <iostream>
#include <stack>
#include <string>
using namespace std;

int main() {
  string perintah;
  cin >> perintah;
  stack<char> s;
  for (char c : perintah) {
    if (c == '#') {
      if (!s.empty()) {
        s.pop();
      }
    } else {
      s.push(c);
    }
  }
  string hasil;
  while (!s.empty()) {
    hasil = s.top() + hasil;
    s.pop();
  }
  cout << hasil << "\n";
}
```

Masukan (`masukan.txt`) `ab#c`:

```text

```

Untuk `##x#` keluarannya baris kosong, karena `#` pertama dan kedua tidak berbuat apa-apa pada teks kosong, `x` masuk, dan `#` terakhir membuangnya. Untuk `kode#aa##` keluarannya `kod`. Periksa `empty()` sebelum `pop()` dan `top()`.

2: isi `a` mula-mula 5 2 4 1. Tukar pertama (5 dan 2): 2 5 4 1. Tukar kedua (5 dan 4): 2 4 5 1. Tukar ketiga (5 dan 1): 2 4 1 5. Tercetak `2 4 1 5 ` lalu `3` pada baris berikutnya (program dijalankan penyusun). Elemen terbesar, 5, pasti sudah di tempat akhirnya setelah satu putaran penuh; isi lainnya belum terurut.

3: galat pertama, `kanan = a.size()` melewati indeks terakhir yang sah (`size() - 1`), sehingga `a[tengah]` dapat membaca di luar larik; perbaikannya `(int)a.size() - 1`. Galat kedua, `a[tengah] = x` adalah penugasan: ia menimpa elemen dan bernilai benar bila `x` bukan 0; perbaikannya `==`. Galat ketiga, `kiri = tengah` tidak menggeser batas, sehingga untuk dua elemen perulangan dapat tak berhenti; perbaikannya `tengah + 1`. Versi benar:

```cpp
#include <iostream>
#include <vector>
using namespace std;

int cari(const vector<int>& a, int x) {
  int kiri = 0;
  int kanan = (int)a.size() - 1;
  while (kiri <= kanan) {
    int tengah = (kiri + kanan) / 2;
    if (a[tengah] == x) {
      return tengah;
    } else if (a[tengah] < x) {
      kiri = tengah + 1;
    } else {
      kanan = tengah - 1;
    }
  }
  return -1;
}

int main() {
  vector<int> a = {2, 5, 9, 14, 20, 31};
  cout << cari(a, 14) << " " << cari(a, 2) << " " << cari(a, 31) << " " << cari(a, 7) << "\n";
}
```

```text
3 0 5 -1
```

4: (a) `queue`, karena yang datang pertama dilayani pertama (FIFO); (b) `stack`, karena halaman terakhir yang dibuka adalah yang pertama dikembalikan (LIFO); (c) `vector`, karena perlu akses lewat indeks untuk diurutkan dan dicari. Pencarian sekuensial paling banyak 1000 langkah; pencarian biner sekitar 10 langkah, karena 2 pangkat 10 adalah 1024. Bubble sort tanpa penghenti dini melakukan n(n - 1)/2 perbandingan: 499500 untuk 1000 data dan 1999000 untuk 2000 data, sekitar 4 kali lipat; data menjadi 2 kali lipat, langkahnya menjadi sekitar kuadratnya.

5: rubrik singkat (sudah, sebagian, belum): ketepatan (hasil terurut menurun benar, kode ikut berpindah), ketekunan menguji (kedua nilai `x` diuji), pesan untuk skor yang tidak ada, dan keterbacaan. Program contoh:

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
  int n;
  cin >> n;
  vector<string> kode(n);
  vector<int> skor(n);
  for (int i = 0; i < n; i++) {
    cin >> kode[i] >> skor[i];
  }
  for (int i = 1; i < n; i++) {
    string k = kode[i];
    int s = skor[i];
    int j = i - 1;
    while (j >= 0 && skor[j] < s) {
      kode[j + 1] = kode[j];
      skor[j + 1] = skor[j];
      j--;
    }
    kode[j + 1] = k;
    skor[j + 1] = s;
  }
  for (int i = 0; i < n; i++) {
    cout << kode[i] << " " << skor[i] << "\n";
  }
  int x;
  cin >> x;
  int posisi = -1;
  for (int i = 0; i < n; i++) {
    if (skor[i] == x) {
      posisi = i;
      break;
    }
  }
  if (posisi == -1) {
    cout << "skor " << x << " tidak ada\n";
  } else {
    cout << "skor " << x << " dimiliki " << kode[posisi] << "\n";
  }
}
```

6: kasus dasar: `n < 10` mengembalikan `n`. Langkah rekursif: `n % 10 + jumlahDigit(n / 10)`. Telusuri: `jumlahDigit(4096)` = 6 + `jumlahDigit(409)` = 6 + 9 + `jumlahDigit(40)` = 6 + 9 + 0 + `jumlahDigit(4)` = 6 + 9 + 0 + 4 = 19. Program contoh:

```cpp
#include <iostream>
using namespace std;

int jumlahDigit(int n) {
  if (n < 10) {
    return n;
  }
  return n % 10 + jumlahDigit(n / 10);
}

int main() {
  cout << jumlahDigit(7) << " " << jumlahDigit(4096) << "\n";
}
```

```text
7 19
```
