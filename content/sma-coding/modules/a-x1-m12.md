**Fungsi** adalah potongan program bernama yang dipanggil dari tempat lain. Bentuknya `tipe_kembalian nama(tipe parameter, ...) { ... }`. **Parameter** adalah nama di definisi fungsi (`x`); **argumen** adalah nilai yang diberikan saat memanggil (`n`, atau `n + 1`). `return` mengirim nilai kembali dan mengakhiri fungsi; fungsi `void` tidak mengembalikan nilai. Secara bawaan argumen **disalin**: `a` di `ubah` adalah salinan, sehingga mengubahnya tidak mengubah `n`. Variabel yang dibuat di dalam fungsi hanya hidup di dalam fungsi itu.

Bila sebuah parameter ditulis dengan `&` (misalnya `int& a`), fungsi bekerja pada variabel aslinya. Itu cara menukar dua nilai (modul `a-x1-m8`) di dalam fungsi:

```cpp
#include <iostream>
using namespace std;

void tukar(int& a, int& b) {
  int sementara = a;
  a = b;
  b = sementara;
}

int main() {
  int x = 7;
  int y = 3;
  tukar(x, y);
  cout << "x = " << x << ", y = " << y << "\n";
}
```

Keluaran:

```text
x = 3, y = 7
```

Faktorial n adalah 1 x 2 x ... x n. Hasilnya cepat membesar; `long long` cukup sampai 20! (2.432.902.008.176.640.000), sedangkan 21! sudah melewati batas `long long` (9.223.372.036.854.775.807).

```cpp
#include <iostream>
using namespace std;

long long faktorial(int n) {
  long long hasil = 1;
  for (int i = 2; i <= n; i++) {
    hasil *= i;
  }
  return hasil;
}

int main() {
  int n;
  cin >> n;
  cout << n << "! = " << faktorial(n) << "\n";
}
```

Masukan (`masukan.txt`):

```text
20
```

Keluaran:

```text
20! = 2432902008176640000
```

FPB (faktor persekutuan terbesar) dengan algoritma Euclid: selama `b` bukan 0, ganti pasangan `(a, b)` dengan `(b, a % b)`; saat `b` menjadi 0, jawabannya `a`. Penelusuran untuk 84 dan 36:

| langkah | a | b | `a % b` |
| --- | --- | --- | --- |
| 1 | 84 | 36 | 12 |
| 2 | 36 | 12 | 0 |
| selesai | 12 | 0 | |

```cpp
#include <iostream>
using namespace std;

int fpb(int a, int b) {
  while (b != 0) {
    int sisa = a % b;
    a = b;
    b = sisa;
  }
  return a;
}

int main() {
  int a, b;
  cin >> a >> b;
  cout << "FPB(" << a << ", " << b << ") = " << fpb(a, b) << "\n";
}
```

Masukan (`masukan.txt`):

```text
84 36
```

Keluaran:

```text
FPB(84, 36) = 12
```

## Soal Parsons

Susun baris-baris berikut (sudah diacak) menjadi program yang mencetak keliling persegi panjang 7 kali 3 lewat fungsi. Baris (b) dan (h) sama, jadi boleh bertukar tempat. `AI: tanpa AI`: tujuannya melatih membaca urutan program.

```text
(a) int main() {
(b) }
(c)   cout << keliling(7, 3) << "\n";
(d) using namespace std;
(e) int keliling(int p, int l) {
(f)   return 2 * (p + l);
```

## Latihan

## Kesalahan umum

- **Mengira argumen yang diubah di fungsi ikut berubah di luar.** Tanpa `&`, fungsi bekerja pada salinan.
- **Lupa `return`.** Fungsi bernilai kembalian yang tidak mengembalikan apa pun menghasilkan nilai tak terduga; kompilator biasanya memberi peringatan, jadi baca peringatannya.
- **Memanggil fungsi sebelum didefinisikan.** Letakkan definisi di atas `main`, atau tulis deklarasinya lebih dulu.
- **Memakai tipe yang terlalu kecil untuk hasil.** Faktorial melewati batas `int` dengan cepat; pakai `long long`.
- **Satu fungsi mengerjakan banyak hal.** Fungsi yang membaca, menghitung, dan mencetak sekaligus sulit diuji; pisahkan.

**Soal Parsons.** Urutan benar: g, d, e, f, b, a, c, h (atau dengan (b) dan (h) bertukar). Fungsi `keliling` harus berada di atas `main`.

**Latihan.** 1: pseudocode: fungsi jumlahDeret(n): jumlah <- 0; untuk i dari 1 sampai n: jumlah <- jumlah + i; kembalikan jumlah. Program contoh:

```cpp
#include <iostream>
using namespace std;

long long jumlahDeret(int n) {
  long long jumlah = 0;
  for (int i = 1; i <= n; i++) {
    jumlah += i;
  }
  return jumlah;
}

int main() {
  int n;
  cin >> n;
  cout << jumlahDeret(n) << "\n";
}
```

Masukan (`masukan.txt`):

```text
100
```

Keluaran:

```text
5050
```

2: `fpb(48, 18)`: (48, 18) sisa 12; (18, 12) sisa 6; (12, 6) sisa 0; hasil 6. `fpb(7, 0)` langsung mengembalikan 7 karena `b` sudah 0. 3: program contoh:

```cpp
#include <iostream>
using namespace std;

bool prima(int n) {
  if (n < 2) {
    return false;
  }
  for (int i = 2; i * i <= n; i++) {
    if (n % i == 0) {
      return false;
    }
  }
  return true;
}

int main() {
  for (int n = 2; n <= 30; n++) {
    if (prima(n)) {
      cout << n << " ";
    }
  }
  cout << "\n";
}
```


```cpp
#include <iostream>
```

**Latihan bercampur.** 1: contoh: `if (skor >= 85) { return 'A'; } if (skor >= 70) { return 'B'; } return 'C';`. 2: `for (int i = 1; i <= 5; i++) { cout << i << "! = " << faktorial(i) << "\n"; }`; hasil 1, 2, 6, 24, 120. 3: `rata(7, 4)` memberi 5,5 karena `(x + y) / 2` dihitung dengan `double`; dengan `int` hasilnya 5.

**Ulang berjarak.** 1: parameter adalah nama di definisi fungsi; argumen adalah nilai yang diberikan saat memanggil. 2: bila fungsi harus mengubah variabel aslinya (atau menghindari menyalin data besar). 3: contoh: tiap bagian bisa diuji sendiri dan dipakai ulang; program lebih mudah dibaca.
