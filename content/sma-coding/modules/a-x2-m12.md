```cpp
#include <iostream>
using namespace std;

void hitung(int n, int& satu, int& dua) {
  satu = 0;
  dua = 0;
  for (int i = 1; i <= n; i++) {
    satu++;
  }

  hitung(20, satu, dua);

}
```

## Contoh terselesaikan

Keluaran program tadi:

Keluaran:

```text
n = 10: 10 55
n = 20: 20 210
```

Perulangan tunggal menghitung `n` kali. Perulangan bersarang menghitung `1 + 2 + ... + n = n * (n + 1) / 2` kali: 55 untuk `n = 10` dan 210 untuk `n = 20`. Dua kali lebih besar `n` membuat angka pertama dua kali lebih besar, tetapi angka kedua hampir empat kali lebih besar (210 dibanding 55). Itulah beda **naik secara linear** dan **naik secara kuadrat**.

Mengapa menghitung langkah, bukan detik? Detik bergantung pada mesin dan beban lain; langkah hanya bergantung pada algoritma dan data. Berikut masalah karangan: apakah sebuah deretan `n` bilangan memuat dua bilangan yang sama? **Cara pasangan** membandingkan setiap pasangan `i < j`. **Cara penanda** memakai larik penanda, satu sel per kemungkinan nilai: tiap bilangan cukup diperiksa dan ditandai satu kali. Data karangan berikut tidak memuat bilangan kembar, sehingga kasus terburuk terjadi: kedua cara memeriksa semuanya.

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
  int ukuran[3] = {100, 1000, 10000};
  for (int k = 0; k < 3; k++) {
    int n = ukuran[k];
    vector<int> v(n);
    for (int i = 0; i < n; i++) {
      v[i] = (i * 7) % 100003;
    }
    long long langkahPasangan = 0;
    bool kembar1 = false;
    for (int i = 0; i < n; i++) {
      for (int j = i + 1; j < n; j++) {
        langkahPasangan++;
        if (v[i] == v[j]) {
          kembar1 = true;
        }
      }
    }
    vector<bool> ada(100003, false);
    long long langkahPenanda = 0;
    bool kembar2 = false;
    for (int i = 0; i < n; i++) {
      langkahPenanda++;
      if (ada[v[i]]) {
        kembar2 = true;
      }
      ada[v[i]] = true;
    }
    cout << "n = " << n << ": pasangan " << langkahPasangan << " langkah, penanda " << langkahPenanda << " langkah, kembar: " << (kembar1 ? "ya" : "tidak") << "/" << (kembar2 ? "ya" : "tidak") << "\n";
  }
}
```

Keluaran:

```text
n = 100: pasangan 4950 langkah, penanda 100 langkah, kembar: tidak/tidak
n = 1000: pasangan 499500 langkah, penanda 1000 langkah, kembar: tidak/tidak
n = 10000: pasangan 49995000 langkah, penanda 10000 langkah, kembar: tidak/tidak
```

Keduanya menjawab sama, tetapi dengan harga yang sangat berbeda. Cara penanda membayar dengan memori untuk larik 100003 sel: efisiensi sering menukar satu sumber daya dengan yang lain.

Para pemrogram merangkum pertumbuhan itu dengan **notasi O-besar**: abaikan konstanta dan suku yang kecil, lalu tulis bentuk yang menentukan saat `n` besar. Cara pasangan melakukan `n * (n - 1) / 2` langkah, sekitar setengah `n` kuadrat; konstanta setengah dibuang, sehingga ia `O(n^2)`, dibaca "O besar n kuadrat". Cara penanda `O(n)`. Secara intuitif, `O(f(n))` berarti: untuk `n` besar, langkahnya tidak tumbuh lebih cepat daripada kelipatan `f(n)`. Keluarga yang akan sering kamu temui:

| Bentuk | Arti intuitif | Contoh dari modul sebelumnya |
| --- | --- | --- |
| `O(1)` | tetap, tidak bergantung `n` | membaca `a[i]` |
| `O(log n)` | bertambah satu langkah tiap data berlipat dua | pencarian biner |
| `O(n)` | sebanding dengan `n` | pencarian sekuensial, satu putaran bubble sort |
| `O(n^2)` | `n` 10 kali lebih besar, langkah sekitar 100 kali | bubble sort, insertion sort (kasus terburuk) |
| `O(2^n)` | `n` naik satu, langkah berlipat | Fibonacci rekursif sederhana (pendekatan kasar) |

Program berikut menghitung angka-angkanya supaya terasa bedanya.

```cpp
#include <cmath>
#include <iomanip>
#include <iostream>
using namespace std;

int main() {
  cout << fixed << setprecision(1);
  long long ukuran[4] = {10, 100, 1000, 1000000};
  for (int k = 0; k < 4; k++) {
    long long n = ukuran[k];
    cout << "n = " << n << ": log2 " << log2(n) << ", n kuadrat " << n * n << "\n";
  }
  long long p = 1;
  for (int n = 1; n <= 40; n++) {
    p = p * 2;
    if (n % 10 == 0) {
      cout << "2^" << n << " = " << p << "\n";
    }
  }
}
```

Keluaran:

```text
n = 10: log2 3.3, n kuadrat 100
n = 100: log2 6.6, n kuadrat 10000
n = 1000: log2 10.0, n kuadrat 1000000
n = 1000000: log2 19.9, n kuadrat 1000000000000
2^10 = 1024
2^20 = 1048576
2^30 = 1073741824
2^40 = 1099511627776
```

Pedoman kasar yang sering dipakai (bukan janji; bergantung mesin dan kodenya): komputer biasa mengerjakan sekitar seratus juta operasi sederhana per detik. Untuk `n = 1000000`, cara `O(n^2)` memerlukan sekitar 10^12 langkah, jauh melewati batas itu, sedangkan `O(n)` dan `O(log n)` selesai seketika. Notasi O-besar hanya perkiraan pola pertumbuhan, bukan hitungan persis. Bacaan pendamping yang lebih matematis: modul `matkom-pertumbuhan-fungsi`.

## Kesalahan umum

- **Menghitung detik, bukan langkah.** Waktu satu kali jalan bergantung pada mesin dan beban lain; untuk membandingkan algoritma, hitung langkahnya pada `n` yang berbeda.
- **Mengira `O(n^2)` berarti persis `n^2` langkah.** Ia hanya menyatakan pola pertumbuhan; konstanta dan suku kecil dibuang.
- **Menganggap `O(n)` selalu lebih cepat dari `O(n^2)` untuk semua `n`.** Untuk `n` kecil, cara yang konstantanya besar bisa lebih lambat; pola pertumbuhan baru menentukan pada `n` besar.
- **Salah menggabungkan perulangan.** Perulangan bersarang mengalikan langkah; dua perulangan berurutan menjumlahkannya.
- **Melupakan kasus terbaik dan terburuk.** Satu algoritma bisa cepat pada satu bentuk data dan lambat pada bentuk lain; sebutkan datanya.

**Soal Parsons.** Urutan benar: a, b, c, d, e, f, g. Baris (e) menutup perulangan dalam dan (f) menutup perulangan luar.

**Latihan.** 1: satu perulangan: `n` langkah. Rumus: satu langkah. Perulangan bersarang: `n * (n + 1) / 2` langkah. Program contoh:

```cpp
#include <iostream>
using namespace std;

int main() {
  int ukuran[3] = {10, 100, 1000};
  for (int k = 0; k < 3; k++) {
    int n = ukuran[k];
    long long a = 0;
    long long jumlah1 = 0;
    for (int i = 1; i <= n; i++) {
      jumlah1 += i;
      a++;
    }
    long long jumlah2 = (long long)n * (n + 1) / 2;
    long long c = 0;
    long long jumlah3 = 0;
    for (int i = 1; i <= n; i++) {
      for (int j = 1; j <= i; j++) {
        jumlah3++;
        c++;
      }
    }
    cout << "n = " << n << ": loop " << a << ", rumus 1, bersarang " << c << " (hasil " << jumlah1 << " " << jumlah2 << " " << jumlah3 << ")\n";

}
```

Keluaran:

```text

n = 100: loop 100, rumus 1, bersarang 5050 (hasil 5050 5050 5050)
n = 1000: loop 1000, rumus 1, bersarang 500500 (hasil 500500 500500 500500)
```

Ketiganya benar; yang berbeda harganya. 2: (a) tetap, dua pengambilan tanpa perulangan. (b) linear: `n` pengulangan. (c) kuadrat: `n` kali `n` perbandingan.
