Pada **insertion sort**, bagian kiri `v[0..i-1]` selalu sudah terurut. Untuk tiap `i`, elemen `v[i]` diambil dan disimpan di `x`. Elemen di kiri yang lebih besar dari `x` digeser satu tempat ke kanan, lalu `x` dimasukkan ke lubang yang tersisa. Kamu wajib menyimpan `x` dulu: bila tidak, geseran pertama menimpa `v[i]`. Urutan syarat `j >= 0 && v[j] > x` juga penting: `j >= 0` diperiksa lebih dulu, sehingga `v[-1]` tidak pernah dibaca. Program berikut mengurutkan data dari masukan dan menghitung geseran.

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
  int n;
  cin >> n;
  vector<int> v(n);
  for (int i = 0; i < n; i++) {
    cin >> v[i];
  }
  int geseran = 0;
  for (int i = 1; i < n; i++) {
    int x = v[i];
    int j = i - 1;
    while (j >= 0 && v[j] > x) {
      v[j + 1] = v[j];
      j--;
      geseran++;
    }
    v[j + 1] = x;
  }
  for (int i = 0; i < n; i++) {
    if (i > 0) {
      cout << " ";
    }
    cout << v[i];
  }
  cout << "\n" << "geseran: " << geseran << "\n";
}
```

Masukan (`masukan.txt`):

```text
6
8 3 7 1 9 2
```

Keluaran:

```text
1 2 3 7 8 9
geseran: 9
```

Banyak geseran sama dengan banyak pasangan yang urutannya terbalik pada data awal, sama seperti banyak pertukaran bubble sort. Lalu mengapa orang memilih salah satunya? Program berikut membandingkan banyak perbandingan kedua cara pada tiga data berukuran 200: data acak sintetis, data hampir terurut (sepuluh pasangan bertetangga dibalik), dan data terbalik. Tiap pemeriksaan `v[j] > x` dihitung satu perbandingan. Fungsi menerima salinan `vector` (tanpa `&`) agar data yang sama dapat dipakai dua kali.

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

void bubble(vector<int> v, long long& banding) {
  int n = v.size();
  banding = 0;
  for (int putaran = 1; putaran < n; putaran++) {
    bool adaTukar = false;
    for (int j = 0; j < n - putaran; j++) {
      banding++;
      if (v[j] > v[j + 1]) {
        int t = v[j];
        v[j] = v[j + 1];
        v[j + 1] = t;
        adaTukar = true;
      }
    }
    if (!adaTukar) {
      break;
    }
  }
}

void sisip(vector<int> v, long long& banding) {
  int n = v.size();
  banding = 0;
  for (int i = 1; i < n; i++) {
    int x = v[i];
    int j = i - 1;
    while (j >= 0) {
      banding++;
      if (v[j] <= x) {
        break;
      }
      v[j + 1] = v[j];
      j--;
    }
    v[j + 1] = x;
  }
}

int main() {
  int n = 200;
  vector<int> acak(n), hampir(n), terbalik(n);
  for (int i = 0; i < n; i++) {
    acak[i] = (i * 7919) % 1009;
    hampir[i] = i;
    terbalik[i] = n - i;
  }
  for (int i = 0; i + 1 < n; i += 20) {
    int t = hampir[i];
    hampir[i] = hampir[i + 1];
    hampir[i + 1] = t;
  }
  vector<int> data[3] = {acak, hampir, terbalik};
  string nama[3] = {"acak", "hampir terurut", "terbalik"};
  for (int k = 0; k < 3; k++) {
    long long b1, b2;
    bubble(data[k], b1);
    sisip(data[k], b2);
    cout << nama[k] << ": bubble " << b1 << ", insertion " << b2 << "\n";
  }
}
```

Keluaran:

```text
acak: bubble 19795, insertion 10324
hampir terurut: bubble 397, insertion 208
terbalik: bubble 19900, insertion 19900
```

Pada data hampir terurut, insertion sort hanya sedikit di atas `n - 1` perbandingan karena tiap elemen hanya digeser satu atau dua tempat. Pada data acak, insertion sort sekitar separuh perbandingan bubble sort. Pada data terbalik keduanya sama buruk: sekitar `n * (n - 1) / 2`, naik secara kuadrat. Jadi tidak ada pengurut terbaik untuk semua data; pilihan bergantung pada bentuk data.

## Kesalahan umum

- **Menulis syarat `v[j] > x && j >= 0`.** Untuk `j = -1`, `v[j]` dibaca sebelum `j >= 0` diperiksa. Selalu tulis `j >= 0` lebih dulu.
- **Tidak menyimpan `x`.** Geseran pertama menimpa `v[i]`, sehingga nilai yang akan disisipkan hilang.
- **Menulis `v[j] = x` di akhir.** Setelah perulangan, `j` berada satu tempat di kiri lubang; lubangnya `v[j + 1]`.
- **Memulai dari `i = 0`.** Satu elemen sudah terurut dengan sendirinya; mulai dari `i = 1`.
- **Menganggap insertion sort selalu lebih cepat dari bubble sort.** Pada data terbalik keduanya sama banyaknya.

Insertion sort memeriksa 6 kali (satu per elemen dari `i = 1`, ditambah satu pemeriksaan lagi saat 3 bertemu 4 dan 2); bubble sort memerlukan satu putaran penuh (5 perbandingan) dan satu putaran lagi (4 perbandingan) untuk memastikan tidak ada pertukaran, jadi 9. Buktinya:

```cpp
#include <iostream>
#include <vector>
using namespace std;

void bubble(vector<int> v, int& banding) {
  int n = v.size();
  banding = 0;
  for (int putaran = 1; putaran < n; putaran++) {
    bool adaTukar = false;
    for (int j = 0; j < n - putaran; j++) {
      banding++;
      if (v[j] > v[j + 1]) {
        int t = v[j];
        v[j] = v[j + 1];
        v[j + 1] = t;
        adaTukar = true;
      }
    }
    if (!adaTukar) {
      break;
    }
  }
}

void sisip(vector<int> v, int& banding) {
  int n = v.size();
  banding = 0;
  for (int i = 1; i < n; i++) {
    int x = v[i];
    int j = i - 1;
    while (j >= 0) {
      banding++;
      if (v[j] <= x) {
        break;
      }
      v[j + 1] = v[j];
      j--;
    }
    v[j + 1] = x;
  }
}
```

4: program contoh (dua `vector` dipindahkan bersama; geser dilakukan bila skor di kiri **lebih kecil**, sehingga yang sama-sama 85 tidak saling melewati):

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
  int n;
  cin >> n;
  vector<string> kode(n);
  vector<int> skor(n);
  for (int i = 0; i < n; i++) {
    cin >> kode[i] >> skor[i];
  }
  for (int i = 1; i < n; i++) {
    string k = kode[i];
    int s = skor[i];
    int j = i - 1;
    while (j >= 0 && skor[j] < s) {
      kode[j + 1] = kode[j];
      skor[j + 1] = skor[j];
      j--;
    }
    kode[j + 1] = k;
    skor[j + 1] = s;
  }
  for (int i = 0; i < n; i++) {
    cout << kode[i] << " " << skor[i] << "\n";
  }
}
```

**Latihan bercampur.** 1: keduanya mengurangi satu pasangan terbalik tiap kali; pertukaran bubble sort dan geseran insertion sort masing-masing membetulkan tepat satu pasangan, jadi totalnya sama dengan banyak pasangan terbalik pada data awal. 2: tiga kali sekuensial paling banyak 3 x 1000 = 3000 langkah. Mengurutkan 1000 data dengan insertion sort memerlukan paling banyak sekitar 1000 x 999 / 2 = 499.500 langkah, ditambah tiga kali biner (sekitar 10 langkah tiap kali). Untuk hanya tiga pencarian, sekuensial jauh lebih murah; mengurutkan baru sepadan bila pencarian sangat banyak. 3: kode `'B'` bernilai 66 dan `'a'` bernilai 97 dalam ASCII, sehingga `'B' < 'a'`. Akibatnya `Zebra` dianggap lebih kecil dari `apel`, dan semua kata berawalan huruf besar muncul lebih dulu daripada yang berawalan huruf kecil.

**Ulang berjarak.** 1: bagian kiri `v[0..i]` sudah terurut (tetapi belum tentu berisi elemen terbesar atau final). 2: sangat cepat pada data hampir terurut, dengan langkah sekitar `n`; paling lambat pada data terbalik, dengan langkah sekitar `n * (n - 1) / 2`. 3: geseran pertama menimpa `v[i]`; tanpa salinan di `x`, nilai yang mau disisipkan hilang.
