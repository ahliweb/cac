## Untuk siapa modul ini

Modul ini untuk murid kelas X jalur C (IoT dan robotika), minggu `C-X2-M14` silabus v1.3: asesmen dan refleksi semester 2. Prasyarat: modul `c-x2-m12` dan seluruh materi semester ini, `c-x2-m1` sampai `c-x2-m13`; modul ini menilai semuanya.

Modul ini berstatus DRAF: karangan penyusun, belum ditinjau pemilik, dan tidak dihitung sebagai pemenuhan butir capaian pembelajaran. Asesmen ini **tanpa AI**: jangan memakai AI generatif saat mengerjakannya (silabus 7.4). Bobot nilai dan predikat mengikuti kebijakan sekolah `[belum terverifikasi]`; modul ini hanya memberi soal dan kunci latihan.

Bagian praktik dapat dikerjakan **dengan papan** bila tersedia, atau **tanpa papan** di kertas dan komputer. Bila memakai papan, ikuti aturan keselamatan modul sebelumnya: daya USB saja, cabut kabel sebelum mengubah rangkaian, dan jangan menyentuh bagian yang bergerak saat daya menyala.

## Tujuan

Soal di modul ini menilai apakah kamu dapat:

- menjelaskan antrian, tumpukan, rata-rata bergerak, dan median, dan menerapkannya pada data sensor;
- menelusuri program dengan larik dan pencarian linear, dan menemukan galat;
- mengubah pembacaan sensor menjadi satuan dan keputusan, dan memperlakukan pembacaan tidak valid dengan benar;
- menyusun berkas data yang dapat dibaca orang lain;
- menyebut langkah keselamatan sebelum mengubah rangkaian.

## Latihan bercampur

Kerjakan sendiri, `AI: tanpa AI`, dengan waktu yang ditetapkan gurumu.

1. **Tulis.** Tulis pseudocode lalu program `masuk` dan `keluar` untuk antrian berkapasitas 3 dari larik bilangan bulat: `masuk` menolak data baru bila penuh, dan `keluar` mengambil yang tertua lalu menggeser sisanya.
2. **Telusuri.** Program berikut dijalankan:

   ```cpp
   // C++17 biasa, jalan di komputer. Diperiksa oleh check:module-code.
   #include <iostream>

   int main() {
     const int a[5] = {9, 4, 7, 4, 8};
     int terkecil = a[0];
     int indeks = 0;
     for (int i = 1; i < 5; i++) {
       if (a[i] < terkecil) {
         terkecil = a[i];
         indeks = i;
       }
     }
     std::cout << terkecil << " di indeks " << indeks << "\n";
   }
   ```

   Apa yang tercetak? Mengapa nilai 4 yang kedua tidak mengganti hasilnya?
3. **Hitung.** Waktu gema 1750 mikrodetik dengan 0,0343 cm per mikrodetik: berapa jaraknya (satu angka di belakang koma), dan zona apa dengan batas bahaya 20 cm dan batas waspada 50 cm? Lalu berapa median lima pembacaan 12, 15, 11, 40, 13?
4. **Cari galat.** Potongan berikut sengaja salah. Tulis dua galat, jelaskan akibatnya, dan tulis perbaikannya.

   ```text
   int median(int data[], int n) {
     urutkan(data, n);
     return data[n / 2 + 1];
   }
   ```
5. **Praktik atau data.** Dengan papan: rakit sensor jarak dan buzzer sesuai lembar guru, unggah programmu, dan peragakan alarm. Tanpa papan: tulis kepala berkas data tiga kolom (waktu, suhu, cahaya) dengan satuan dan selang waktu, lalu tiga baris karangan, dan dua langkah keselamatan sebelum mengubah rangkaian.

## Kunci dan petunjuk

**Ingat kembali.** 1: contoh: tidak menyentuh bagian bergerak saat daya menyala; cabut daya sebelum memasang atau mengubah; batasi sudut sesuai batas mekanik; jangan memutar lengan dengan tangan. 2: karena waktu gema adalah perjalanan pergi dan pulang, sedangkan jarak benda hanya satu arah. 3: sensor dibaca berkali-kali, disaring dengan median, lalu dicatat sebagai baris berformat. 4: (10 + 12 + 20) / 3 = 14. 5: antrian mengeluarkan 5 lebih dulu; tumpukan mengeluarkan 3 lebih dulu.

**Latihan bercampur.** 1: pseudocode: `masuk`: bila `terisi` sama dengan 3, tolak; bila tidak, taruh di `antrian[terisi]` lalu tambah `terisi`. `keluar`: bila `terisi` sama dengan 0, gagal; bila tidak, ambil `antrian[0]`, geser tiap elemen satu tempat ke depan, kurangi `terisi`. Contoh program: `bool masuk(int n) { if (terisi == 3) return false; antrian[terisi] = n; terisi++; return true; }` dan `bool keluar(int& n) { if (terisi == 0) return false; n = antrian[0]; for (int i = 0; i < terisi - 1; i++) antrian[i] = antrian[i + 1]; terisi--; return true; }`. 2: tercetak `4 di indeks 1`; nilai 4 kedua tidak mengganti hasil karena syaratnya `a[i] < terkecil` dan 4 tidak lebih kecil dari 4. Untuk mengganti pada nilai sama, syaratnya `<=`. 3: 1750 x 0,0343 / 2 = 30,0 cm, zona `WASPADA`; terurut 11, 12, 13, 15, 40, median 13. 4: galat pertama `urutkan(data, n)` mengurutkan larik asli sehingga urutan menurut waktu hilang; perbaikan: urutkan salinan. Galat kedua `n / 2 + 1` salah satu: median ada di indeks `n / 2` (untuk n = 7 indeks 3, bukan 4); perbaikan `data[n / 2]` pada salinan. 5: contoh kepala berkas: `# suhu dan cahaya ruang kelas, data karangan`, `# satuan: waktu detik, suhu derajat Celsius, cahaya nilai mentah; selang 30 detik`, `waktu_detik,suhu_c,cahaya`, lalu tiga baris seperti `0,28.1,2900`. Contoh langkah keselamatan: cabut kabel USB sebelum mengubah rangkaian dan periksa polaritas buzzer; tanpa listrik 220 V; laporkan papan panas atau berbau.

**Rubrik singkat.** Untuk soal 1 dan 5, periksa empat hal: ketepatan (program atau berkas memenuhi tujuan), keterbacaan (nama dan konstanta jelas), pengujian (disebut cara mengujinya, termasuk keadaan penuh dan kosong atau nilai tak valid), dan justifikasi (alasan pilihan). Skala yang disarankan: sudah, sebagian, belum, per hal. Untuk soal 2 sampai 4, jawaban dinilai benar bila angka dan alasan sama dengan kunci.

**Refleksi.** Tidak ada kunci. Jawaban yang baik menyebut bukti, bagian yang lemah, dan rencana yang jelas waktunya.
