## Contoh terselesaikan

Fungsi adalah blok program yang diberi nama. Ia membantu karena satu bagian punya satu tugas, bisa dipakai berulang, dan bisa diuji sendiri. Fungsi punya parameter (masukan ke fungsi) dan boleh mengembalikan nilai dengan `return`. Fungsi `void` tidak mengembalikan apa-apa; fungsi `int` mengembalikan bilangan bulat. Tulis fungsi di atas tempat ia dipakai. Mengubah parameter di dalam fungsi tidak mengubah variabel milik pemanggil, karena yang dikirim hanya salinan nilainya.

Larik (array) menyimpan beberapa nilai bertipe sama berderet di memori. Indeks dimulai dari 0: larik berisi 5 elemen punya indeks 0 sampai 4, jadi `POLA[5]` tidak ada. Membaca di luar larik tidak ditolak dengan pesan yang jelas; ia membaca memori lain dan hasilnya tidak terjamin.

Program berikut memecah tugas jadi tiga fungsi: `bacaCahaya()` mengembalikan nilai sensor, `gelap()` memakai ambang, dan `tampilkanPola()` menampilkan pola dari larik bila gelap. Papan tiruan di bawah memberi dua pembacaan sensor: terang (3500) lalu gelap (400).

```cpp
// C++17 biasa, jalan di komputer. Diperiksa oleh check:module-code.
#include <iostream>

// Papan tiruan: pengganti fungsi Arduino.
const int OUTPUT = 3;
const int HIGH = 1;
const int LOW = 0;
long waktu_ms = 0;
const int BACAAN[] = {3500, 400};
int langkah = 0;

void pinMode(int, int) {}
int analogRead(int) { return BACAAN[langkah]; }
void digitalWrite(int pin, int nilai) {
  std::cout << waktu_ms << " ms: pin " << pin << (nilai == HIGH ? " HIGH" : " LOW") << "\n";
}
void delay(long ms) { waktu_ms += ms; }

// Program yang sama dengan versi Arduino.
const int PIN_SENSOR = 34;
const int PIN_LED = 2;
const int AMBANG = 2000;
const int POLA[] = {1, 0, 1, 1, 0};
const int PANJANG_POLA = 5;

int bacaCahaya() {
  return analogRead(PIN_SENSOR);
}

bool gelap() {
  return bacaCahaya() < AMBANG;
}

void tampilkanPola() {
  for (int i = 0; i < PANJANG_POLA; i++) {
    digitalWrite(PIN_LED, POLA[i]);
    delay(100);
  }
  digitalWrite(PIN_LED, LOW);
}

void setup() {
  pinMode(PIN_LED, OUTPUT);
}

void loop() {
  if (gelap()) {
    tampilkanPola();
  } else {
    digitalWrite(PIN_LED, LOW);
  }
}

int main() {
  setup();
  for (langkah = 0; langkah < 2; langkah++) loop();
}
```

Keluarannya:

```text
0 ms: pin 2 LOW
0 ms: pin 2 HIGH
100 ms: pin 2 LOW
200 ms: pin 2 HIGH
300 ms: pin 2 HIGH
400 ms: pin 2 LOW
500 ms: pin 2 LOW
```

Baris pertama berasal dari pembacaan terang: lampu dipadamkan. Enam baris berikutnya berasal dari pembacaan gelap: lima langkah pola 1, 0, 1, 1, 0 (masing-masing 100 ms), lalu satu `LOW` penutup. `loop()` sekarang terbaca seperti kalimat: jika gelap, tampilkan pola. Rincian cara membaca sensor tersembunyi di dalam `bacaCahaya()`, sehingga bila sensornya diganti, hanya satu fungsi yang diubah.

## Soal Parsons

Susun baris-baris di bawah (sudah diacak) menjadi fungsi `tampilkanPola()` yang menampilkan larik `POLA` dengan jeda 100 ms.

```text
(a) }
(b)   for (int i = 0; i < PANJANG; i++) {
(c) void tampilkanPola() {
(d)     digitalWrite(PIN_LED, POLA[i]);
(e)   }
(f)     delay(100);
```

## Latihan

1. `AI: boleh` **Pseudocode dulu.** Tulis pseudocode, lalu programnya: fungsi `kedip(pin, kali, jeda_ms)` yang membuat LED berkedip sejumlah `kali`, dipakai di `loop()` untuk berkedip tiga kali cepat lalu jeda 1 detik.
2. `AI: tanpa AI` **Telusuri.** Diberikan `const int POLA[] = {2, 4, 6, 8};` dan `int jumlah = 0;`, lalu `for (int i = 1; i < 4; i++) { jumlah += POLA[i]; }`. Tulis nilai `jumlah` setelah tiap putaran.
3. `AI: tanpa AI` **Cari galat.** Larik `POLA` berisi 5 elemen dan `PANJANG_POLA` bernilai 5, tetapi perulangannya `for (int i = 0; i <= PANJANG_POLA; i++)`. Apa yang salah dan bagaimana memperbaikinya?
4. `AI: boleh` **Bila papan tersedia (opsional).** Unggah program modular dari contoh terselesaikan, lalu ubah isi `POLA` menjadi pola buatanmu sendiri. Bila LED tidak merespons, jangan mengubah rangkaian sendiri: periksa nomor pin lalu tanya guru.
5. *Opsional:* **catatan pemakaian AI.** Bila memakai AI generatif, jawab nomor 1 sendiri dulu, lalu minta penjelasan atau petunjuk bertahap, bukan program jadi. Catat alatnya, tujuanmu, garis besar perintahmu, bagian yang kamu pakai, dan cara memeriksanya (jalankan atau telusuri). Jangan menaruh data pribadi atau tugas bernilai pada perintah.

## Kesalahan umum

- **Indeks dimulai dari 1.** Elemen pertama larik berindeks 0; elemen terakhir berindeks panjang dikurangi satu.
- **Membaca di luar larik.** `POLA[5]` pada larik 5 elemen tidak ada. Program tetap dikompilasi, tetapi hasilnya tidak terjamin.
- **Lupa `return` pada fungsi bernilai.** Fungsi `int` harus mengembalikan nilai pada setiap jalur.
- **Mengira parameter mengubah variabel pemanggil.** Yang dikirim adalah salinan; variabel asli tidak berubah.
- **Mengira fungsi berjalan sendiri di latar belakang.** Fungsi hanya berjalan ketika dipanggil, dan pemanggil menunggu sampai selesai.

## Kunci dan petunjuk

**Ingat kembali.** 1: 3 dan 3,5; pembagian dua `int` membuang sisa, sedangkan operand berkoma membuat hasil berkoma. 2: `LOW`. 3: RAM menyimpan sementara dan cepat, hilang saat daya padam; penyimpanan menyimpan tetap dan lebih lambat.

**Prediksi dulu.** 1: dua langkah (indeks 0 dan 3). 2: 4 x 100 = 400 ms. 3: 0. 4: `POLA[4]` tidak ada (larik hanya berindeks 0 sampai 3), jadi nilai yang dibaca tidak terjamin.

**Contoh setengah jadi.** Isian berurutan: `HIGH`, `durasi_ms`, `1`. Fungsi `nyalaSebentar` menahan LED menyala selama `durasi_ms`; fungsi `dibawahAmbang` mengembalikan 1 bila nilai kurang dari ambang.

**Soal Parsons.** Urutan benar: c, b, d, f, e, a. Baris (e) menutup `for`; baris (a) menutup fungsi.

**Latihan.** 1: pseudocode: fungsi kedip(pin, kali, jeda): ulangi sebanyak kali: nyalakan pin; tunggu jeda; padamkan pin; tunggu jeda. Program: `void kedip(int pin, int kali, int jeda_ms) { for (int k = 0; k < kali; k++) { digitalWrite(pin, HIGH); delay(jeda_ms); digitalWrite(pin, LOW); delay(jeda_ms); } }`, lalu di `loop()`: `kedip(PIN_LED, 3, 100); delay(1000);`. 2: putaran i=1: 4; i=2: 10; i=3: 18; jumlah akhir 18. 3: `i <= PANJANG_POLA` menjalankan `POLA[5]` yang tidak ada; ganti menjadi `i < PANJANG_POLA`.

**Latihan bercampur.** 1: `int persen(int nilai) { return map(nilai, 0, 4095, 0, 100); }`; 2048 x 100 / 4095 = 50,01 menjadi 50. 2: `if (gelap() && digitalRead(PIN_TOMBOL) == LOW)`. 3: 10110 biner = 16 + 4 + 2 = 22.

**Ulang berjarak.** 1: fungsi `void` tidak mengembalikan nilai; fungsi `int` mengembalikan bilangan bulat lewat `return`. 2: indeks 0 dan 4. 3: tiap fungsi dapat dicoba sendiri dengan masukan yang diketahui, sehingga galat lebih cepat ditemukan.
