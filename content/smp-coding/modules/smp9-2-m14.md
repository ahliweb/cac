## Prediksi dulu

Tulis prediksimu sebelum menelusuri. Program X:

```python
def rapikan(teks):
    return teks.strip().capitalize()


def cari_petugas(jadwal, hari):
    return jadwal.get(rapikan(hari), [])


def ringkas(jadwal):
    if len(jadwal) == 0:
        return "jadwal kosong"
    jumlah = 0
    for hari in jadwal:
        jumlah = jumlah + len(jadwal[hari])
    return str(jumlah) + " petugas dalam " + str(len(jadwal)) + " hari"


jadwal = {"Senin": ["Murid-01", "Murid-02"], "Selasa": ["Murid-03"]}
print(cari_petugas(jadwal, "  SENIN "))
print(cari_petugas(jadwal, "kamis"))
print(ringkas(jadwal))
print(ringkas({}))
print(ringkas({"Rabu": []}))
```

**Prediksi.** Apa yang tercetak pada kelima baris? Tulis dulu, lalu telusuri `rapikan` dan `jumlah` per putaran.

## Contoh terselesaikan

| Baris | Telusuran | Tercetak |
| --- | --- | --- |
| 1 | `rapikan("  SENIN ")` menjadi `"Senin"`; ada di kamus | `['Murid-01', 'Murid-02']` |
| 2 | `rapikan("kamis")` menjadi `"Kamis"`; tidak ada, nilai cadangan `[]` | `[]` |
| 3 | `jumlah` 0, lalu +2 (Senin), lalu +1 (Selasa) menjadi 3; dua hari | `3 petugas dalam 2 hari` |
| 4 | `len({})` sama dengan 0, jadi pengaman langsung kembali | `jadwal kosong` |
| 5 | satu hari berisi daftar kosong: jumlah 0, satu hari | `0 petugas dalam 1 hari` |

Cara menjawab yang baik: rapikan masukan dulu, periksa pengaman, lalu hitung per putaran dan tulis nilainya.
