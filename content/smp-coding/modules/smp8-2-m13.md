## Prediksi dulu

Program W adalah kuis dua soal. Fungsi `periksa` membuang spasi di ujung jawaban, mengubahnya menjadi huruf kecil, lalu membandingkannya dengan kunci.

```python
def periksa(jawaban, benar):
    return jawaban.strip().lower() == benar

soal = ["6 x 7 = ?", "Hewan yang mengeong?"]
kunci = ["42", "kucing"]
skor = 0
for i in range(len(soal)):
    jawaban = input(soal[i] + " ")
    if periksa(jawaban, kunci[i]):
        skor = skor + 1
print("Skor:", skor, "dari", len(soal))
```

**Prediksi.** Murid mengetik ` 42 ` (dengan spasi) untuk soal 1 dan `Anjing` untuk soal 2. Apa baris terakhir yang tercetak? Tulis dulu, lalu telusuri dengan tabel `i`, `jawaban`, `periksa`, dan `skor`.

## Contoh terselesaikan

Karena ini minggu proyek, contohnya berupa **contoh rencana kerja**.

| Bagian rencana | Isi contoh (kuis dua soal) |
| --- | --- |
| Tujuan satu kalimat | Menanyakan dua soal dan menghitung berapa jawaban benar. |
| Bagian kecil | (1) fungsi `periksa`; (2) daftar `soal` dan `kunci`; (3) `for` yang bertanya; (4) `if` yang menambah skor. |
| Yang dipakai | `def`, `return`, daftar, `for`, `if`, `input`, `print`. |
| Tiga kasus uji | Benar: `42`. Batas: `  KUCING ` (spasi dan huruf besar). Salah: `anjing`. |
| Pembagian kerja | A menulis bagian 1 dan 2; B menulis bagian 3 dan 4; keduanya menguji. |
| Bahan orang lain | Tidak ada; semua soal buatan sendiri. |
| Data pribadi | Tidak ada; program tidak menanyakan nama. |

Penelusuran W: untuk `i` = 0, `jawaban` ` 42 ` menjadi `42` sesudah `strip` dan cocok dengan kunci, jadi `skor` 1. Untuk `i` = 1, `anjing` tidak sama dengan `kucing`, jadi `skor` tetap 1. Baris terakhir yang tercetak: `Skor: 1 dari 2`.

Tiga kasus uji untuk `periksa` dijalankan seperti ini:

```python
print(periksa("42", "42"))
print(periksa("  KUCING ", "kucing"))
print(periksa("anjing", "kucing"))
```

Tercetak `True`, `True`, lalu `False`. Kasus di batas (spasi dan huruf besar) paling mudah terlupa. Pilihan **kuis gambar** memakai kura-kura dari `SMP8-2-M7`: program menggambar segi-`n` lalu bertanya "berapa sisinya?". Rencana, fungsi, dan kasus ujinya sama.
