## Untuk siapa modul ini

Modul ini untuk murid kelas 9 pada minggu ketiga belas semester pertama, minggu proyek mini. Kamu bekerja sendiri atau berdua dengan Python dan kertas rencana; simpan berkas sesuai arahan gurumu. Waktunya satu pertemuan, 2 JP, dan hasilnya satu program yang membaca data kecil beserta penjelasan satu menit. Prasyaratnya `SMP9-1-M4` (membaca berkas teks) dan `SMP9-1-M5` (data tabel kecil). Semua data di modul ini rekaan.

## Ingat kembali

Tutup modul ini dan jawab dari ingatan.

1. Sebut jenis galat bila berkas tidak ditemukan dan dua penyebabnya. (`SMP9-1-M4`)
2. Hitung jumlah, rata-rata, dan nilai terbesar `[3, 8, 5, 9, 5]` dengan program. (`SMP9-1-M5`)
3. Sebut apa yang dicatat dalam tinjauan asal dan lisensi sebuah himpunan data. (`SMP9-1-M6`)
4. Tulis program yang mencetak grafik batang teks dari sebuah kamus, lalu satu kesimpulan beserta batasnya. (`SMP9-1-M7`)
5. Tulis tiga kasus uji untuk program yang membaca data kecil: biasa, kosong, dan di batas. (`SMP8-2-M13`)
6. Tulis rencana kerja untuk proyek mini pengolah data kecil: tujuan, bagian kecil, dan tiga kasus uji. (`SMP9-1-M12`)

Kunci: (1) `FileNotFoundError`; nama berkas salah ketik, atau berkas ada di folder lain; (2) jumlah 30, rata-rata 6.0, terbesar 9, dengan `total = 0`, `for n in daftar:` lalu `total = total + n`, dan `max`; (3) penerbit, tanggal, lisensi, ada tidaknya data pribadi, dan cara menyebut sumber; (4) `for nama in data:` dengan `print(nama, "|", "#" * data[nama], data[nama])`; kesimpulan memuat pernyataan, angka pendukung, dan batas; (5) satu berkas berisi beberapa angka, satu kosong, satu berisi satu angka 0, masing-masing dengan hasil diharapkan; (6) tujuan satu kalimat, tiga atau empat bagian kecil, dan tiga kasus uji.

## Tujuan

Setelah modul ini kamu dapat:

1. menulis rencana kerja untuk program pengolah data kecil;
2. membuat program dengan fungsi yang membaca berkas angka dan meringkasnya;
3. menguji dengan tiga kasus dan memperbaiki yang gagal dengan catatan penyebab;
4. menjelaskan programmu lisan dalam satu menit.

## Prediksi dulu

Berkas `suhu.txt` berisi suhu rekaan, satu angka satu baris, dengan satu baris kosong di tengah:

```text
28
31

30
27
```

Program W:

```python
def baca_angka(nama):
    angka = []
    with open(nama, encoding="utf-8") as berkas:
        for baris in berkas:
            baris = baris.strip()
            if baris != "":
                angka.append(int(baris))
    return angka


def ringkas(angka):
    if len(angka) == 0:
        return "data kosong"
    rata = sum(angka) / len(angka)
    return "rata-rata " + str(rata) + ", terbesar " + str(max(angka))


print(ringkas(baca_angka("suhu.txt")))
```

**Prediksi.** Apa yang tercetak? Isi `angka` ada berapa? Tulis dulu, lalu telusuri `baris`, apakah kosong, dan isi `angka`.

## Contoh terselesaikan

Karena ini minggu proyek, contohnya berupa **contoh rencana kerja**.

| Bagian rencana | Isi contoh (peringkas suhu) |
| --- | --- |
| Tujuan satu kalimat | Membaca berkas suhu dan mencetak rata-rata dan suhu terbesar. |
| Bagian kecil | (1) `baca_angka` membaca dan melewati baris kosong; (2) `ringkas` menghitung; (3) pengaman data kosong. |
| Tiga kasus uji | Biasa: `suhu.txt`. Kosong: berkas tanpa baris. Batas: berkas berisi satu angka 0. |
| Asal dan lisensi data | Rekaan buatan sendiri; tidak ada pemilik lain. |
| Data pribadi | Tidak ada; berkas hanya berisi angka. |

Penelusuran W: baris `"28"`, `"31"`, `""` (dilewati), `"30"`, `"27"`, jadi `angka` berisi `[28, 31, 30, 27]`, empat isi. Jumlahnya 116, rata-rata 29.0, terbesar 31. Tercetak `rata-rata 29.0, terbesar 31`.

Tiga kasus uji dijalankan lewat `ringkas(baca_angka(...))`:

| Kasus | Berkas | Tercetak |
| --- | --- | --- |
| Biasa | `suhu.txt` | `rata-rata 29.0, terbesar 31` |
| Kosong | tanpa baris | `data kosong` |
| Batas | satu baris `0` | `rata-rata 0.0, terbesar 0` |

Tanpa pengaman di `ringkas`, kasus kosong menghitung `0 / 0` dan berhenti dengan `ZeroDivisionError`. Dengan pengaman, program memberi jawaban yang jelas. Tinjau ulang: kasus kosong paling mudah terlupa.

## Kesalahan umum

- **Tidak menangani data kosong.** Kenali: `ZeroDivisionError` saat membagi dengan `len(angka)` yang 0.
- **Lupa melewati baris kosong atau lupa `strip`.** Kenali: `int("")` menghasilkan `ValueError`.
- **Lupa `int`.** Kenali: `"28" + "31"` menjadi `2831`, bukan 59.
- **Berkas di folder yang salah.** Kenali: `FileNotFoundError` padahal nama berkas benar.
- **Menyimpulkan sebab dari rata-rata.** Kenali: kalimat memakai "karena", padahal data hanya menunjukkan ringkasan.
