## Untuk siapa modul ini

Modul ini untuk murid kelas 8 pada minggu kesepuluh semester pertama. Kamu memakai simulator MakeCode untuk micro:bit di peramban, tanpa akun; simpan berkas sesuai arahan gurumu. Kalau komputer terbatas, tabel penelusuran di kertas cukup untuk sebagian besar kegiatan. Waktunya satu pertemuan, 2 JP. Prasyaratnya `SMP8-1-M9` (translasi ke bahasa blok lain).

## Ingat kembali

Tutup modul ini dan jawab dari ingatan.

1. Sebut padanan MakeCode untuk `when green flag clicked`, `forever`, dan `say`. (`SMP8-1-M9`)
2. Sebut komponen sistem komputer: masukan, proses, keluaran, dan tempat menyimpan. Beri satu contoh tiap komponen. (`SMP7-2-M10`)
3. Mengapa komputer menyimpan data dengan dua nilai, 0 dan 1? (`SMP7-2-M2`)

Kunci: (1) `on start`, `forever`, `show string` atau `show number`; (2) masukan: papan ketik; proses: prosesor; keluaran: layar; memori sementara dan penyimpanan jangka panjang; (3) rangkaian elektronik paling mudah dibuat dengan dua keadaan, misalnya ada arus atau tidak.

## Tujuan

Setelah modul ini kamu dapat:

1. membedakan masukan dan keluaran pada perangkat micro:bit simulator;
2. menulis program yang bereaksi pada tombol A dan B;
3. memakai koordinat layar LED 5 x 5 untuk menyalakan lampu tertentu;
4. menelusuri program berperistiwa dengan tabel dan menjaga nilai di batas.

## Prediksi dulu

Perangkat seperti micro:bit adalah komputer kecil: **masukan** (tombol, sensor) masuk ke **proses** (programmu), lalu keluar sebagai **keluaran** (lampu, bunyi). Programnya berbentuk potongan yang menunggu **peristiwa**: isi `on button A pressed` hanya dijalankan tiap kali tombol A ditekan.

Program P:

```text
on start
  set hitung to 0
on button A pressed
  change hitung by 1
  show number hitung
on button B pressed
  set hitung to 0
  show number hitung
```

Tombol ditekan berurutan: A, A, A, B, A.

**Prediksi.** Angka apa yang tampil sesudah tiap penekanan? Tulis dulu.

**Jalankan.** Telusuri dengan tabel:

| Penekanan | Tombol | hitung | Tampil |
| --- | --- | --- | --- |
| 1 | A | | |
| 2 | A | | |
| 3 | A | | |
| 4 | B | | |
| 5 | A | | |

**Selidiki.** Cocokkan dengan prediksimu. Apa yang terjadi pada `hitung` saat tombol B ditekan?

## Contoh terselesaikan

Penelusuran P: hitung 1, 2, 3, 0, 1, dan angka itulah yang tampil. `on start` hanya berjalan satu kali di awal; dua blok tombol berjalan setiap kali tombolnya ditekan.

Sekarang layar LED. Layar berukuran 5 x 5; kolom **x** dihitung dari kiri (0 sampai 4) dan baris **y** dari atas (0 sampai 4). Program L menyalakan satu lampu tiap A ditekan, bergeser ke kanan di baris 2, dan menjaga batas:

```text
on start
  set kolom to 0
on button A pressed
  if kolom < 5 then
    plot x kolom y 2
    change kolom by 1
on button B pressed
  clear screen
  set kolom to 0
```

Sesudah A ditekan tiga kali, `kolom` = 3 dan tiga lampu menyala:

```text
        x: 0 1 2 3 4
y = 0      . . . . .
y = 1      . . . . .
y = 2      # # # . .
y = 3      . . . . .
y = 4      . . . . .
```

| Penekanan A | kolom sebelum | Lampu yang menyala | kolom sesudah |
| --- | --- | --- | --- |
| 1 | 0 | (0, 2) | 1 |
| 2 | 1 | (1, 2) | 2 |
| 3 | 2 | (2, 2) | 3 |

Dalam bahasa komponen: masukan adalah tombol A dan B; proses adalah `if` dan perhitungan `kolom`; keluaran adalah lampu LED; `kolom` hidup di memori, jadi nilainya hilang bila simulator dimulai ulang.

Tiga hal yang perlu diingat. Pertama, program berperistiwa tidak berjalan dari atas ke bawah; tiap blok peristiwa menunggu pemicunya. Kedua, layar hanya punya posisi 0 sampai 4, jadi `kolom` perlu dijaga dengan `if`; hasil `plot` di luar layar tidak dijamin. Ketiga, `clear screen` menghapus lampu, tetapi tidak mengubah variabel; makanya B juga memanggil `set kolom to 0`.

## Contoh setengah jadi

Lengkapi program L dengan batas dan pengaturan ulang. Isi bagian kosong, lalu sebut `kolom` sesudah A ditekan enam kali.

```text setengah-jadi
on button A pressed
  if kolom < ____ then
    plot x kolom y 2
    change kolom by 1
on button B pressed
  clear screen
  set kolom to ____
```

## Susun urutannya

Lima baris berikut sudah diacak. Susun menjadi program yang menampilkan banyaknya tombol A ditekan.

- **A.** `on start`
- **B.** `  set hitung to 0` (di dalam `on start`)
- **C.** `on button A pressed`
- **D.** `  change hitung by 1` (di dalam `on button A pressed`)
- **E.** `  show number hitung` (di dalam `on button A pressed`, sesudah `change`)

Tulis urutan hurufnya. Jelaskan mengapa `show number` ada sesudah `change`.

## Latihan

1. **Ubah.** Pada program P, ganti `change hitung by 1` menjadi `change hitung by 2`. Berapa yang tampil sesudah A, A, A?
2. **Buat.** Tulis program: tombol B menyalakan lampu pojok kiri bawah (x 0, y 4), dan tombol A mematikannya dengan `unplot x 0 y 4`.
3. **Selidiki.** Telusuri P untuk urutan A, A, B, A, A. Angka apa saja yang tampil?
4. **Pilah.** Mana yang masukan dan mana yang keluaran: tombol A, layar LED, sensor suhu, bunyi dari pengeras suara, menggoyangkan papan?
5. **Jelaskan.** Kapan isi `on button A pressed` dijalankan?

## Latihan bercampur

2. Kartu memori yang menyimpan foto termasuk memori atau penyimpanan? Mengapa? (`SMP7-2-M10`)

## Kesalahan umum

- **Mengira program berjalan dari atas ke bawah.** Blok peristiwa menunggu pemicunya. Kenali: kamu menunggu tampilan padahal tombol belum ditekan.
- **Mengira variabel kembali ke awal tiap tombol ditekan.** Nilainya bertahan di memori. Kenali: angka terus naik walau kamu mengira ulang dari 0.
- **Lupa menjaga batas layar.** Kenali: posisi lampu lebih dari 4 atau kurang dari 0.
- **Tertukar kolom dan baris.** Kenali: lampu muncul di tempat yang menurutmu terbalik; x untuk kolom, y untuk baris.
- **Mengira `clear screen` mengatur ulang variabel.** Kenali: layar kosong tetapi lampu baru muncul di posisi lama.

## Catatan untuk guru

- **Waktu:** 2 JP x 40 menit `[asumsi]` (silabus bagian 2). Berpasangan boleh untuk "Prediksi dulu" dan "Latihan"; bukan jaminan efek belajar.
- **Alat:** simulator MakeCode untuk micro:bit di peramban, tanpa akun murid; berkas disimpan lokal. Papan fisik opsional; bila dipakai, ikuti panduan keselamatan resmi micro:bit (microbit.org, bagian User guide) untuk daya dan baterai. Nama dan bentuk blok bisa berbeda menurut bahasa antarmuka dan versi editor; periksa blok `plot`, `unplot`, `clear screen`, dan `show number` di simulator sebelum kelas. Nama blok MakeCode dicocokkan per 2026-11 dengan sumber resmi MakeCode micro:bit (pustaka inti `pxt-microbit`: `forever`, `pause (ms)`, `show number`, `show string`, `on button A pressed`, `plot x y`, `unplot x y`, `clear screen`; editor `pxt`: `repeat n times`, `set x to`, `change x by`, `if ... then`/`else`) dan situs resmi makecode.microbit.org (halaman referensi `basic`, `input`, `music`; blok `on start`). Penulis menelusuri tangan semua program dan menghitung ulang semua angka dengan skrip bantu; ia tidak menjalankan program di editor. Hasil `plot` di luar layar tidak diklaim di modul; periksa sendiri bila ingin menunjukkannya.
- **Butir CP:** corpus memetakan minggu ini ke `D-LD-f` dan `D-BK-e`. Modul ini tidak menyatakan CP "terpenuhi"; ia hanya melatih masukan, keluaran, dan program berperistiwa pada perangkat tersimulasi.
- **Kunci "Prediksi dulu":** hitung 1, 2, 3, 0, 1; tampil 1, 2, 3, 0, 1.

- **Kunci "Susun urutannya":** A, B, C, D, E. `show number` sesudah `change` agar yang tampil nilai terbaru.
