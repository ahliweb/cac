## Prediksi dulu

Program Python P mencari nilai di daftar dan mengembalikan indeks, atau -1 bila tidak ada:

```python
def cari(daftar, x):
    for i in range(len(daftar)):
        if daftar[i] == x:
            return i
    return -1


nilai = [7, 3, 9, 3]
print(cari(nilai, 3))
print(cari(nilai, 5))
print(cari(nilai, 9))
```

**Prediksi.** Apa yang tercetak pada tiga baris? Tulis dulu, lalu telusuri `i` dan `daftar[i]` untuk `cari(nilai, 3)`.

## Contoh terselesaikan

Tercetak `1`, `-1`, `2`. Berikut program yang sama dalam pseudocode (kosakata `FUNGSI` dan `KEMBALIKAN` baru di sini):

```text
FUNGSI cari(daftar, x)
  UNTUK i DARI 0 SAMPAI panjang(daftar) - 1
    JIKA daftar[i] = x MAKA
      KEMBALIKAN i
  KEMBALIKAN -1
```

Dan dalam C++ (hanya dibaca):

```cpp
#include <iostream>
#include <vector>

int cari(const std::vector<int>& daftar, int x) {
    for (int i = 0; i < static_cast<int>(daftar.size()); i++) {
        if (daftar[i] == x) {
            return i;
        }
    }
    return -1;
}

int main() {
    std::vector<int> nilai = {7, 3, 9, 3};
    std::cout << cari(nilai, 3) << "\n";
    std::cout << cari(nilai, 5) << "\n";
    std::cout << cari(nilai, 9) << "\n";
    return 0;
}
```

Keluaran C++ sama: `1`, `-1`, `2`. Tiga hal yang dicari saat membaca kode bahasa lain, dan di mana kamu menemukannya:

| Yang dicari | Python | C++ |
| --- | --- | --- |
| Masukan dan keluaran | `def cari(daftar, x)`, `return` | `int cari(...)`: `int` di depan adalah tipe keluaran; tiap masukan punya tipe |
| Perulangan dan kondisi | `for i in range(...)`, `if ...:` | `for (int i = 0; ...; i++)`, `if (...)` |
| Awal dan akhir blok | titik dua dan jorokan | kurung kurawal `{ }` dan titik koma `;` di akhir pernyataan |

Dua hal baru di C++: tipe ditulis di depan nama, dan `daftar.size()` ukuran daftar (padanan `len`). Yang sama: gagasan, yaitu memeriksa satu per satu dan mengembalikan indeks pertama. Bahasa berganti, perulangan dan kondisi tetap sama.

## Contoh setengah jadi

Terjemahkan fungsi Python ke pseudocode. Isi bagian kosong.

```python setengah-jadi
def terbesar(daftar):
    hasil = daftar[0]
    for n in daftar:
        if n > hasil:
            hasil = n
    return hasil
```

```text setengah-jadi
FUNGSI terbesar(daftar)
  hasil <- daftar[0]
  UNTUK SETIAP n DALAM daftar
    JIKA n ____ hasil MAKA
      hasil <- ____
  KEMBALIKAN ____
```
