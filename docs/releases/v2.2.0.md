# Release v2.2.0 — 2026-11-19

SMA coding syllabus v1.1 with the shared grade-X foundation block, `plan` and
`render lembar-siswa` for `sma-coding`, 27 draft `sma-coding` modules, and the
owner approval of the nine OSN modules. This is a **minor** release: **no
breaking changes**, and **no OSN curriculum content (transcribed syllabus
content) changed**.

This document only covers what changed between v2.1.0 and v2.2.0; for earlier
releases read [`v2.1.0.md`](v2.1.0.md) and [`v2.0.0.md`](v2.0.0.md).

## Upgrade notes

None required. Paths, package name (`kurikulum-informatika`) and output shapes
are unchanged. Behaviours that differ from v2.1.0:

- `osn plan` and `osn render lembar-siswa` now **accept** `--program
  sma-coding` (they exited 2 in v2.1.0). `render weekly`, `render checkpoint`,
  `render sop`, `report` and `checklist` still exit 2 for `sma-coding`.
- `osn validate --program sma-coding` now checks **seven** data files (the new
  `foundation.json`) plus the module index, and the registered `sma-coding`
  syllabus version is `1.1.0` (`2026-11-19`). `osn validate` without
  `--program` still returns `{ ok, programs: [...] }` with two entries.
- Week codes for `sma-coding` gain the `FND` prefix (`FND-X1-M1..M7`); the
  grade-X semester-1 track weeks now run M8..M14.
- `osn report --by topic|week` still exits 2, with a new message that states
  the reason and the alternative.
- `bun run check:requirements` is stricter: issue references above #26 are
  accepted, malformed ones (`#0`, `#abc`, `26`) are reported.
- Biome is 2.6 and Markdown is excluded from formatting; run `bun install`
  after pulling the tag.

## What is new

### Owner approvals

- **2026-11-18:** the nine remaining OSN modules (`aritmetika`,
  `aturan-berhitung`, `geometri-dasar`, `graph-tree`, `logika-bitwise`,
  `rekursi`, `search-sort`, `strategi-problem-solving`, `struktur-data`) are
  `disetujui` (#99, #98); all ten OSN modules render without the `DRAF`
  banner. Milestone M8 is complete.
- **2026-11-19:** SMA coding syllabus v1.1 (#112, #92), applying the
  seven-week foundation block decided on 2026-11-18. The design documents for
  the companion, cloud and computational-maths series were also recorded as
  approved.

### SMA coding programme

- **Corpus v1.1:** `data/sma-coding/foundation.json` (schema
  `src/schema/sma-foundation.ts`) with `FND-X1-M1..M7`; audit rules require
  grade-X semester-1 track weeks 8..14 and `FND-X1` weeks 1..7.
- **CLI:** `osn plan --program sma-coding --track <A|B> [--kelas] [--semester]`
  and `osn render lembar-siswa --program sma-coding --week <week-code>` (#119,
  #77). The sheet lists "Modul terkait" (#120) and carries no identity fields.
- **Module index and renderer** (#114, #106): `src/schema/sma-module.ts`,
  `osn render modul --id <id> --program sma-coding`. The same change fixes a
  week check for `sma-coding` that was silently skipped.
- **27 draft modules** in `content/sma-coding/modules/` (#115-#118): 6
  foundation, 7 computational maths, 7 cloud, 7 companion. All `draf`.
- **Requirements** `FR-27`..`FR-31`, `TR-12`, `TR-13`, `GR-13` (#103, #76),
  `FR-32` (#114, #106) and `FR-33` (#119, #77).

Companion modules (#100), cloud series (#101) and computational maths series

syllabus v1.1 draft (#104, approved and encoded in #112); drafts of tracks C

### Documentation and tooling
