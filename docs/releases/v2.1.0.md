# Release v2.1.0 — 2026-11-18

Nine draft learning modules, the `sma-coding` programme corpus and the owner
approvals behind them. This is a **minor** release: **no breaking changes**,
and **no OSN curriculum content changed**.

If you are adopting this project for the first time, read
[`docs/releases/v1.0.0.md`](v1.0.0.md) and [`docs/releases/v2.0.0.md`](v2.0.0.md)
first; this document only covers what changed between v2.0.0 and v2.1.0.

## Upgrade notes

None required. Paths, package name (`kurikulum-informatika`) and the output
shapes from v2.0.0 are unchanged. Two behaviours are new and worth knowing:

- `osn validate` without `--program` now validates **both** registered
  programmes (`osn` and `sma-coding`); the `{ ok, programs: [...] }` shape
  simply gains a second entry.
- `osn plan`, `render` (except `render modul`), `report` and `checklist`
  refuse `--program sma-coding` with exit 2 ("belum didukung untuk program
  sma-coding") instead of serving OSN data.

Run `bun install` after pulling the tag.

## What is new

### Owner approvals (2026-11-18)

- **Pilot module `dasar-pemrograman` is `disetujui`** (#55, #67). The `DRAF`
  banner no longer appears in `osn render modul --id dasar-pemrograman`;
  module content is unchanged.
- **SMA coding syllabus v1.0** is approved for tracks A (C++) and B (JS/TS on
  Bun with `awcms-one`) (#70) and renamed to
  `docs/programs/sma-coding/silabus.md`. Track C (IoT/robotics) and the
  companion modules are tracked separately and are **not** part of this
  approval.

### Nine OSN learning modules, status `draf`

`aritmetika`, `aturan-berhitung`, `geometri-dasar`, `graph-tree`,
`logika-bitwise`, `rekursi`, `search-sort`, `strategi-problem-solving` and
`struktur-data` (#71-#75, #78-#81; issue #55). All ten OSN modules now exist.
The nine new ones render with the `DRAF` banner until the owner approves them
(ADR-0007).

### `sma-coding` programme corpus

- `data/sma-coding/` (#52, #82) encodes the approved syllabus v1.0: CP
  quotations and item codes, tracks, programme structure, the 168-week plan,
  the CP-to-week mapping and the bridge to the ten OSN topic families.
- Registered in `data/programs.json` (syllabus `1.0.0`, `2026-11-18`); new
  schemas `src/schema/sma-*.ts` and `src/domain/sma-corpus-audit.ts` back
  `osn validate --program sma-coding`, including a check that every OSN topic
  family id used by the bridge exists in the OSN corpus.
- `bun run check:sma-fidelity` (also run by `bun test`) compares every table
  cell of the syllabus with the data and fails on drift.

### AI book research and track D

A research note on AI books by Onno W. Purbo as possible references for the
SMA coding programme (#66, #83): verified titles, unverified items listed
separately, fit against CP codes and tracks, utilisation options. It links to
the books and does not copy their content. The owner decided that the
findings feed a separate **AI track D** (#84, #85); the note moves to v0.2.0.
