# Release v2.4.0 — 2026-11-19

Coding programmes from kindergarten to adults. Five more programmes
(`tk-coding`, `sd-coding`, `smp-coding`, `kuliah-coding`, `dewasa-coding`)
were approved by the owner and encoded. The release also adds a
per-programme audit and fidelity table (ADR-0008), two research documents
shared by every programme, and an AI-use policy per programme.

This is a **minor** release with **no breaking changes**. **No OSN curriculum
content changed.**

This document only covers what changed between v2.3.0 and v2.4.0. Read
[`docs/releases/v2.3.0.md`](v2.3.0.md) for the previous release.

## Upgrade notes

None required. Run `bun install` after pulling the tag.

These things behave differently:

- **`osn validate` checks seven programmes.** Run it without `--program` to
  validate all seven, or pass `--program <id>` to validate one.
- **`bun run check:fidelity [--program <id>]` is new.** It runs the
  cell-by-cell syllabus check of every programme that has one: all except
  `osn`, whose transcription is checked by `check:checklist-fidelity`.
  `check:sma-fidelity` still works.
- **`osn plan` and `osn render lembar-siswa` exit 2 for the five new
  programmes.** The refusal message now says which commands support each
  programme: `osn validate` and `check:fidelity`.
- **`sma-coding` corpus is at 1.3.0.** Learners in grades X–XII may now
  use generative AI under the ethics rules in syllabus section 7.4. This
  replaces the v1.2 rule for track D that only allowed teacher
  demonstrations.

## What is new

### Owner decisions (2026-11-19)

- **Encoding approach.** Each new programme gets its own schema and fidelity
  module rather than one generic schema
  ([ADR-0008](../architecture/adr/0008-skema-khusus-per-program.md), #140).
- **Five syllabi approved** with every author recommendation (#127–#131).
- **AI research proposals adopted.** All proposals U-01..U-17 from the AI
  research were adopted (#139), with the AI policy set per programme:
  - SMA: learners use AI freely under ethics rules.
  - SMP: AI stays a teacher demonstration, with no learner accounts.
  - Kuliah: three levels of AI use with a usage log, and no AI in contests.
  - Dewasa: a policy written for adult learners.
- **Pre-release tidy-up** (#165). The CLI refusal messages were corrected,
  and the five syllabi got patch revisions that replace only stale
  sentences about whether a sibling programme exists.

### Research (draft, authored content)

- **Learning science.**
  [`docs/riset/ilmu-belajar-kognitif.md`](../riset/ilmu-belajar-kognitif.md)

  [`docs/riset/ai-rekayasa-perangkat-lunak.md`](../riset/ai-rekayasa-perangkat-lunak.md)

  Its review is due in May 2027
  ([#151](https://github.com/ahliweb/osn/issues/151)).

The DOIs and arXiv IDs in both documents were checked against their
registries.

### Code and requirements

- **Programme table.** `PROGRAM_MODULES` in `src/cli/program-registry.ts`
  holds each programme's schemas, audit, module-index hooks and fidelity
  module. A programme that is registered but has no table entry is reported
  as a finding.
- **Per-programme code.** Each programme has its own `src/schema/*`, a
  pure audit in `src/domain/*-corpus-audit.ts` and a fidelity module in
  `src/cli/fidelity/<id>.ts`.
- **Requirements register.** There are now 99 requirements. New ones are
  `TR-14`, `FR-34`..`FR-38`, `TR-15`..`TR-19` and `ER-17`.
