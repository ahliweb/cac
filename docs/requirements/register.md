# Requirements Register

Full register of requirements derived from *Silabus Operasional Pembinaan OSN Informatika 2026*
(`docs/silabus/`). See `README.md` in this directory for the ID scheme, status vocabulary, and
verification methods. See `traceability.md` for the section↔requirement↔issue matrices that
prove this register is exhaustive.

99 requirements: 38 `FR`, 19 `TR`, 12 `OR`, 17 `ER`, 13 `GR`. The first 77 are derived from the OSN syllabus; `FR-27`-`FR-38`, `TR-12`-`TR-19`, `ER-17` and `GR-13` were added for the multi-programme work (ADR-0006, ADR-0007, ADR-0008), the `sma-coding` programme and the five further coding programmes (`tk-coding`, `sd-coding`, `smp-coding`, `kuliah-coding`, `dewasa-coding`), and cite those documents instead of an OSN section.
